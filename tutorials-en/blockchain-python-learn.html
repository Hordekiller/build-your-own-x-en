Learn Blockchains by Building One

About

The tutorial that launched a thousand blockchains. Using Python, Flask and a modicum of requests, you build a complete blockchain API: mining with proof-of-work, the longest valid chain as consensus, and nodes that hash together with a registration mechanism.

What you'll learn

  • A Blockchain class with transactions.
  • Proof-of-work: finding a nonce that satisfies the target.
  • A Flask network: mine, submit transactions, sync chains.
  • Consensus: replace a chain when a peer's is longer.

Why it matters

It proves a blockchain is just a web API plus hashing plus a rule for choosing the truth. The practical consensus demonstration — two nodes and a longer chain replacing the local one — demystifies distributed agreement permanently.
