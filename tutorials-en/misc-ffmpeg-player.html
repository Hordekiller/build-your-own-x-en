How to Write a Video Player in Less Than 1000 Lines

About

A video player built with the FFmpeg library and SDL in C: open the file, find audio/video streams, decode frames with the right codec, convert YUV to RGB and display them - covering the classic (simplified) FFmpeg API and playback timing.

What you'll learn

  • The pipeline: file -> encoded packets -> decoded frames -> RGB -> screen
  • AVFormatContext vs AVCodecContext and stream discovery
  • YUV-to-RGB conversion with sws_scale and SDL display + playback timing

Core idea

Two structures carry everything: AVFormatContext owns the file and streams, AVCodecContext owns the active codec. Each frame is decoded, converted to RGB and copied into an SDL surface.

C// turn one decoded frame into RGB and display it
void displayFrame(AVFrame *frame, AVPicture *pict, SwsContext *sws, SDL_Surface *screen) {
    int w = frame->width, h = frame->height;
    // YUV -> RGB using swscale
    sws_scale(sws, frame->data, frame->linesize, 0, h,
              pict->data, pict->linesize);
    // copy pixels to the SDL surface
    SDL_LockSurface(screen);
    memcpy(screen->pixels, pict->data[0], pict->linesize[0] * h);
    SDL_UnlockSurface(screen);
    SDL_UpdateRect(screen, 0, 0, w, h);
}

Why it matters

Multimedia is usually a black box; here every step from compressed file to pixels on screen is your own code.
