Build Your Own Web Server From Scratch In JavaScript

About

A book-style tutorial building an HTTP server in Node.js from the ground up. Part one (7 chapters) covers HTTP semantics and a base server; part two (6 chapters) adds dynamic content, file serving, Range requests, caching, compression and WebSockets.

What you'll learn

  • Raw TCP servers with the net module and how HTTP sits on top
  • Parsing requests and building responses by hand
  • Range requests, caching, compression and WebSocket upgrades

Core idea

A request is complete when the \r\n\r\n header terminator is seen; the request line splits into method, path and version.

JavaScriptconst net = require('net');

const server = net.createServer((socket) => {
  let buf = '';
  socket.on('data', (data) => {
    buf += data.toString();
    const headerEnd = buf.indexOf('\r\n\r\n');
    if (headerEnd === -1) return; // not complete yet
    const requestLine = buf.slice(0, buf.indexOf('\r\n'));
    const [method, path, version] = requestLine.split(' ');
    console.log(`${method} ${path}`);
    const body = 'Hello, World!';
    const response =
      'HTTP/1.1 200 OK\r\n' +
      `Content-Length: ${body.length}\r\n` +
      'Content-Type: text/plain\r\n' +
      '\r\n' + body;
    socket.write(response);
    socket.end();
  });
});

server.listen(8000, () => console.log('HTTP server on port 8000'));

Why it matters

In the 'build from scratch' tradition it skips Node's own http module and uses net, so every layer is hand-made - then compared with the standard library.
