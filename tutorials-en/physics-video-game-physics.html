About

The classic Gaffer on Games series on game physics: vector math, particles, rigid bodies and more, with a focus on numerical robustness.

What you'll learn

  • Semi-implicit Euler integration for a particle system
  • Representing particles as position, velocity and mass structs
  • Watching simulation output drift as numeric error accumulates

Core idea

The first lesson integrates a single particle: update velocity with force over dt, then position with the new velocity. The printed output afterwards shows the particle's steady fall - and later, the drift that motivates better integrators.

Textv(t+1) = v(t) + (f(t) / m) * dt      # velocity first
p(t+1) = p(t) + v(t+1) * dt           # position after
