About

Warren Toomey's 34-part series builds SubC: a compiler covering a large part of real C - all operators, basic types, struct, union, enum, typedef, varargs functions and even a simple preprocessor.

What you'll learn

  • A modern Pratt parser based on binding power for clean operator precedence
  • The full journey: lexer/parser/assembly in parts 1-5, pointers in 16-22, struct/union/enum in 23-28, varargs and preprocessor in 29-31
  • Every part ships tests that guarantee no regressions - like a real project

Core idea

The compiler builds a real C subset with a token-class lexer, then a parser using Pratt's binding-power method. Each part ends with x86-64 assembly output and tests.

C// operator precedence table
static struct { int token; int precedence; } binop_prec[] = {
    { T_PLUS,  10 }, { T_MINUS, 10 },   // add / subtract
    { T_STAR,  20 }, { T_SLASH, 20 },   // multiply / divide
    { T_EQ,    40 }, { T_NE,    40 },   // equality
};

// binary operator parsing (Pratt)
static struct ASTnode *binexpr(int ptp) {
    struct ASTnode *left = unary();
    while (op_precedence(Token.token) > ptp) {
        int tok = Token.token;
        left = mkastnode(A_BINOP, left, NULL, tok);
        scan(&Token);
    }
    return left;
}
