Write a System Call

⚙ Language: C 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Write a System Call"
↗ Visit the original tutorial فارسی — Persian version

About

Write your own Linux system call: define it with SYSCALL_DEFINEx, register it in the sys_call_table, copy the argument safely from user space with strncpy_from_user, then call it from a user program with syscall().

What you'll learn

  • User space vs kernel space and the syscall dispatch table
  • SYSCALL_DEFINE macros and safe copying from user memory
  • Invoking a custom syscall from C with syscall()

Core idea

A syscall is a number that indexes a function in the kernel's sys_call_table. Since data comes from user space, you must never copy without bounds checks - strncpy_from_user does it safely.

C// define a syscall accepting one string argument
SYSCALL_DEFINE1(hello, const char __user*, buffer) {
    char kernel_buf[128];
    ssize_t copied =
        strncpy_from_user(kernel_buf, buffer, sizeof(kernel_buf) - 1);
    if (copied < 0) {
        return -EFAULT;
    }
    kernel_buf[copied] = '\0';
    printk(KERN_INFO "hello syscall: %s\n", kernel_buf);
    return 0;
}

Why it matters

The boundary between your code and the OS becomes visible: one number, one table, and a lesson in kernel security.
