Creating a Roguelike Game in C#

⚙ Language: C# 📁 Game 🌐 English page 🔗 Original source
Original source: "Creating a Roguelike Game in C#"

About

RogueSharp is an open-source C# library for roguelike games handling the hard parts: dungeon map generation, field of view, pathfinding and line of sight. The tutorial combines RogueSharp v3 with RLNET; an older v2 covered MonoGame.

What you'll learn

  • Random dungeon generation with the RandomRooms creation strategy
  • Field of view with ComputeFov and the explored/visible cell distinction
  • Classic roguelike atmosphere: lit, dark-but-explored, and unknown cells

Core idea

Create the map, then compute FOV from the player's position; iterating cells lets you render lit, dim-explored or hidden tiles - the classic unknown-darkness feel without rewriting any FOV algorithm.

C#using RogueSharp;
using RogueSharp.MapCreation;

// build a map with a random dungeon generator (Rogue style)
IMapCreationStrategy<Map> strategy =
    new RandomRoomsMapCreationStrategy<Map>(
        width: 80, height: 50, maxRooms: 30,
        roomMaxSize: 12, roomMinSize: 6);
Map map = Map.Create(strategy);

// compute field of view from the player
map.ComputeFov(x: playerX, y: playerY, radius: 10, lightWalls: true);

// iterate: draw only visible or explored cells
foreach (Cell cell in map.GetAllCells()) {
  if (cell.IsInFov)       // lit - draw normally
  else if (cell.IsExplored) // dark but seen - draw dim
}

Why it matters

A ready-made toolbox for roguelike mechanics in C#: dungeon, FOV, pathfinding and line of sight without implementing them yourself.
