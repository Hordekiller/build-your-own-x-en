Build Your Own Shell using Rust

About

Build a shell in Rust step by step: read a line, run a command, then add arguments and a real loop.

What you'll learn

  • Reading input with stdin().read_line() and trimming the newline
  • Spawning processes with std::process::Command
  • Splitting whitespace into command and arguments

Core idea

A REPL loop reads a line, trims it, splits it into words, and spawns the command with its arguments via std::process::Command.

Rustfn main() {
    let mut input = String::new();
    stdin().read_line(&mut input).unwrap();

    let command = input.trim();   // read_line leaves a trailing newline

    Command::new(command).spawn().unwrap();
}
Rustlet mut parts = input.trim().split_whitespace();
let command = parts.next().unwrap();
let args = parts;

let mut child = Command::new(command)
    .args(args)
    .spawn()
    .unwrap();
child.wait();

Why it matters

Rust's Command API makes process spawning explicit and safe - the best language for a first from-scratch shell.
