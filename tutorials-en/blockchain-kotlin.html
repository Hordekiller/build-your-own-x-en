Let’s implement a cryptocurrency in Kotlin

About

A Kotlin cryptocurrency where blocks are declared as data classes and hashing is an extension function. The implementation keeps the core of a real blockchain — hashes, previous-hash links, timestamped blocks — in a very small amount of idiomatic code.

What you'll learn

  • Extension functions and data classes in Kotlin.
  • SHA-256 hashing via MessageDigest.
  • Modeling a block with immutable properties.
  • Chaining blocks by previous hash.

Core idea

Hashing is an extension on String, defaulting to the same algorithm Bitcoin uses:

kotlinimport java.math.BigInteger
import java.security.MessageDigest

// Extension function on String that returns the SHA-256 hash;
// the default algorithm is "SHA-256" (the same algorithm Bitcoin uses)
fun String.hash(algorithm: String = "SHA-256"): String {
    // create a MessageDigest instance with the requested algorithm
    val messageDigest = MessageDigest.getInstance(algorithm)
    // update the digest with the bytes of the string
    messageDigest.update(toByteArray())
    // ...
}

Kotlin's expressiveness shows how small a correct blockchain core can be. Immutable data classes make chain integrity a natural outcome of the type system.
