A Python Interpreter Written in Python

About

500 Lines chapter by Allison Kaptur (who worked on PyPy) builds byterun: an interpreter that reads .pyc bytecode files and runs them - no source text parsing at all.

What you'll learn

  • Four classes: VirtualMachine (main loop), Frame (code, locals, return stack), Function (with closure), Block (try/except and loop management)
  • Bytecode semantics: LOAD_FAST/STORE_FAST for locals, LOAD_GLOBAL, JUMP_ABSOLUTE
  • Function calls and returns through a stack of frames; functions as values with closures

Core idea

Each frame keeps an execution stack and an instruction pointer. The run loop dispatches opcodes: UNARY_/BINARY_ operations, LOAD_/STORE_ names, jumps, printing and return values.

Pythonclass VirtualMachine:
    def run_code(self, code, global_names=None, local_names=None):
        frame = self.make_frame(code, global_names, local_names)
        self.run_frame(frame)

    def run_frame(self, frame):
        while True:
            opname = frame.code.co_names[frame.next_instr]
            if opname.startswith('UNARY'):
                self.unaryOperator(opname[5:])   # UNARY_NEGATIVE, ...
            elif opname.startswith('BINARY'):
                self.binaryOperator(opname[6:])  # BINARY_ADD, ...
            elif opname.startswith('LOAD'):
                self.load_name(opname[4:])       # LOAD_FAST, ...
            elif opname.startswith('STORE'):
                self.store_name(opname[5:])      # STORE_FAST, ...
            elif opname == 'JUMP_ABSOLUTE':
                frame.next_instr = self.parse_arg_and_increment(frame)
            elif opname == 'PRINT_ITEM':
                print(self.pop(), end=' ')
            elif opname == 'RETURN_VALUE':
                return self.pop()
            frame.next_instr += 1
