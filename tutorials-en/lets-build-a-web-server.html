About

A three-part series (Ruslan's classic) that builds your own basic web server: from what a socket is, through parsing the request line and headers, to serving files, handling HTML forms and concurrency - finishing with HTTP client simulation and multi-threaded workers.

What you'll learn

  • Sockets over TCP/IP and a minimal HTTP handshake
  • Parsing the request line, headers and query strings
  • Concurrency: threads, thread pools and process pools

Core idea

A web server sits on a physical server, waits for a client request, produces a response and sends it back over HTTP. The very first version is ~15 lines: accept, read, and send a fixed response.

Python# webserver1.py - Python 3.7+
import socket

HOST, PORT = '', 8888
listen_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
listen_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
listen_socket.bind((HOST, PORT))
listen_socket.listen(1)
print(f'Serving HTTP on port {PORT} ...')

while True:
    client_connection, client_address = listen_socket.accept()
    request_data = client_connection.recv(1024)
    print(request_data.decode('utf-8'))

    http_response = b"""\
HTTP/1.1 200 OK

Hello, World!
"""
    client_connection.sendall(http_response)
    client_connection.close()
