About

A hands-on workshop in which docker is rebuilt from scratch, one kernel feature at a time — from fork/exec, through chroot, mount, PID and network namespaces, to a working image layer and Dockerfile.

What you'll learn

  • Building up Docker incrementally: fork, chroot, namespaces
  • Layered filesystems and image building mechanics
  • The Linux tools that power every container runtime
  • Running, listing and cleaning containers by hand

Core idea

The course is organized as levels, each adding exactly one piece of the puzzle:

Tests are physical: you verify isolation with your own eyes on the command line.

textdocs/                    <- preparation notes + linux module docs
levels/
  00_fork_exec/           <- level 0: fork and exec (the skeleton)
  01_chroot_image/        <- level 1: chroot (filesystem jail)
  02_mount_ns/            <- level 2: mount namespaces
shtouch /tmp/test
sudo chown 29311 /tmp/test
ls -lh /tmp/test
shsudo python3 rd.py run -i ubuntu -- /bin/bash

Why it matters

Learning Docker by rebuilding it turns a wall of concepts into a staircase of short, testable steps — the same philosophy that still powers the best systems education.
