About

Face recognition with FaceNet: embed faces into a 128-dimensional space and compare them, all inside a Docker container.

What you'll learn

  • The FaceNet model and pre-trained embeddings
  • Running the pipeline in Docker with CUDA-style setup
  • Comparing embeddings for verification and identification

Core idea

A pre-trained FaceNet graph converts each face into an embedding vector. Images are loaded in parallel with a queue - preprocessing on CPU, the network on GPU - so batches flow without stalling.

  -it colemurray/medium-facenet-tutorial \
  python3 medium_facenet_tutorial.py
