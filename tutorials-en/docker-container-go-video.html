Building a container from scratch in Go

⚙ Language: Go 📁 Docker 🌐 English page 🔗 Original source
Original source: "Building a container from scratch in Go — by Liz Rice"
↗ Visit the original tutorial فارسی — Persian version

About

The famous 35-minute talk in which Liz Rice builds a working container from scratch in Go — then tears it down, explaining every syscall as it happens.

What you'll learn

  • What a container actually is: processes in namespaces
  • Namespaces and cgroups as they are used in the wild
  • Building a run/child handoff with clone flags
  • Distinguishing containerization from virtualization

Core idea

The heart of the demo is a single fork where every isolation flag is set before the child even starts:

Go// the core of the container: run the child process in isolated namespaces
cmd := exec.Command("/proc/self/exe", "child")
cmd.SysProcAttr = &syscall.SysProcAttr{
	Cloneflags: syscall.CLONE_NEWUTS | // separate hostname
		syscall.CLONE_NEWPID |         // separate process tree
		syscall.CLONE_NEWNS | syscall.CLONE_NEWNET |
		syscall.CLONE_NEWIPC | syscall.CLONE_NEWUSER,
}

Why it matters

The definitive 'containers are just processes' talk — after it, you can explain container security and isolation in terms of actual kernel mechanics instead of metaphors.
