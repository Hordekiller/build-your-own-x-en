Creating a Simple Facebook Messenger AI Bot with API.ai in Node.js

⚙ Language: Node.js 📁 Bot 🌐 English page 🔗 Original source
Original source: "Creating a Simple Facebook Messenger AI Bot with API.ai" — a hands-on tutorial by Tomomi Imura that wires an Express webhook to the API.ai natural language service.

About

This tutorial builds a Messenger bot that understands natural language: Facebook posts incoming messages to your Express webhook, which forwards them to API.ai (now Dialogflow) for intent parsing, and sends the reply back to the user.

What you'll learn

  • Setting up a webhook with Express and verifying it with Facebook.
  • Using API.ai for natural language intent detection.
  • Sending structured messages back through the Messenger API.
  • The full request/response cycle of a chat platform bot.

Core idea

Only two dependencies are needed — the HTTP server and the request library:

bashnpm init
npm install express request --save

The heart of the bot is the webhook: verify it, then listen for messages:

js// app.js — Facebook Messenger bot with API.ai
const express = require('express');
const request = require('request');

const app = express();

// Page access token — from your Facebook app settings
const PAGE_ACCESS_TOKEN = 'your_page_token';
// Webhook verify token — the one you define yourself
const VERIFY_TOKEN = 'your_verify_token';

app.use(express.json());

// Webhook verification by Facebook
app.get('/webhook', (req, res) => { /* ... */ });

// Handle incoming messages
app.post('/webhook', (req, res) => { /* ... */ });

Why it matters

It demystifies the most common bot architecture: a plain HTTP endpoint plus a language API. Understanding webhooks, tokens and the request/response shape applies to Slack, Telegram and every other chat platform.
