Think like a programmer: How to build Snake using only JavaScript, HTML & CSS

About

This freeCodeCamp article teaches thinking like a programmer rather than just writing Snake: break the problem into pieces - representation, movement, eating, losing, scoring - and solve each in a few lines, all in one snake.html file.

What you'll learn

  • A snake as an array of [x, y] coordinates on a 20x20 grid
  • Movement as unshift + conditional pop - elegant growth with no extra code
  • Keyboard input guarded against instant 180-degree reversal

Core idea

Each step computes a new head, checks wall/self collisions, prepends the head, and pops the tail unless food was eaten; the grid is drawn cell by cell on a canvas.

JavaScript// snake: an array of [x, y]
let snake = [ [9, 9], [8, 9], [7, 9] ];
let direction = [1, 0];  // moving right
const CELL = 20; const GRID = 20;

function gameStep() {
  const head = snake[0];
  const newHead = [head[0] + direction[0], head[1] + direction[1]];
  // wall or self collision -> game over
  const hitWall = newHead[0] < 0 || newHead[0] >= GRID ||
                  newHead[1] < 0 || newHead[1] >= GRID;
  const hitSelf = snake.some(([x, y]) => x === newHead[0] && y === newHead[1]);
  if (hitWall || hitSelf) { gameOver(); return; }
  snake.unshift(newHead);
  if (newHead[0] === food[0] && newHead[1] === food[1]) {
    score++;
    food = randomFood();
  } else {
    snake.pop();   // no growth: drop the tail
  }
  draw();
}

setInterval(gameStep, 100);

Why it matters
