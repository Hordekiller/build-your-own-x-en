About

A video tutorial building a text editor in Python with tkinter - a Text widget, a save function and the classic file dialog flow.

What you'll learn

  • Laying out an editor with the tkinter Text widget
  • Wiring up save with filedialog
  • The minimal loop: type, edit, save

Core idea

The editor is a full-window tkinter Text widget. Save grabs the widget's contents and writes them to a file selected through the native file dialog.

Pythonimport tkinter as tk

app = tk.Tk()
text = tk.Text(app)                        # the text editing area
text.pack(fill="both", expand=True)

def save():
    with open("file.txt", "w") as f:
        f.write(text.get("1.0", "end"))

Why it matters

Tkinter is built into Python - this video gets you a working editor with zero dependencies, great for first editor projects.
