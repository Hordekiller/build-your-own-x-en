Building A Blockchain in Rust & Substrate

⚙ Language: Rust 📁 Blockchain / Cryptocurrency 🌐 English page 🔗 Original source
Original source: "Building A Blockchain in Rust & Substrate" — a Substrate workshop by Nicole Zhu that builds a Bitcoin-style UTXO runtime on substrate.
↗ Visit the original tutorial فارسی — Persian version

About

A hands-on workshop from Substrate's official documentation: build a UTXO-based blockchain runtime in Rust, modeled on Bitcoin but running inside the Substrate framework — with Node.js tooling for network setup and validation.

What you'll learn

  • Setting up a Rust + Substrate toolchain (rustup, targets, wasm).
  • UTXO (Unspent Transaction Output) model design.
  • Implementing the runtime with substrate modules.
  • Networking, consensus and testing with Substrate's tooling.

Core idea

Everything starts with the Rust toolchain — including the WebAssembly target that Substrate runtimes compile to:

shell# On Windows, download and run rustup-init.exe from https://rustup.rs instead

# On Mac:
curl https://sh.rustup.rs -sSf | sh
rustup update nightly
rustup target add wasm32-unknown-unknown --toolchain nightly
rustup update stable
cargo install --git https://github.com/alexcrichton/wasm-gc

Then the workshop code comes from the UTXO starter repo:

shellgit clone https://github.com/substrate-developer-hub/utxo-workshop.git
git fetch origin workshop:workshop
git checkout workshop
# [optional] after completing the installations of stage 1
# run the commands below to shorten future build times
cd /project_base_directory
cargo test -p utxo-runtime

Why it matters

Substrate is how production parachains are built, and this workshop shows the middle ground between toy chains and production systems: a Bitcoin-style ledger, as a runtime module, on real blockchain infrastructure.
