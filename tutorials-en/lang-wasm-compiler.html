Build your own WebAssembly Compiler

About

WebAssembly is a binary format for fast browser execution - the payoff of this tutorial is a runnable .wasm file you can execute in the browser immediately, no toolchain needed.

What you'll learn

  • The three classic stages: lexer, recursive-descent parser, and wasm bytecode generator
  • TypeScript to bytes: Active opcodes like i32.add and leb128 encoding
  • Loading and running the result in the browser with WebAssembly.instantiate

Core idea

The mini language has JavaScript-like syntax: integers, local variables, return and a main function. The interesting part is translating the AST to binary instructions - each node becomes opcodes; a function becomes a type section plus function body.

TypeScript// parse an expression: number, variable or function call
function parseExpression(): AstNode {
  const token = nextToken();
  if (token.type === "number") {
    return { kind: "number", value: Number(token.value) };
  }
  if (token.type === "identifier") {
    const next = peek();
    if (next.type === "lparen") {
      // function call
      nextToken();
      const args: AstNode[] = [];
      while (peek().type !== "rparen") {
        args.push(parseExpression());
        if (peek().type === "comma") nextToken();
      }
      nextToken();          // closing paren
      return { kind: "call", name: token.value, args };
    }
    return { kind: "var", name: token.value };
  }
  throw new Error("unexpected token: " + token.value);
}
TypeScript// produce bytecode for the main function
function emitFunction(name: string, params: number[], body: AstNode): Uint8Array {
  const bytes: number[] = [];
  // register the function type section
  const typeIdx = encodeL128(params.length);
  // body: emit the expression, then end-of-block
  emitExpression(body);
  bytes.push(0x0b);
  return new Uint8Array(bytes);
}

Why it matters

A great entry into browser-language compilers with instant feedback; the natural next project is a frontend for types, loops or bigger features.
