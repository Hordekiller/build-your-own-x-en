Ray Tracing in One Weekend

⚙ Language: C++ 📁 3D Renderer 🌐 English page 🔗 Original source
Original source: "Ray Tracing in One Weekend" by Peter Shirley — the most famous weekend-sized raytracer project, complete with source and free online book.

About

Peter Shirley's classic walks you through building a complete path tracer over a weekend: starting from an empty file that outputs a PPM image, and ending with a photorealistic scene full of reflective and refractive spheres. Every step is a small C++ file you can compile and run immediately.

What you'll learn

  • Writing images: the simple PPM file format, no libraries needed.
  • Building a vec3 class and a ray-traced color function.
  • A camera as position + viewport, with anti-aliasing by multi-sampling.
  • Diffuse, metal and dielectric materials.
  • Positionable cameras and depth-of-field.
  • Acceleration with bounding volume hierarchies (BVH).

Core idea

The first render is just a gradient written to stdout: for each pixel, map its coordinates to an RGB value and print the PPM header followed by the colors. From there each chapter adds exactly one concept.

cpp#include <iostream>

int main() {

    // Image
    int image_width = 256;
    int image_height = 256;

    // Render
    std::cout << "P3\n" << image_width << ' ' << image_height << "\n255\n";

    for (int j = 0; j < image_height; j++) {
        for (int i = 0; i < image_width; i++) {
            auto r = double(i) / (image_width-1);
            auto g = double(j) / (image_height-1);
            auto b = 0.0;

            int ir = int(255.999 * r);
            int ig = int(255.999 * g);
            int ib = int(255.999 * b);

            std::cout << ir << ' ' << ig << ' ' << ib << '\n';
        }
    }
}

Why it matters

It is the ideal first raytracer: minimal dependencies, tiny files, and a satisfying image after every section. The follow-up books in the series add motion blur, textures, lights, volumes and a final production scene — together they form the best-known path-tracing curriculum available.
