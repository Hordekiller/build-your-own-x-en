How Physics Engines Work

About

An illustrated explanation of how physics engines work under the hood - integrators, forces and the math of motion, before any code.

What you'll learn

  • Euler integration: the simplest force-to-motion path
  • Semi-implicit and average-acceleration improvements
  • Applying the same pattern to rotation (T = J times alpha)

Core idea

The core loop is three lines: acceleration from force and mass, velocity from acceleration, position from velocity. More accurate variants reevaluate acceleration at the new position and average the two values.

Text# the simplest integration: Euler's method
# force, acceleration, velocity, position are all vectors
acceleration = force / mass
velocity += acceleration * time_step
position += velocity * time_step
Textlast_acceleration = acceleration
position += velocity * time_step + (0.5 * last_acceleration * time_step**2)
new_acceleration = force / mass            # computed at the new position
avg_acceleration = (last_acceleration + new_acceleration) / 2
Text# rotation follows exactly the same pattern as translation:
alpha = torque / moment_of_inertia      # T = J * alpha
angularVelocity += alpha * time_step
angle += angularVelocity * time_step

Why it matters

Before writing a physics engine, you should know what an integrator is - this readable introduction provides exactly that foundation.
