GameBoy Emulation in JavaScript

About

GameBoy Emulation in JavaScript: a browser-based Game Boy, built up through the memory management unit, the Z80 registers, opcode execution and graphics.

What you'll learn

  • The MMU: read and write at two byte widths
  • The Z80's register bank and stack operations
  • Executing Game Boy opcodes in JavaScript
  • Bringing graphics to the canvas

Core idea

Everything flows through the memory management unit — one read/write convention:

jsMMU = {
    rb: function(addr) { /* read an 8-bit byte from the given address */ },
    rw: function(addr) { /* read a 16-bit word from the given address */ },

    wb: function(addr, val) { /* write an 8-bit byte to the given address */ }
    ...
js    // push registers B and C onto the stack (PUSH BC)
    PUSHBC: function() {
        Z80._r.sp--;                               // grow down in the stack
        MMU.wb(Z80._r.sp, Z80._r.b);               // write B
        Z80._r.sp--;
        MMU.wb(Z80._r.sp, Z80._r.c);               // write C
    },
js    reset: function() {
        Z80._r.a = 0; Z80._r.b = 0; Z80._r.c = 0; Z80._r.d = 0;
        Z80._r.e = 0; Z80._r.h = 0; Z80._r.l = 0; Z80._r.f = 0;
        Z80._r.sp = 0;
        Z80._r.pc = 0;      // start execution at 0
    }

Why it matters

An emulator that runs in your browser — the joy of games meets the joy of systems programming, and JavaScript turns out to be a perfectly capable host for hardware.
