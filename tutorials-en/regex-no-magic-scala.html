About

Regexes without magic in Scala: represent a pattern as an algebraic data type and match against it with pure functions.

What you'll learn

  • Describing patterns with a sealed RegexExpr ADT
  • The semantics table: dot, alternation, plus, star, grouping
  • Operator precedence: literals bind strongest, | binds weakest

Core idea

A regex is an expression: Literal(c), Or(e1, e2), Concat(a, b) and friends. Precedence rules - alternation weakest, literals and parentheses strongest - determine how a string parses into that tree.

// ., a, b

// a|b

Why it matters

An ADT for regexes makes matching a type-checked, self-explaining program instead of a pile of string hacks.
