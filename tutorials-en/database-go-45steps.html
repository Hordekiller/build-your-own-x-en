Code a database in 45 steps: a series of test-driven small coding puzzles

About

A database built puzzle by puzzle: 45 small, test-driven steps in Go, each one a self-contained challenge. You start from Go itself — its idioms — and work up through the storage engine until a database emerges, one verified step at a time.

What you'll learn

  • Go syntax and idioms (as the puzzles assume no prior Go).
  • Test-driven construction of each storage component.
  • File layout, encoding and on-disk structures.
  • Assembling parts into one working database.

Core idea

Step one is the language itself — reading code that uses Go's borrowings from C and Python, minus the ceremony:

go// if/else without parentheses
if a != c {
    // ...
} else {
    // ...
}
// switch does not fall through like C
switch a {
case 123:
    // ...
case 456:
    // ...
default:
    // ...
}

Variables declared where they are used, multi-value returns, and loops that cover every C pattern:

go// declare and use a variable inside if
if err := f(); err != nil {
    // ...
}
// loops
for i := 0; i < N; i++ {
    // ...
}
for {
    if xxx {
        break
    }
    if yyy {
        continue
    }
}
// multiple return values
func g() (string, bool) {
    return "hi", false
}
s, b := g()

Why it matters

Forty-five small wins beat one big wall. Each puzzle is verified by tests, so confidence compounds — a genuinely new way to teach database internals.
