About

Gooact: React in 160 lines of JavaScript — a compact implementation of components, setState, an internal instance tree, and a diff that keeps the DOM honest.

What you'll learn

  • React's instance model: element -> instance -> DOM node
  • setState as an update queue feeding re-renders
  • A diff that reuses DOM nodes when types match
  • The whole framework in a file you can print

Core idea
