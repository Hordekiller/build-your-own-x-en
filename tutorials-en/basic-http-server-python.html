Building a basic HTTP Server from scratch in Python

⚙ Language: Python 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Building a basic HTTP Server from scratch in Python"
↗ Visit the original tutorial فارسی — Persian version

About

Shows how to build a completely simple HTTP server from zero with Python sockets. Starts from the insight that HTTP is nothing but text - proven with telnet against real servers - then implements a full HTTP/1.0 server in about 20 lines.

What you'll learn

  • HTTP as raw text: request line, headers, blank line, body
  • Using telnet to speak HTTP by hand against google.com
  • A minimal socket-based HTTP/1.0 server loop

Core idea

In the first line you say which resource you want, then headers follow, then an empty line separates headers from the body. Type the text by hand in telnet and the server answers: it really is just text.

Pythonimport socket

SERVER_HOST = '0.0.0.0'
SERVER_PORT = 8000

server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
server_socket.bind((SERVER_HOST, SERVER_PORT))
server_socket.listen(1)
print('Listening on port %s ...' % SERVER_PORT)

while True:
    client_connection, client_address = server_socket.accept()
    request = client_connection.recv(1024).decode()
    print(request)

    response = 'HTTP/1.0 200 OK\n\nHello World'
    client_connection.sendall(response.encode())
    client_connection.close()

server_socket.close()

Why it matters

The shortest honest implementation of HTTP there is - perfect for proving to yourself that servers are not magic.
