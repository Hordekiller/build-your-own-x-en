Building a CDN from Scratch to Learn about CDN

About

Build a real, runnable CDN with OpenResty (Nginx plus Lua): edge nodes, caching, origin forwarding and smart invalidation - theoretical understanding and working config together.

What you'll learn

  • Edge nodes, caches and origin forwarding
  • Pull vs push caching and Cache-Control semantics
  • Lua scripts inside nginx.conf for cache logic

Core idea

Pull caching fetches content only when requested; HTTP headers like Cache-Control: max-age decide what is cachable and for how long. Nginx handles TLS, HTTP/2 and gzip while Lua runs the cache logic.

Lua-- check the cache and set headers
local cache_ttl = 3600   -- one hour

function handle_request(ngx)
    local status, headers, body = ngx.location.capture('/proxy_upstream')
    if status == ngx.HTTP_OK then
        ngx.shared.cache:set(ngx.var.uri, body, cache_ttl)
        ngx.header['Cache-Control'] = 'public, max-age=' .. cache_ttl
    end
    ngx.status = status
    ngx.say(body or 'error')
end

Why it matters

The distributed-system trick behind fast websites everywhere becomes one config file you control.
