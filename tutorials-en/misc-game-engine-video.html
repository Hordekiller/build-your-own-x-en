About

A long video series building a game engine from the first window to renderer: GLFW windowing, OpenGL, shaders, 3D math, textures and models - with live code and on-screen error fixing in every episode.

What you'll learn

  • Window setup with GLFW and vertex buffers (VBO)
  • Shaders and the graphics pipeline basics
  • 3D math, textures and model loading, step by step

Core idea

The first triangle - VBO + shader - fixes the entire graphics architecture of the engine; the series keeps building on exactly those foundations.

C++#include <glad/glad.h>
#include <GLFW/glfw3.h>

// vertex data for a triangle
float vertices[] = {
    -0.5f, -0.5f, 0.0f,
     0.5f, -0.5f, 0.0f,
     0.0f,  0.5f, 0.0f
};

GLuint vao, vbo;
glGenVertexArrays(1, &vao);
glGenBuffers(1, &vbo);
glBindVertexArray(vao);
glBindBuffer(GL_ARRAY_BUFFER, vbo);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), 0);
glEnableVertexAttribArray(0);

Why it matters

Watching errors get fixed live is the fastest way to build your own mental debugger for graphics code.
