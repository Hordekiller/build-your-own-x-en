About

Operating Systems: From 0 to 1 — a book-sized tutorial covering bootloaders, the GDT, and switching to 32-bit protected mode.

What you'll learn

  • Real mode and the first bytes executed at boot
  • The Global Descriptor Table and its descriptors
  • Switching from 16-bit to 32-bit mode safely

Core idea

The bootloader defines a minimal GDT in NASM — a null descriptor and a code descriptor with a 4 GB limit — so that the CPU has valid segments to jump into protected mode with.

nasm; bootloader os.asm — define the GDT and enter 32-bit mode
gdt_start:

gdt_null:              ; null descriptor (required)
    dd 0
    dd 0

gdt_code:              ; code segment descriptor
    dw 0xffff          ; limit
    dw 0x0000          ; base (low)

Why it matters

The jump from 16-bit to 32-bit mode is a rite of passage in OS development; this book explains every byte of it.
