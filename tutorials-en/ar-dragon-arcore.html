About

A practical, results-oriented tutorial: place an animated dragon in your room using Unity and ARCore. The video walks through importing an animated model, detecting a horizontal plane, tap-to-place and triggering the dragon's idle/roar animations in AR.

What you'll learn

  • Importing and setting up an animated 3D model in Unity.
  • Plane detection with AR Foundation and ARCore.
  • Placing the model with an AR raycast on tap.
  • Playing animations (idle, roar) via the Animator.

Core idea

The placement logic is the same pattern seen throughout ARCore tutorials — raycast, take the hit pose, spawn — with the fun twist of an animated creature:

C#// Place the dragon on a detected plane (Unity + AR Foundation)
public void OnPlaneHit(ARRaycastHit hit) {
    dragon.transform.position = hit.pose.position;   // ray's contact point
    dragon.transform.rotation = hit.pose.rotation;
    dragon.SetActive(true);                          // activate the model
}

Why it matters

Games and marketing demos both rely on placing animated characters in the real world. This tutorial shows the complete flow — model, plane, animation — in one bite-sized project, and its patterns transfer directly to any AR creature, robot or product demo.
