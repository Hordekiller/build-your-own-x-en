Learning how to write a 3D soft engine from scratch in C#, TypeScript or JavaScript

About

A ten-part tutorial series that builds a complete 3D software engine — no DirectX, no OpenGL, no Unity — writing every pixel yourself. The same engine is implemented three times: C# on Windows 8, and both TypeScript and JavaScript for the web, so you can follow in whichever language you prefer and even compare them side by side.

What you'll learn

  • Camera, meshes and their mathematical representation.
  • World, view and projection matrices — and how to combine them.
  • Rasterizing wireframe triangles, then filled ones.
  • The z-buffer for correct depth ordering.
  • Flat shading, Gouraud shading and the normal/light math behind them.
  • Rendering a full textured OBJ model, e.g. Suzanne the blender monkey.

Core idea

The project starts with the data model — a Camera and a Mesh holding vertices — then builds the transformation pipeline and the triangle fillers around them.

c#// Camera.cs and Mesh.cs
using SharpDX;

namespace SoftEngine
{
    public class Camera
    {
        public Vector3 Position { get; set; }
        public Vector3 Target { get; set; }
    }
    public class Mesh
    {
        public string Name { get; set; }
        public Vector3[] Vertices { get; private set; }
        public Vector3 Position { get; set; }
        public Vector3 Rotation { get; set; }

        public Mesh(string name, int verticesCount)
        {
            Vertices = new Vector3[verticesCount];
            Name = name;
        }
    }
}

Why it matters

This series is the classic bridge between "math class" and "video games": every matrix and vector gets a visible payoff on screen. Because three language versions are provided, it is also excellent for learning how renderer code translates across ecosystems.
