A cryptocurrency implementation in less than 1500 lines of code

About

Naivecoin is a complete, runnable cryptocurrency in JavaScript. It hashes with SHA-256, keeps balances via transactions and mining, and communicates between nodes over HTTP. The code is organized into small modules: blocks, chain, operator, miner, node and wallet.

What you'll learn

  • A modular architecture for a coin: chain, operator, miner, node.
  • Block hashing and the longest-chain rule.
  • Transactions, balances and a simple in-file database.
  • HTTP-based peer-to-peer communication.

Mining attaches to the longest chain, and every node validates what it receives — keeping the whole system honest with plain HTTP requests.

Why it matters

Reading a full working coin in 1500 lines is far more illuminating than any lecture: you see the trade-offs (a simple file-backed store), the network protocol, and exactly which parts of a real cryptocurrency are hard.
