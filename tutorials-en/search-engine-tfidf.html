About

Implementing tf-idf weighting and cosine similarity for a small document corpus, with a walkthrough of the math behind search ranking.

What you'll learn

  • Term frequency and inverse document frequency
  • Building numeric vectors from plain text documents
  • Ranking documents by similarity to a query

Core idea

Each word is weighted by its frequency inside the document (tf) and how rarely it appears across the corpus (idf). Documents then become vectors, and a query is matched by vector similarity.

Pythonfrom math import log
from collections import Counter

def tf(word, doc):
    # term frequency: occurrences of the word in the doc,
    # divided by the total number of words
    counts = Counter(doc.split())
    return counts[word] / sum(counts.values())
