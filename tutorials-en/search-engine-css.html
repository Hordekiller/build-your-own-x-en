A search engine in CSS

⚙ Language: CSS 📁 Search Engine 🌐 English page 🔗 Original source
Original source: "A search engine in CSS"

About

A playful experiment: building a tiny 'search engine' with pure CSS, where the page filters its contents without any JavaScript.

What you'll learn

  • Matching an input's current value with attribute selectors
  • Driving visibility purely from CSS matching
  • Seeing how layout engines evaluate such selectors

Core idea

When the input's value equals a term, a CSS rule matches the companion element and displays it - search implemented as a selector evaluation.

CSS/* if the input's current value is exactly 'tim', this rule activates */
input[value="tim" i] ~ p.tim {
  /* show the related element */
  display: block;
}

Why it matters

It is a delightful reminder that browsers are matching engines too - and it exposes the power of CSS attribute selectors.
