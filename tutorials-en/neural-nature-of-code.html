Core idea

A perceptron guesses by computing the weighted sum of its inputs and applying a step activation. Shiffman makes the training visible — you watch the decision boundary move as the weights update.

JavaScript// a simple perceptron in p5.js: weighted sum + step activation
function guess(inputs) {
  let sum = 0;
  for (let i = 0; i < inputs.length; i++) {
    sum += inputs[i] * this.weights[i];   // weighted sum of the inputs
  }
  return sum > 0 ? 1 : -1;
}
