0dmg: Learning Rust by building a partial Game Boy emulator

About

0dmg: Learning Rust by building a partial Game Boy emulator — a handful of assembled routines are traced opcode by opcode against a real Z80, bringing the CPU to life.

What you'll learn

  • Rust applied to systems programming with real purpose
  • Reading raw Z80 assembly alongside a full trace
  • How opcode handlers compose (LD, XOR, BIT, JR)
  • Deterministic debugging: the trace as your oracle

Core idea

The tutorial reads like a debug session — each opcode, its machine state, and the consequence:

log> 0x32: write the A register to the address pointed by HL; then decrement HL.

read opcode 0x32 at 0x7
  memory[HL] = A; HL -= 1
    memory[0xFF9F] = 0x0
      high_ram[0x1F] = 0x0
log> 0xCB7C: set the Z flag equal to the 7th bit of the H register.

read opcode 0xCB at 0x8
  setting Z flag to 7th bit of H register (true)
z80  LD SP,$fffe      ; $0000  Setup Stack
  XOR A            ; $0003  Zero the memory from $8000-$9FFF (VRAM)
  LD HL,$9fff      ; $0004
Addr_0007:
  LD (HL-),A       ; $0007
  BIT 7,H          ; $0008
  JR NZ, Addr_0007 ;

Why it matters

Rust's type system is an ally for emulator correctness — and tracing real boot code gives you the most satisfying 'it works' moment in systems programming.
