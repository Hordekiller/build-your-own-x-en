About

The training half of the F# network: gradient descent and backpropagation expressed with matrix operations.

What you'll learn

  • The weight update rule: w ← w − η × gradient
  • Backpropagating error from the output to hidden layers
  • Using the transposed weight matrix and the tanh derivative

Core idea

Training is a two-step dance: updateWeights() nudges every weight against the gradient scaled by the learning rate, and backpropagate() spreads the output error back through the layers using the transposed weight matrix.

fsharp// weight update: w <- w - eta * gradient of the error w.r.t. w
