Building a Custom React Renderer

About

Building a Custom React Renderer: a talk that goes inside react-reconciler and shows how to plug React into your own target by implementing just a handful of host methods.

What you'll learn

  • The host environment contract React requires
  • supportsMutation and the imperative host API
  • createContainer and updateContainer plumbing
  • React as a rendering substrate, not a DOM library

Core idea

The whole integration surface is a config object React hands off to:

js// entry point: build a reconciler with your own host functions
let reconciler = ReactReconciler({
  // mutation mode: our environment is like the DOM
  // (has appendChild and removeChild)
  supportsMutation: true,

  // build a node in the target environment
  createInstance(type, props, rootContainerInstance, ...) { ... },
  ...
});
jsconst root = reconciler.createContainer(domElement, false);
reconciler.updateContainer(<App />, root, null, () => console.log('render complete'));

Why it matters

Forty minutes to lift the curtain on react-reconciler — afterwards you can target React at anything: native, canvas, or a terminal TUI of your own design.
