About

Write yourself a Git!: wyag (Write Yourself a Git) implements init, add, commit, branch, checkout, log and track in Python — real Git's internal model made explicit.

What you'll learn

  • The .git layout: objects, refs, HEAD and the index
  • GitRepository and GitObject abstractions
  • Kat: how read, write, compress and hash objects work
  • A command surface that mirrors real git

Core idea

A repository is a directory with a contract — and a friendly class to create one:
