About

A proof-of-concept Docker imitation written in 100% Python: images, containers, builds and a CLI — a full docker-shaped toy you can read from end to end.

What you'll learn

  • Modeling Docker's object model in Python classes
  • A full command surface: run, images, build, attach
  • docopt-style CLI parsing and layered storage
  • How far a 'toy' implementation can genuinely go
