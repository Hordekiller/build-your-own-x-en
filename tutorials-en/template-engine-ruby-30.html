How to write a template engine in less than 30 lines of code

About

A 30-line template engine in Ruby that turns a view file with embedded Ruby code into a plain Ruby render function.

What you'll learn

  • ERB-style templates: %-lines that prefix Ruby code
  • Building the output string by appending template pieces
  • Code generation: assembling a function definition as a string

Core idea

The template is converted into Ruby source: lines starting with % are kept as code, everything else is wrapped into output << append operations. The generated function is then defined and called directly.

Ruby<html>
<body>
% if access == 0
   <div> no access :( </div>
% else
   <ul>
  % data.each do |i|
      <li>{{i}}</li>
  % end
   </ul>
% end
</body>
</html>
Rubydef render_index(access, data)
  output = ""                     # the output string
  output << "<html>"
  output << "<body>"

  if access == 0
     output << " no access :( "
Rubydef define_render_index()
  func = ""
  func << "def render_index(access, data) \n"
  func << "output = \"\" \n"
  func << "output << \"<html>\" 
"

Why it matters

Thirty lines that demystify every template language: your view is just a program that builds a string.
