About

BYTEPATH is a 15-part series building a complete space-shooter with a skill tree system - a mix of Bit Blaster XL and Path of Exile's passive tree. Aimed at programmers with some experience, with full code per part.

What you'll learn

  • Arcade-style player movement with acceleration and damping instead of fixed speed
  • A data-driven skill tree: nodes with owners, connections and effects
  • State management, UI and the full game-development workflow with LÖVE

Core idea

Player physics integrates acceleration with exponential damping; the skill tree stores node tables and ownership, letting players buy and connect upgrades that change real stats.

Luafunction Player:update(dt)
  -- physics with acceleration/damping
  local ms = self.stats.move_speed
  if input:down('left')  then self.vx = self.vx - ms * dt end
  if input:down('right') then self.vx = self.vx + ms * dt end
  if input:down('up')    then self.vy = self.vy - ms * dt end
  if input:down('down')  then self.vy = self.vy + ms * dt end
  -- damping: fade back to zero
  self.vx = self.vx * (1 - 0.5 * dt)
  self.vy = self.vy * (1 - 0.5 * dt)
  self.x = self.x + self.vx * dt
  self.y = self.y + self.vy * dt
end

Why it matters

One of the most complete LÖVE game tutorials, practicing ratios, systems, state management and UI together - the skill tree alone is a valuable project.
