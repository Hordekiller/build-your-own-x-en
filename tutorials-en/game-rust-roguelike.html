About

A famous series building a classic roguelike in Rust: ASCII grid, random dungeons, keyboard movement, field of view, pathfinding and monsters - translated from the Python/libtcod tutorial, per part on GitHub.

What you'll learn

  • Rust + tcod: Root initializer, Offscreen consoles and blitting
  • The main loop: render, flush, blocked key wait and state handling
  • A complete roguelike tutorial structure available on GitHub with setup docs

Core idea

The game holds a player, a map and consoles; render draws to an offscreen console which is blitted to the root and flushed; keys drive movement and rerun FOV.

Rustuse tcod::console::*;

struct Game {
    player: Player,
    map: Map,
}

fn main() {
    let mut root = Root::initializer()
        .font("arial10x10.png", FontLayout::Tcod)
        .font_type(FontType::Greyscale)
        .size(SCREEN_WIDTH, SCREEN_HEIGHT)
        .title("Roguelike in Rust")
        .init();

    let mut con = Offscreen::new(SCREEN_WIDTH, SCREEN_HEIGHT);
    let mut game = Game::new();

    while !root.window_closed() {
        // draw map and player onto con
        game.render(&mut con);
        blit(&con, (0, 0), (SCREEN_WIDTH, SCREEN_HEIGHT),
             &mut root, (0, 0), 1.0);
        root.flush();
        // input: recompute FOV on every move
        let key = root.wait_for_keypress(true);
        game.handle_key(key);
    }
}
