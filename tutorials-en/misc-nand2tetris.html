About

The NAND to Tetris course: build a complete computer from a single NAND gate all the way up to a Tetris-playing machine. Twelve projects across two tracks - hardware (gates to ALU to CPU to the HACK computer) and software (assembler, VM, Jack compiler, simple OS) - all running on the course's own simulator.

What you'll learn

  • HDL: describe chips from NAND up to ALU, CPU and RAM
  • The software stack: assembler, virtual machine and a Jack->VM->HACK compiler chain
  • A minimal operating system: memory manager, arithmetic and I/O

Core idea

Every project runs on the course simulator, independent of real hardware, so anyone - high school to professional - can build every layer. The layers connect: the Jack program you write is translated by the VM intermediary to HACK assembly and interpreted on the simulated CPU.

HDL// NOT gate built from NAND: out = not in
CHIP Not {
    IN in;
    OUT out;

    PARTS:
    Nand(a=in, b=in, out=out);
}

Why it matters

The only course that links all layers end-to-end - you see your own compiler's output execute on your own CPU.
