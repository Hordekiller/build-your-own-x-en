An Introduction to Convolutional Neural Networks

About

An introduction to convolutional networks with every layer built by hand in Python: Conv3x3, MaxPool2 and Softmax.

What you'll learn

  • How 3×3 convolution filters slide over images
  • Max pooling with 2×2 windows
  • A fully connected softmax layer for classification

Core idea

The tutorial builds each layer as a plain Python class. Conv3x3 applies learned filters, MaxPool2 downsamples, and Softmax turns the final activations into class probabilities — a full CNN forward pass in ~100 lines.

pythonimport numpy as np

class Conv3x3:
    # convolution layer with 3x3 filters

    def __init__(self, num_filters):
        self.num_filters = num_filters
        # filters: 3D array (num_filters, 3, 3)
pythonclass MaxPool2:
    # max pooling layer with a 2x2 window (no overlap)

    def forward(self, input):
        h, w, num_filters = input.shape
        output = np.zeros((h // 2, w // 2, num_filters))
pythonclass Softmax:
    # fully connected layer with softmax activation

    def __init__(self, input_len, nodes):
        self.weights = np.random.randn(input_len, nodes) / input_len
        self.biases = np.zeros(nodes)

Why it matters

Building the layers by hand — instead of importing them — makes convolutions, pooling and softmax genuinely obvious.
