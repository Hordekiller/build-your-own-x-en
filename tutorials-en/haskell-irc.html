Roll your own IRC bot

⚙ Language: Haskell 📁 Bot 🌐 English page 🔗 Original source
Original source: "Roll your own IRC bot" — the Haskell wiki's classic guide to writing an IRC bot from scratch in Haskell, from sockets to the protocol loop.
↗ Visit the original tutorial فارسی — Persian version

About

A step-by-step Haskell guide that connects to a real IRC network, speaks the IRC protocol line by line, and reacts to chat messages — ending with a working bot that responds to commands like a pong to a ping.

What you'll learn

  • Opening TCP sockets to an IRC server with the network package.
  • Reading raw IRC protocol lines (PING, PRIVMSG, 001…).
  • Parsing messages and dispatching replies.
  • Clean, functional bot loop design in Haskell.

Core idea

Everything starts with a socket and a string — the server, the port, and the lazy input stream the server sends back:

hs-- file 1.hs

import System.IO                      -- base library
import qualified Network.Socket as N  -- network package

-- configuration options
myServer = "irc.libera.chat" :: String
myPort   = 6667 :: N.PortNumber

-- Toplevel program
main :: IO ()
main = do
    h <- connectTo myServer myPort
    t <- hGetContents h
    hSetBuffering stdout NoBuffering
    print t

-- comment

Run it and the raw handshake sequence appears on screen — the exact bytes your bot must eventually parse and reply to:

shell   $ runhaskell 1.hs
   "NOTICE AUTH :*** Looking up your hostname...\r\nNOTICE AUTH :***
   Checking ident\r\nNOTICE AUTH :*** Found your hostname\r\n ...

Why it matters

IRC predates modern chat APIs and is a tiny, text-based protocol — ideal for learning real socket programming and network protocol handling without any libraries hiding the details.
