Writing a Simple Garbage Collector in C

⚙ Language: C 📁 Programming Language 🌐 English page 🔗 Original source
Original source: "Writing a Simple Garbage Collector in C"
↗ Visit the original tutorial فارسی — Persian version

About

Instead of raw malloc/free, this tutorial builds a small, efficient mark-and-sweep garbage collector in about 150 lines of C - exactly what real interpreters do.

What you'll learn

  • A linked list of blocks (map entries) with size, memory and mark flag
  • A global stack of roots with map_stack_push so the GC knows what is live
  • The pointer-to-pointer trick (map_entry_t**) for clean deletion from a linked list

Core idea

All allocated objects live in a linked list of blocks carrying metadata (size, real address, marked flag); allocation goes through map_alloc. The GC marks reachable objects from the root stack, then sweeps unmarked blocks. The author also notes this GC is "manual" (runs only when called) and real interpreters add conservative/exact scanning strategies.

Ctypedef struct map_entry {
    size_t size;          // block size
    char* memory;         // real memory
    struct map_entry* next;
    uint8_t marked;       // mark flag
} map_entry_t;

void gc_sweep(void) {
    map_entry_t** entry = &map.entries;  // pointer to head
    while (*entry) {
        map_entry_t* cur = *entry;
        if (!cur->marked) {              // garbage found
            *entry = cur->next;
            free(cur->memory);
            free(cur);
        } else {
            cur->marked = 0;             // reset for next cycle
            entry = &cur->next;
        }
    }
}

Why it matters

A compact C implementation that gives you full control over an interpreter's memory; a perfect starting point if you plan to build an interpreter or game engine.
