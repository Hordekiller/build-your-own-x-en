Implement your own — call(), apply() and bind() method in JavaScript

About

Implement call, apply and bind on Function.prototype yourself: myCall with spread arguments, myApply with an array, and myBind returning a bound closure - learning exactly how this works in JavaScript.

What you'll learn

  • Setting this by attaching the function to a context object
  • Symbol keys and globalThis fallback for edge cases
  • Closures in myBind: merging initial and later arguments

Core idea

The idea: call the function as a method of context. Use a unique Symbol key to avoid collisions, delete it afterwards, and fall back to globalThis when context is null.

JavaScript// myCall: invoke with a custom this and separate arguments
Function.prototype.myCall = function (context = globalThis, ...args) {
    const fnKey = Symbol('fn');
    context[fnKey] = this;
    const result = context[fnKey](...args);
    delete context[fnKey];
    return result;
};

// myBind: return a function bound to this
Function.prototype.myBind = function (context = globalThis, ...initialArgs) {
    const original = this;
    return function (...laterArgs) {
        return original.myCall(context, ...initialArgs, ...laterArgs);
    };
};

Why it matters

Three tiny methods that reveal the actual mechanics of this - the most misunderstood word in JavaScript.
