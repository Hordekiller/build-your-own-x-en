Let's Create a Simple Load Balancer

About

A load balancer in Go distributing requests across backends with round-robin, health checks and the standard httputil.ReverseProxy - everything a small production load balancer needs.

What you'll learn

  • Reverse proxy: rewriting requests to backend servers
  • Round-robin distribution with locking
  • Health checks and 503 behavior when all backends die

Core idea

Backends track an Alive flag; the round-robin counter moves through live servers under a mutex, and if none survive we must return 503 instead of nothing.

Gotype Server struct {
    URL           *url.URL
    Alive         bool
    ReverseProxy  *httputil.ReverseProxy
}

type LoadBalancer struct {
    servers []*Server
    current uint64
    mu      sync.RWMutex
}

func (lb *LoadBalancer) NextServer() *Server {
    lb.mu.Lock()
    defer lb.mu.Unlock()
    for i := 0; i < len(lb.servers); i++ {
        idx := int(lb.current) % len(lb.servers)
        lb.current++
        if lb.servers[idx].Alive {
            return lb.servers[idx]
        }
    }
    return nil
}

Why it matters

Scaling out is a solved, readable ~100-line problem - the same shape behind the biggest web companies.
