Command line apps in Rust

⚙ Language: Rust 📁 Command-Line Tool 🌐 English page 🔗 Original source
Original source: "Command line apps in Rust" — the official rust-cli book by Pascal Hertleithner and the Rust community: a full guide from first hello to published CLI applications.

About

The definitive free book for Rust CLIs. It builds grrs — a grep clone — while covering the whole journey: argument parsing, reading files, error handling with anyhow, testing, packaging, and publishing to crates.io.

What you'll learn

  • Parsing arguments with clap.
  • Reading stdin and files, streaming and error handling.
  • Writing tests for CLI behavior.
  • Packaging, publishing and distributing binaries.

Core idea

The goal is set on the very first page — a tool that searches a file for a pattern, used exactly like grep:

shell$ cat test.txt
foo: 10
bar: 20
baz: 30
$ grrs foo test.txt
foo: 10
$ grrs --help
[some help text explaining the available options]

And the starting point is a fresh cargo binary:

shell$ cargo new grrs
     Created binary (application) `grrs` package
$ cd grrs/
$ cargo run
   Compiling grrs v0.1.0
   Running `target/debug/grrs`
Hello, world!

Why it matters

It is the rare book that covers both the happy path and the release path — testing, publishing, and shipping binaries — which is exactly where most CLI projects quietly die.
