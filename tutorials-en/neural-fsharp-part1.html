About

Building neural networks in F#: model the network's math with immutable types and vectors, using Math.NET Numerics.

What you'll learn

  • Type-driven design: Node, Layer and NodesVect types that mirror the math
  • Random initialization of weights and biases
  • Composing layers into a feed-forward network

Core idea

The network's structure is encoded directly in the types: a Layer is a list of Nodes, and each Node carries a vector of values. Creating a layer is then a one-liner that builds n neurons with random weights.

fsharp// types that give the network's math its meaning
type Node<'a> = { Values: Vector<'a> }
type Layer<'a> = { Nodes: List<Node<'a>> }
type NodesVect<'a> = { Nodes: Vector<'a> }
fsharp// create a layer with n neurons; each neuron is a vector of values
let createLayer (n: int) (size: int) =
    { Nodes = [ for _ in 1 .. n -> { Values = Vector.Build.Random(size) } ] }

Why it matters

F#'s type system lets the compiler check the shape of your network — a rare guarantee for machine-learning code.
