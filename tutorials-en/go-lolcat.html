Build a command line app with Go: lolcat

⚙ Language: Go 📁 Command-Line Tool 🌐 English page 🔗 Original source
Original source: "Build a command-line app with Go: lolcat" — Flavio Copes rebuilds the beloved lolcat (rainbow-colored text) as a Go CLI, reading stdin and printing ANSI colors.

About

The fun one: reimplement lolcat — the tool that colors every line of text in a rainbow — in Go. You read from standard input, iterate over the text, and emit ANSI color codes, one character at a time.

What you'll learn

  • Reading piped stdin in Go.
  • Generating random content with the faker library.
  • ANSI escape sequences and terminal colors.
  • Iterating over strings and runes safely.

Core idea

For a demonstration of the rainbow effect, the tutorial even generates its own input with a fake-hacker-phrases library:

shellgo get -u github.com/enodata/faker
gopackage main

import (
    "fmt"
    "strings"

    "github.com/enodata/faker"
)

func main() {
    var phrases []string

    for i := 1; i < 3; i++ {
        phrases = append(phrases, faker.Hacker().Phrases()...)
    }

    fmt.Println(strings.Join(phrases[:], "; "))
}

Why it matters

ANSI colors and stdin pipelines are the everyday texture of the Unix command line; building lolcat makes both tangible — and the result is a delightful tool you'll keep in your PATH.
