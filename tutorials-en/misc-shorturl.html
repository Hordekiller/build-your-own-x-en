Writing a URL Shortening Service

About

A URL shortener: incremental IDs from a Redis counter encoded in Base62 (a-z, A-Z, 0-9) produce short codes like abc123, and GET /<code> issues a 301 redirect to the original URL.

What you'll learn

  • Base62 encoding: numbers to short, ordered codes
  • Redis INCR for atomic counters and short:code mappings
  • Why 301 redirects matter for SEO

Core idea

With 7 characters, 62^7 is about 3.5 trillion links. 301 is a permanent redirect: search engines understand the content moved and transfer page rank.

Nimconst Alphabet = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789"

proc toBase62(num: int): string =
  var n = num
  while n > 0:
    result.add(Alphabet[n mod 62])
    n = n div 62
  result.reverse()   # least significant digit last

proc fromBase62(code: string): int =
  for c in code:
    result = result * 62 + Alphabet.find(c)
