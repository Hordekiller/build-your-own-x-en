Build your own blockchain: a Python tutorial

About

Eric Munsing's tutorial builds a blockchain the way a researcher would: first a deterministic hash function, then transactions, then blocks, and finally a real peer-to-peer network where nodes gossip the newest block. Every piece is tested as you go.

What you'll learn

  • A simple, deterministic SHA-256 wrapper.
  • Transaction generation with mathematical validity built in.
  • Block templates and a chain that recomputes hashes.
  • Connecting to a live node mesh with Flask and requests.

Core idea

It all leans on one helper — determinism is the whole game:

pyimport hashlib, json, sys

def hashMe(msg=""):
    # for convenience, this is a helper function that wraps our hash algorithm
    if type(msg)!=str:
        msg = json.dumps(msg,sort_keys=True)  # if we don't sort the keys, reproducibility is not guaranteed!

    if sys.version_info.major == 2:
        return unicode(hashlib.sha256(msg).hexdigest(),'utf-8')
    else:
        return hashlib.sha256(str(msg).encode('utf-8')).hexdigest()

Transactions are generated so they always satisfy the conservation of money:

pyimport random
random.seed(0)

Why it matters

The disciplined, step-by-step approach — with a test after every step — and the counterintuitive live demo (peers in a mesh that agree by gossip) make this one of the most instructive blockchain introductions for programmers.
