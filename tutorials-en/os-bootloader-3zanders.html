Writing a Bootloader

⚙ Language: C++ 📁 Operating System 🌐 English page 🔗 Original source
Original source: "Writing a Bootloader"
↗ Visit the original tutorial فارسی — Persian version

About

Writing a bootloader: set up the GDT, switch to protected mode, and jump into C++ kernel code.

What you'll learn

  • Loading the GDT with lgdt and enabling protected mode
  • The far jump that flushes the CPU pipeline
  • Building and running the result with make and QEMU

Core idea

The bootloader loads the GDT, sets bit 0 of cr0, and performs a far jump into 32-bit code — a jump that also clears the pipeline. From there, the kernel runs in protected mode.

nasm; enter protected mode
lgdt [gdt_descriptor]
mov eax, cr0
or eax, 1
mov cr0, eax

jmp 0x08:protected       ; far jump: fully reload the segment registers

[bits 32]
protected:
bash# build the bootloader and kernel, then run
make
qemu-system-i386 -fda os.img

Why it matters

The switch into protected mode is where real mode ends and modern OS code begins — and this tutorial draws that line clearly.
