How to Make Flappy Bird in HTML5 With Phaser

⚙ Language: JavaScript 📁 Game 🌐 English page 🔗 Original source
Original source: "How to Make Flappy Bird in HTML5 With Phaser"
↗ Visit the original tutorial فارسی — Persian version

About

Thomas Palef (of lessmilk.com) wrote a simple Flappy Bird with Phaser 2.4 in just 65 lines of code, explained step by step: gravity, jump on click, moving pipes and collision.

What you'll learn

  • Phaser states, sprites and the Arcade physics system
  • Gravity + one impulse for the jump; a repeating timer spawning pipe rows
  • Scoring and restart-on-death for the full game feel

Core idea

Everything lives in one main state: preload loads assets, create sets gravity and pipes, update checks overlap, jump applies an upward impulse, addRowOfPipes spawns a random pipe row moving left.

JavaScriptvar game = new Phaser.Game(400, 490, Phaser.AUTO, 'gameDiv');

var mainState = {
  preload: function() {
    game.load.image('bird', 'assets/bird.png');
    game.load.image('pipe', 'assets/pipe.png');
  },
  create: function() {
    game.physics.startSystem(Phaser.Physics.ARCADE);
    this.bird = game.add.sprite(100, 245, 'bird');
    game.physics.arcade.enable(this.bird);
    this.bird.body.gravity.y = 1000;
    var spaceKey = game.input.keyboard.addKey(Phaser.Keyboard.SPACEBAR);
    spaceKey.onDown.add(this.jump, this);
    this.pipes = game.add.group();
    this.timer = game.time.events.loop(1500, this.addRowOfPipes, this);
    this.score = 0;
    this.labelScore = game.add.text(20, 20, "0", { font: "30px Arial", fill: "#fff" });
  },
  update: function() {
    game.physics.arcade.overlap(this.bird, this.pipes, this.restartGame, null, this);
    if (this.bird.y < 0 || this.bird.y > 490) this.restartGame();
  },
  jump: function() { this.bird.body.velocity.y = -350; },
  addRowOfPipes: function() {
    var hole = Math.floor(Math.random() * 5) + 1;
    for (var i = 0; i < 10; i++) {
      if (i != hole && i != hole + 1) {
        var pipe = game.add.sprite(400, i * 49, 'pipe');
        game.physics.arcade.enable(pipe);
        pipe.body.velocity.x = -200;
        pipe.checkWorldBounds = true;
        pipe.outOfBoundsKill = true;
        this.pipes.add(pipe);
      }
    }
    this.score++;
    this.labelScore.text = this.score;
  },
  restartGame: function() { game.state.start('main'); }
};

game.state.add('main', mainState);
game.state.start('main');

Why it matters

Just open index.html and play: a complete Flappy Bird in one tiny file, the fastest possible introduction to Phaser.
