About

Implement a neural network from scratch in pure Python and numpy, with hand-drawn diagrams of every gradient.

What you'll learn

  • Mean-squared-error loss and the chain rule
  • Computing gradients for every weight and bias by hand
  • Training a tiny network over 1,000 epochs

Core idea

After defining the MSE loss, the tutorial computes every gradient by hand using the chain rule — then turns those formulas into code and trains the network for 1,000 epochs to fit a tiny dataset.

python# a single neuron's output: sum(input * weight) + bias
def output(self, inputs):
    total = np.dot(self.weights, inputs) + self.bias
    return total   # no activation (regression)
python# mean squared error loss

def mse_loss(predictions, targets):
    return np.mean((predictions - targets) ** 2)
