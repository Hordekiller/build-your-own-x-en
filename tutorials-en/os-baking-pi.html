Baking Pi – Operating Systems Development

About

Baking Pi: build an operating system for the Raspberry Pi from bare metal — cross-compiler, kernel.img, GPIO and ARM assembly.

What you'll learn

  • Setting up the ARM cross-compiler (arm-none-eabi)
  • Building a bootable kernel.img with the OS template Makefile
  • Controlling GPIO to light the ACT LED

Core idea

After installing the cross-compiler, the project template builds a kernel.img with make. The first lesson writes main.s — ARM assembly that configures GPIO and turns the board's OK/ACT LED on.

bash# install the ARM cross-compiler for the Raspberry Pi (older ARMv6)
sudo apt install gcc-arm-none-eabi binutils-arm-none-eabi

# build the project with the OS Template Makefile
make        # output: kernel.img, kernel.list, kernel.map
arm// main.s — turn on the OK/ACT LED on the Raspberry Pi (ARMv6)
.section .init          // this section runs first
.global _start

_start:
    ldr r0, =0x20200000  // base address of the GPIO controller
    mov r1, #1           // set bit 16 (pin 16)

Why it matters

It is the gentlest possible way onto real hardware: your first kernel runs on a physical ARM chip and lights a real LED.
