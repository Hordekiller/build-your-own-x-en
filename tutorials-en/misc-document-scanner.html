How to Build a Kick-Ass Mobile Document Scanner in Just 5 Minutes

About

A mobile document scanner in four steps with OpenCV: find the paper's edges, extract its corners, apply a perspective transform for skewed photos, and improve the image with grayscale/thresholding - about 30 readable lines.

What you'll learn

  • Edge detection and the largest contour as the paper
  • approxPolyDP corner approximation (4 sides = paper)
  • Perspective warp to a perfect rectangle + thresholding

Core idea

The pipeline: grayscale, blur, Canny edges, findContours, take the largest contour, approximate its corners, order them top-left/top-right/bottom-right/bottom-left - then warpPerspective to an A4 rectangle.

Pythonimport cv2
import numpy as np

def find_document(image):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (5, 5), 0)
    edged = cv2.Canny(blur, 75, 200)
    cnts, _ = cv2.findContours(edged.copy(),
                               cv2.RETR_LIST, cv2.CHAIN_APPROX_SIMPLE)
    cnt = max(cnts, key=cv2.contourArea)   # largest contour = paper
    peri = cv2.arcLength(cnt, True)
    approx = cv2.approxPolyDP(cnt, 0.02 * peri, True)
    return approx if len(approx) == 4 else None

Why it matters

The '5-minute' scanner is exactly this: edge detection, corners, warp, threshold - all in your own hands.
