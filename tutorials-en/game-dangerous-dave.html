About

A playlist rebuilding Dangerous Dave - John Romero's classic 1988 DOS platformer - in C with near-identical graphics: 16x16 sprites, movement, gravity, item collection, enemies, jumping and multiple levels.

What you'll learn

  • Tile-based level representation and the fixed game loop
  • Player physics: gravity, horizontal movement and tile collisions
  • Simple enemy AI and multi-level management from files

Core idea

The level is a tile grid; the loop processes input, updates player physics against tiles, updates monsters and items, then renders sprite buffers.

C#define TILE_EMPTY 0
#define TILE_BLOCK 1
#define TILE_LADDER 2

typedef struct {
  int tile[ROWS][COLS];        // level map
  Player player;
  Monster monsters[MAX_MONSTERS];
  Item items[MAX_ITEMS];
} Level;

// main loop: input -> physics update -> render
void game_loop(void) {
  while (running) {
    handle_input();
    // gravity, horizontal movement, tile collisions
    update_player(&level.player, &level);
    update_monsters(&level);
    render(&level);      // draw sprites to the buffer
    swap_buffers();
    delay_frame();
  }
}

Why it matters

One of the most fun ways to build your first complete game: a famous title, simple expandable code, then move on to more complex games with the same structure.
