How Regexes Work

About

How regexes work, from the Perl side: parse the pattern into an AST, compile it to an NFA, and execute the machine.

What you'll learn

  • The parse, compile, execute pipeline
  • Translating a regex into a nondeterministic automaton
  • Using the compiled machine from Perl

Core idea

The pipeline is three calls: parse the string into a syntax tree, compile the tree into a machine, and run the machine against text. A tiny Perl wrapper then applies it line by line.

Perl	use Regex;

	$regex    = Regex->parse('ab+');    # parse the string
	$machine  = NFA->compile($regex);   # build the machine
	$result   = NFA_Exec->match($machine, 'abbbbb'); # run the pennies
Perl	while (<>) {
	  print if /$./;
	}

Why it matters

Connecting regex syntax to an executable automaton in one short pipeline removes every trace of regex magic.
