Creating a Linux Desktop application with Ruby

⚙ Language: Ruby 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Creating a Linux Desktop application with Ruby"
↗ Visit the original tutorial فارسی — Persian version

About

A complete GTK todo list app in Ruby: window, input, buttons and a list box wired together with signals - showing how every desktop toolkit's event loop works.

What you'll learn

  • The GTK event loop: widgets reacting to events
  • signal_connect callbacks (clicked, activate, destroy)
  • Widgets + signals + model: the desktop app skeleton

Core idea

GTK apps wait in an event loop reacting to clicks, typing and closes. Signal connections are callbacks - the same mechanism in Qt and Swing; pressing Enter and clicking the button both call add_todo.

Rubyrequire 'gtk3'

class TodoApp
  def initialize
    @window = Gtk::Window.new("todo list")
    @window.set_default_size(400, 500)
    @window.signal_connect('destroy') { Gtk.main_quit }

    @vbox = Gtk::Box.new(:vertical, 6)
    @entry = Gtk::Entry.new
    @entry.placeholder_text = 'new task...'
    @add_button = Gtk::Button.new(label: 'add')
    @list = Gtk::ListBox.new

    @vbox.pack_start(@entry, expand: false, fill: false, padding: 0)
    @vbox.pack_start(@add_button, expand: false, fill: false, padding: 0)
    @vbox.pack_start(@list, expand: true, fill: true, padding: 0)
    @window.add(@vbox)

    @add_button.signal_connect('clicked') { add_todo }
    @entry.signal_connect('activate') { add_todo }
  end

  def add_todo
    text = @entry.text.strip
    return if text.empty?
    row = Gtk::ListBoxRow.new
    row.add(Gtk::Label.new(text))
    @list.add(row)
    @entry.text = ''
  end

  def run
    @window.show_all
    Gtk.main
  end
end

Why it matters

The event-loop model behind every GUI framework, in a widget you can add to, delete from and restyle.
