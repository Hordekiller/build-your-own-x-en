About

This video builds a simple interpreted language in Python, from basic statements (assignments, loops, conditionals) to running real examples - ideal when you want a quick visible result.

What you'll learn

  • The three components: lexer (text to tokens), parser (tree/sequence), evaluator (execution)
  • A simple env as a dict; focus on errors for a useful interpreter
  • Watch live coding, then read the lsbasi series for depth

Core idea

The evaluator dispatches on node type: assignments store into env, print evaluates and prints, if and while run statement lists conditionally.

Pythondef execute(node, env):
    if node['type'] == 'assign':      # a = 5
        env[node['name']] = eval_expr(node['value'], env)
    elif node['type'] == 'print':     # print expr
        print(eval_expr(node['value'], env))
    elif node['type'] == 'if':        # if cond: ...
        if eval_expr(node['cond'], env):
            for stmt in node['body']:
                execute(stmt, env)
    elif node['type'] == 'while':     # while cond: ...
        while eval_expr(node['cond'], env):
            for stmt in node['body']:
                execute(stmt, env)

Why it matters

The fastest way to see what an interpreter does: follow the live coding, then build your own small language; seeing code take shape beats any dry text.
