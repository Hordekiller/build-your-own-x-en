About

A search engine in PHP, two phases: indexing breaks documents into tokens and builds the inverse map word -> documents in SQLite, queries look words up and return the documents containing them all.

What you'll learn

  • Tokenisation and stop-word removal
  • The inverted index: words, documents and a link table with counts
  • Simple TF ranking with JOINs

Core idea

Two tables plus a link table (word_id, doc_id, count) is the inverted index - the same transparent format commercial engines compress.

PHPfunction tokenise($text) {
    // split into words (keeping case)
    $words = str_word_count(strtolower($text), 1);
    // remove stop words like 'the', 'and', 'for'
    $stop = ['the', 'and', 'for', 'php'];
    return array_diff($words, $stop);
}

foreach ($documents as $doc) {
    $docId = insertDocument($db, $doc['url'], $doc['title']);
    foreach (tokenise($doc['body']) as $word) {
        $wordId = getOrCreateWord($db, $word);
        incrementLink($db, $wordId, $docId);
    }
}

Why it matters

Google's core is one table shape: the inverted index - search understood at its foundation.
