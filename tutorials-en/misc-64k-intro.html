How a 64k intro is made

⚙ Language: C++ 📁 Web Server 🌐 English page 🔗 Original source
Original source: "How a 64k intro is made"
↗ Visit the original tutorial فارسی — Persian version

About

The demoscene's 64KB intro challenge: fit a complete 3D scene, music and animation into 64 kilobytes. The secrets are procedural generation (models, textures and sound created at runtime) and extreme compression of the final file.

What you'll learn

  • Procedural generation instead of pre-made assets
  • GLSL shaders as the heart of the scene (ray marching)
  • Crinkler-class packers that rebuild the executable

Core idea

Much of the graphics is produced by fragment shaders: a full image out of one loop. Models are stored as descriptive commands (counts and positions), music as tiny tracker data, and the whole file is compressed with a packer that also reconstructs the main executable.

GLSL#version 330 core
out vec4 frag_color;
uniform vec2 u_resolution;
uniform float u_time;

void main() {
    vec2 uv = (gl_FragCoord.xy - 0.5 * u_resolution) / u_resolution.y;
    // a simple wave moving with time - and a colorful pattern
    vec3 color = vec3(uv.x, uv.y, 0.5 + 0.5*sin(u_time));
    color += vec3(uv.x*uv.y)*0.5;
    frag_color = vec4(color, 1.0);
}

Why it matters

Extreme constraints teach the difference between 'data' and 'instructions' - the most compact thinking in programming.
