Writing a Redis Protocol Parser

⚙ Language: Nim 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Writing a Redis Protocol Parser"
↗ Visit the original tutorial فارسی — Persian version

About

Parse the RESP protocol - the text-binary language between Redis clients and servers - in Nim: simple strings (+), errors (-), integers (:), bulk strings ($) and arrays (*), with CRLF terminators.

What you'll learn

  • RESP prefixes and message structure
  • Parsing bulk strings by length and arrays of values
  • Nim's variant objects for typed protocol values

Core idea

:1000\r\n is the integer 1000; $5\r\nhello\r\n is a 5-char bulk string; *2\r\n...\r\n... is an array of two values. The main loop dispatches on the first byte.

Nimimport strutils

# one value type for every RESP kind
type RespValue = object
  case kind: enum
  of rSimple: s: string
  of rError:  e: string
  of rInt:    i: int
  of rBulk:   b: string
  of rArray:  items: seq[RespValue]

# parse bulk string: $len\r\n<payload>\r\n
proc parseBulk(data: seq[string], idx: var int): RespValue =
  let len = parseBiggestInt(data[idx]); inc idx
  if len == -1: return RespValue(kind: rBulk, b: "")
  result = RespValue(kind: rBulk, b: data[idx])
  inc idx

Why it matters

Protocols for the real world: a text-binary wire format with a typed parser in a Python-speed language.
