Build a simple 2D physics engine for JavaScript games

⚙ Language: JavaScript 📁 Physics Engine 🌐 English page 🔗 Original source
Original source: "Build a simple 2D physics engine for JavaScript games"

About

Learn how to write a small JavaScript game physics engine from scratch, with gravity, movement, collisions and a clean separation between the physics model and the renderer.

What you'll learn

  • A game loop that steps the physics model independently of drawing
  • Kinematic integration: acceleration changes velocity, velocity changes position
  • Simple ground collision with energy loss (restitution)

Core idea

The engine separates simulation from rendering: every frame it advances the physics model, then draws the result. Movement is basic integration, and colliding with the floor bounces the body back with a restitution factor.

JavaScript// game loop: step the model each frame, then draw
function gameLoop() {
    physics.step(dt);   // physics: the model
    renderer.draw();    // drawing: the view
    requestAnimationFrame(gameLoop);
}
JavaScript// update the kinematics of a body
function integrate(body, dt) {
    body.velocityY += GRAVITY * dt;      // gravity acceleration
    body.x += body.velocityX * dt;       // displacement
    body.y += body.velocityY * dt;
}
JavaScript// collide with the ground: bounce upward, losing energy
function collideWithGround(body) {
    if (body.y + body.radius > floorY) {
        body.y = floorY - body.radius;
        body.velocityY *= -RESTITUTION;
    }
}

Why it matters

A working physics loop is the backbone of every 2D game - this is the minimal mental model to build or debug one.
