Let's Build a Simple Database

⚙ Language: C 📁 Database 🌐 English page 🔗 Original source
Original source: "Let's Build a Simple Database" — Connor Stack's monumental tutorial that reimplements SQLite from scratch in C: a REPL, B-trees, pager and cursor step by step.

About

Part 1 of a thirteen-part series that builds a full SQLite-style database in C. It starts with the user experience — a REPL that talks like the real sqlite3 — then goes deep: tables, the binary file format, B-trees, paging and cursors.

What you'll learn

  • Building a REPL with read/print/loop structure.
  • Parsing SQL-like statements (insert, select).
  • Representing rows in persistent byte layouts.
  • Page caching, B-trees and cursor abstractions.

Core idea

The sqlite3 experience is the specification — here is the reference behavior:

shell~ sqlite3
SQLite version 3.16.0 2016-11-04 19:09:39
Enter ".help" for usage hints.
sqlite> create table users (id int, username varchar(255), email varchar(255));
sqlite> .tables
users
sqlite> .exit
~

And the first code is the classic REPL loop, with an exit path:

cint main(int argc, char* argv[]) {
  InputBuffer* input_buffer = new_input_buffer();
  while (true) {
    print_prompt();
    read_input(input_buffer);

    if (strcmp(input_buffer->buffer, ".exit") == 0) {
      close_input_buffer(input_buffer);
      exit(EXIT_SUCCESS);
    } else {
      printf("Unrecognized command '%s'.\n", input_buffer->buffer);
    }
  }
}

Why it matters

This is the canonical "build your own database" resource. Twelve more parts take the REPL to B-tree indexes and a persistent engine — the best possible preparation for understanding real databases.
