About

The follow-up to "Write Yourself a Scheme in 48 Hours": a complete functional language compiler with Hindley-Milner types, type classes, desugaring and final execution by translation to C.

What you'll learn

  • The Hindley-Milner type system: substitution, unification and the Robinson algorithm
  • Type classes and instance resolution; monomorphism
  • Backend: translating the Core language to C with heap management and a mark-and-sweep GC

Core idea

The book spans 14 chapters: parsing with Parsec, AST with pattern matching, a Core intermediate language, the type system, type classes, desugaring, and a code generator that compiles Core to C.

Haskelltype Subst = Map.Map TVar Type

-- unify: make two types equal via substitution
unify :: Type -> Type -> Subst -> Either String Subst
unify (TAp l r) (TAp l' r') s = do
    s1 <- unify l l' s
    s2 <- unify r r' s1
    return s2
unify (TVar a) t s = bind a t s
unify t (TVar a) s = bind a t s
unify TInt  TInt  s = return s
unify TBool TBool s = return s
unify t1 t2 _ = Left ("type mismatch: " ++ show t1 ++ " vs " ++ show t2)

Why it matters

An advanced but extraordinary resource for functional compilers: Hindley-Milner typing, the unification algorithm, type classes and translation to an intermediate language, all in practice.
