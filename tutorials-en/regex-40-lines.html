About

A regular expression engine in 40 lines of Python, written one function at a time from matchOne() up to quantifiers.

What you'll learn

  • The unfolding approach: start with single-character matching
  • Combining matchOne with star and question-mark semantics
  • Half-understanding regex by reimplementing its core

Core idea

The tutorial grows the engine from a single matchOne(pattern, text) function. Its table of regex semantics - literal characters, star, question mark - drives each new feature.

JSmatchOne('a', 'a') -> true
matchOne('.', 'z') -> true
matchOne('', 'h') -> true
matchOne('a', 'b') -> false
matchOne('p', '') -> false
JSfunction matchOne(pattern, text) {
  if (!pattern) return true; // any text matches the empty pattern
  if (!text) return false;   // pattern set but text empty: no match
  if (pattern === '.') return text.length === 1;

Why it matters

A regex engine in 40 lines is the shortest proof that pattern matching is just functions you can write yourself.
