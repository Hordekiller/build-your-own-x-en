Building A Simple Single Sign On(SSO) Server And Solution From Scratch In Node.js.

About

A single sign-on server: one central authentication for many applications. Users log in once, apps validate a token with the server, and only the user id is shared - never the password.

What you'll learn

  • The redirect flow: app B -> SSO login -> back with a session cookie
  • A /validate endpoint: checking token + allowed app ids
  • The next parameter: returning users to their original page

Core idea

Apps exchange only tokens; passwords and extra data are never sent to them. Each app redirects to SSO when it has no session, then validates the token it receives.

JavaScript// on the SSO server: validate the token an app sends
app.post('/validate', (req, res) => {
    const { appId, token } = req.body;
    const session = sessions[token];
    if (!apps.includes(appId) || !session) {
        return res.status(401).json({ error: 'invalid' });
    }
    // return only the user id - never the password!
    res.json({ ok: true, userId: session.userId });
});

Why it matters

One login for many apps - the architecture behind every enterprise portal, built in a single server.
