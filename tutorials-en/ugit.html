About

ugit: learn Git internals by building Git yourself — a faithful, minimal Git in Python with type hints, covering objects, refs, gc, branches, merges and rebase.

What you'll learn

  • Git's object graph: commits, trees, blobs and parents
  • Refs, detached HEAD and the ^ / ~ operators
  • Garbage collection, branches, merges (including conflicts)
  • Type-annotated Python as a teaching tool

Core idea

A commit is a tree plus a parent — and a log is a walk along parents:

pythondef cmd_commit(tree: str, parent: str | None) -> str:
    """Create a commit: contents of all blobs plus the parent"""
    data = f"tree {tree}\n".encode()
    if parent:
        data += f"parent {parent}\n".encode()
    ...
pythondef log(oid: str) -> Generator[str]:
    """walk the parent chain from one commit"""
    while oid:
        commit = get_commit(oid)
        yield oid
        oid = commit.parent   # step backwards
pythondef get_oid(name: str) -> str:
    """turn a ref or ~ and ^ operator into a commit id"""
    if name.endswith("^"):
        return get_commit(get_oid(name[:-1])).parent   # parent of first parent
    ...

Why it matters

With its type hints and carefully chunked commits, ugit is a masterclass in building a real system — and the closest you can get to git without writing C.
