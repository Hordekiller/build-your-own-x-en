About

The final step in the Codeslinger emulation series: a Sega Master System emulator, covering the Z80 CPU, the VDP video processor, memory banks and accurate I/O ports.

What you'll learn

  • The Master System's Z80 + VDP architecture
  • Memory banking and the 0x0000-0xFFFF map
  • Reading and writing VDP control ports
  • Frame-synchronized main loops

Core idea

The main loop targets real display timing — 60 frames per second, measured per frame:

cppvoid Emulator::MainLoop( )
{
  const double SIXTYTH = 1000/60 ; // working in milliseconds
  double lastFrameTime = 0 ;
  while (notQuitting) // loop until the player quits
  {
    double currentTime = GetCurrentTime() ;
    if (currentTime - lastFrameTime >= SIXTYTH)
    {
      lastFrameTime = currentTime ;
      UpdateGameState() ;   // one frame of the emulated machine
    }
  }
}

text0x7E : read: returns the V counter from the VDP. write: data to the sound chip
0x7F : read: returns the H counter from the VDP. write: data to the sound chip (mirror of above)
text0x0000-0x3FFF : ROM Slot 1
0x4000-0x7FFF : ROM Slot 2
0x8000-0xBFFF : ROM Slot 3 / RAM Slot
0xC000-0xDFFF : RAM
0xE000-0xFFFF : mirrored RAM

Why it matters

Completing the series means you've built three emulators of increasing complexity — the soundest possible foundation for whatever hardware bears your name next.
