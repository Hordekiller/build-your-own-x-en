Build your own 8-Ball Pool game from scratch

About

A video series building a complete 8-Ball Pool game with plain JavaScript and Canvas - no libraries. From cue-ball physics (strike, motion, friction) to the full 8-ball rules and UI, in three parts.

What you'll learn

  • Ball physics: position/velocity integration, restitution and table friction
  • Elastic circle-circle collision with impulse exchange along the normal
  • The 8-ball rule set: aiming, pocketing, win condition with the 8 ball

Core idea

Each ball keeps position, velocity, radius and state; update applies friction and wall collisions. Colliding balls exchange the relative velocity projected onto the normal vector - the standard elastic impulse.

JavaScriptclass Ball {
  constructor(x, y, radius, id) {
    this.x = x; this.y = y;
    this.vx = 0; this.vy = 0;
    this.radius = radius;
    this.id = id;
  }
  update(dt) {
    this.x += this.vx * dt;
    this.y += this.vy * dt;
    this.vx *= FRICTION;   // table friction
    this.vy *= FRICTION;
    if (Math.abs(this.vx) < EPSILON) this.vx = 0;
    if (Math.abs(this.vy) < EPSILON) this.vy = 0;
    this.collideWalls();
  }
  collide(other) {
    const dx = other.x - this.x;
    const dy = other.y - this.y;
    const dist = Math.hypot(dx, dy);
    if (dist < this.radius + other.radius) {
      // normal vector and speed exchange along it
      const nx = dx / dist, ny = dy / dist;
      const relVx = this.vx - other.vx;
      const relVy = this.vy - other.vy;
      const speed = relVx * nx + relVy * ny;
      if (speed > 0) {
        this.vx -= speed * nx;  this.vy -= speed * ny;
        other.vx += speed * nx; other.vy += speed * ny;
      }
    }
  }
}
