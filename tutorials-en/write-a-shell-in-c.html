About

Writing a Unix shell in C: a command-line structure, input reading with getline, tokenizing, and a full execution model.

What you'll learn

  • A command struct: buffer, argv, argc and program_name
  • Reading input safely with getline()
  • Tokenizing with delimiters like space, tab, newline

Core idea

A command is a struct holding the raw buffer, its argv array, and argc. getline() reads a line; splitting walks it against the standard whitespace delimiters into tokens.

C/* the command-line structure and its parts */
typedef struct {
    char *buffer;
    size_t buf_len;
    int argc;
    char **argv;
    char *program_name; /* argv[0] without slashes, for error messages */
} cmd_t;
