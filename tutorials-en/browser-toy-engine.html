About

A toy browser engine in Rust: HTML parses into a DOM tree, CSS into style rules, and together they produce boxes that lay out and paint.

What you'll learn

  • The browser pipeline: parse, style, layout, paint
  • Parsing HTML into a DOM and CSS into rules
  • Computing box positions and dimensions

Core idea

The engine follows the canonical pipeline: HTML to DOM, CSS to rules, DOM plus rules to styled layout boxes. Each box then receives an absolute rectangular position during layout.

Text   HTML  -->  Parse  -->  DOM
   CSS   -->  Parse  -->  Style Rules      -->  Style  -->  Layout  -->  Paint  -->  pixels
                     DOM + Style Rules
Rust// layout: every box gets an absolute rectangular position
pub fn layout(&self, containing_block: Dimensions) -> LayoutBox {
    let mut layout_box = self.build_layout_tree();
    layout_box.layout(containing_block);
    layout_box
}
