About

A C and x86 port of Jack Crenshaw's classic 'Let's Build a Compiler' series by lotabout. The 1980s tutorial that started with a simple calculator and grew into a complete compiler with functions - modernized from Pascal/68k so it runs on today's machines.

What you'll learn

  • Single-pass compilation: emitting output while reading input
  • The GetChar() / Look() / Match() triad that builds every rule
  • A complete small compiler: arithmetic, variables, if/while, functions

Core idea

No AST, no separate lexer: the compiler reads input and emits code at the same time. Three tiny functions - GetChar() to read the next character, Look() for the current one, Match() to verify it - build every grammar rule.

Cvoid Expression() {   // rule: +1+2 -> mov eax,1; add eax,2
  Term();
  while (Look == '+' || Look == '-') {
    EmitLn("push eax");
    switch (Look) {
      case '+': Add(); break;
      case '-': Subtract(); break;
    }
  }
}

Why it matters

The gentle classic path: start with a calculator, end with a working compiler - and the C port emits runnable x86 assembly with as and ld.
