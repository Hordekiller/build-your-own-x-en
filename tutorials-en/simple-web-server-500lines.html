About

The 'A Simple Web Server' chapter from The Architecture of Open Source Applications: 500 Lines or Less, by Greg Wilson. Builds a socket-based web server whose centerpiece is a rule system that lets handlers be added by writing small classes - no rewriting needed.

What you'll learn

  • IP, ports, sockets and how HTTP requests are just text
  • Separating request parsing from response handling
  • A Rule-based design where new functionality means new classes

Core idea

Most of the web runs on the Internet Protocol family; the relevant member is TCP/IP, which makes communication look like reading and writing files. A socket is one end of a point-to-point channel - an address plus a port number.

Pythonclass BaseHTTPHandler:
    def __init__(self, request):
        self.request = request

    def handle(self):
        # polymorphism: subclasses override the verb methods
        if self.request.method == 'GET':
            self.do_GET()
        elif self.request.method == 'POST':
            self.do_POST()

    def do_GET(self):
        raise NotImplementedError

    def do_POST(self):
        raise NotImplementedError

    def send(self, status, body):
        self.request.send_response(status)
        self.request.send_body(body)

Why it matters

A 30-year industry veteran shows the design skill behind servers: extensibility via small classes instead of code rewriting.
