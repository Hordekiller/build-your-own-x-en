Naivecoin: a tutorial for building a cryptocurrency

⚙ Language: TypeScript 📁 Blockchain / Cryptocurrency 🌐 English page 🔗 Original source
Original source: "Naivecoin: a tutorial for building a cryptocurrency" — Lauri Hartikka's step-by-step TypeScript coin with P2P networking and a web UI.

About

Lauri Hartikka's Naivecoin walks through a working cryptocurrency in TypeScript: blocks, hashing, a key-pair wallet, signatures, and a peer-to-peer network — with each step built and demonstrated before moving on.

What you'll learn

  • Typed Block and Blockchain data structures.
  • Block hashing and integrity validation.
  • Key pairs, addresses and digital signatures.
  • Peer-to-peer networking and the longest-chain rule.

Core idea

The block is a typed class — every field declared up front:

typescriptclass Block {

    public index: number;          // block height in the chain
    public hash: string;           // block hash
    public previousHash: string;   // hash of the previous block
    public timestamp: number;      // timestamp
    public data: string;           // data inside the block

    constructor(index: number, hash: string, previousHash: string, timestamp: number, data: string) {
        this.index = index;
        this.hash = hash;
        // ...
    }
}

And the hash is a pure function of its inputs:

typescript// Calculating the hash: combining the index, previous hash, time and data, then SHA256-hashing
const calculateHash = (index: number, previousHash: string, timestamp: number, data: string): string =>
    CryptoJS.SHA256(index + previousHash + timestamp + data).toString();

Why it matters

TypeScript tames the implicit state of a coin implementation, and the tutorial's discipline — one working step at a time, from genesis to P2P — makes the whole cryptocurrency architecture legible.
