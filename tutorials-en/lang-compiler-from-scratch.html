About

Gary Bernhardt's screencast proves a compiler need not be intimidating: in about 90 minutes he compiles a simple C-like language directly to real CPU assembly - not an intermediate.

What you'll learn

  • The live process: how a real compiler decides, finds errors and emits assembly
  • Calls and the stack: push/ret frames and calling conventions
  • Operator precedence handled by layered parse functions: lower layers bind tighter

Core idea

A classic pipeline in Ruby: lexer splits text into tokens, parser builds the AST, and an emitter turns the tree into x86 instructions, producing a standalone executable file.

Ruby# step-by-step cursor over tokens
class Parser
  def initialize(tokens)
    @tokens = tokens
    @pos = 0
  end

  def peek
    @tokens[@pos]
  end

  def next_token
    tok = @tokens[@pos]
    @pos += 1
    tok
  end

  # parse an expression: multiplication binds before addition
  def parse_expression
    left = parse_term
    while peek.to_s == "+" || peek.to_s == "-"
      op         = next_token.to_s
      right      = parse_term
      left       = Emitter.binary(op, left, right)
    end
    left
  end
end

Why it matters

An excellent starting point: after watching, the whole compiler structure (token to assembly) is clear, and bigger text projects like Crafting Interpreters await.
