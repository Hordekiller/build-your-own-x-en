Writing a Command Line Tool in Rust

⚙ Language: Rust 📁 Command-Line Tool 🌐 English page 🔗 Original source
Original source: "Writing a CLI app in Rust" — Matt Gathu builds rget, a wget clone, using clap for argument parsing and the reqwest HTTP client.

About

A wget clone in Rust named rget: a binary project, clap for a polished --help experience, and an HTTP downloader that writes the fetched bytes to disk — a compact tour of the essential Rust CLI stack.

What you'll learn

  • Scaffolding a Rust binary with cargo.
  • Declarative argument parsing with clap.
  • Fetching a URL with reqwest.
  • Writing files and handling failures gracefully.

Core idea

The binary starts minimal, then gains one dependency at a time:

shellcargo new rget --bin
$ cd rget
$ tree .
.
├── Cargo.toml
└── src
    └── main.rs

1 directory, 2 files

clap turns argument handling into a declarative description:

rustextern crate clap;

use clap::{Arg, App};

fn main() {
    let matches = App::new("Rget")
        .version("0.1.0")
        .author("Matt Gathu")
        .about("wget clone written in Rust")
        .arg(Arg::with_name("URL")
                 .required(true)
                 .takes_value(true)
                 .index(1))
        .get_matches();
    // ...
}

Why it matters

Rebuilding a familiar tool (wget) focuses your attention on the details that matter — CLI ergonomics, network errors, file handling — rather than on inventing new requirements.
