Writing a Web Server from Scratch

About

A step-by-step journal building a working web server in C#: every design decision, good or bad. Starts from an HttpListener class, adds logging, routing of verbs and paths to handlers, authentication with session expiry, and AJAX endpoints - implemented as a small library.

What you'll learn

  • Using HttpListener instead of raw sockets for request decoding
  • Routing HTTP verbs and paths to handler methods
  • Authentication, session objects with expiry, and AJAX integration

Core idea

The server is deliberately stateless, so most behavior lives in static singletons; three main files keep the whole thing readable.

C#using System.Net;
using System.Net.Sockets;
using System.Threading;

namespace Clifton.WebServer
{
    public static class Server
    {
        private static HttpListener listener;
        // the intranet assumption: bind to local host IPs
        public static void Start()
        {
            listener = new HttpListener();
            listener.Prefixes.Add("http://*:8080/");
            listener.Start();
        }
    }
}

Why it matters

A rare behind-the-scenes look at the design process itself: routing, auth and sessions solved incrementally, with full source on GitHub.
