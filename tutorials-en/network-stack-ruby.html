How to build a network stack in Ruby

About

A network stack in Ruby: using raw sockets from a high-level language to parse and forge Ethernet frames at the application level.

What you'll learn

  • Raw sockets (SOCK_RAW) and why the OS lets a userspace program peek at frames
  • Parsing Ethernet headers — destination and source MAC addresses
  • Reading and writing frames like a tiny NIC driver

Core idea

A raw socket hands your program the whole Ethernet frame, not just the payload. The EthernetFrame class unpacks the header bytes with Ruby's unpack and turns raw wire data into readable fields.

ruby# like TCP — but it gives you the raw Ethernet frame
socket = Socket.open(Socket::AF_INET, Socket::SOCK_RAW, Socket::IPPROTO_UDP)
# socket() / bind() / recvfrom() / sendto() go on from here
rubyclass EthernetFrame
  ETH_P_IP = 0x0800          # packet type: IPv4

  def initialize(raw)
    @raw = raw
    @dst_mac = raw[0, 6].unpack("H*").first
    @src_mac = raw[6, 6].unpack("H*").first
    @eth_proto = raw[12, 2].unpack("n").first
  end

Why it matters

Seeing the same wire-level mechanics from a dynamic language makes the stack approachable for web developers who never touch C.
