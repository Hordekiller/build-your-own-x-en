How to build a simple artificial neural network with Go

⚙ Language: Go 📁 Neural Network 🌐 English page 🔗 Original source
Original source: "How to build a simple artificial neural network with Go — by Sau Sheong Chang"

About

A simple artificial neural network in Go: one neuron formula, one activation function, and a training loop with backpropagation — nothing else.

What you'll learn

  • The neuron's equation: activation(bias + Σ wᵢ·xᵢ)
  • Sigmoid and its derivative for backpropagation
  • A complete training loop in plain Go

Core idea

The whole network is built on the weighted sum of inputs passed through an activation function. Training then uses the sigmoid derivative to push every weight in the direction that reduces the error.

go// artificial neuron: activation(bias + sum of wi*xi)
output := activation(bias + sum(wi * xi, for i = 1..n))
go// the sigmoid function and its derivative
func sigmoid(x float64) float64 {
    return 1.0 / (1.0 + math.Exp(-x))
}

func sigmoidPrime(x float64) float64 {
    return sigmoid(x) * (1.0 - sigmoid(x))
}

Why it matters

Minimal implementations are the best teachers: this one proves a learning network is only a formula, a loop and a derivative.
