Build A Simple Terminal Emulator In 100 Lines of Golang

About

A terminal emulator in Go: run real programs like sh inside your own terminal using a pseudo-terminal (pty), with a termbox TUI display, two concurrent loops for program output vs keyboard input, and ANSI escape interpretation.

What you'll learn

  • What a pty is: the master/slave pair glueing I/O
  • Two loops: program output -> screen, keys -> program
  • A tiny ANSI state machine for colors

Core idea

ptmx is both read (program output to the grid) and written (user keys into the program). A small state machine collects characters after \x1b until the final letter like [m.

Go// simple ANSI color interpretation
func interpretANSI(data []byte) {
    if len(data) > 2 && data[0] == 0x1b && data[1] == '[' {
        parts := strings.Split(string(data[2:len(data)-1]), ";")
        if len(parts) > 0 {
            switch parts[0] {
            case "31":
                fg = termbox.ColorRed
            case "32":
                fg = termbox.ColorGreen
            case "0":
                fg = termbox.ColorDefault
            }
        }
    }
}

Why it matters

Terminals are the oldest user interface still in daily use - and this one runs real programs.
