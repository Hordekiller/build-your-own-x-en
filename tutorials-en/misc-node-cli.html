How to create a real-world Node CLI app with Node

About

A professional Node CLI: arguments and flags, colored and tidy output, interactive prompts, and npm publication via the bin field - built around a git stats tool.

What you'll learn

  • bin in package.json and the shebang line
  • chalk for colors and inquirer for prompts
  • Manual argv parsing - and what commander/yargs do instead

Core idea

chalk manages color and inquirer asks interactive questions - the two pillars of modern CLIs. Flag parsing is a simple loop over process.argv.

JavaScript#!/usr/bin/env node
'use strict';

const chalk = require('chalk');
const inquirer = require('inquirer');

function parseFlags(argv) {
    const flags = { json: false, repo: '.' };
    for (let i = 2; i < argv.length; i++) {
        switch (argv[i]) {
        case '--json':
            flags.json = true;
            break;
        case '-r':
        case '--repo':
            flags.repo = argv[++i];
            break;
        case '--help':
            console.log('usage: git-stats [-r repo] [--json]');
            process.exit(0);
        }
    }
    return flags;
}

Why it matters

From scripts to shippable software: publish once, and the tool is available globally with npx.
