How to create your own simple 3D render engine in pure Java

⚙ Language: Java 📁 3D Renderer 🌐 English page 🔗 Original source
Original source: "How to create your own simple 3D render engine in pure Java" by Rogach — a complete Java 3D engine using only Swing and the standard library.
↗ Visit the original tutorial فارسی — Persian version

About

This tutorial builds an interactive 3D engine in pure Java: a Swing window shows a wireframe-then-filled cube, sliders rotate the camera, and step by step you implement perspective projection, depth sorting and flat shading. Everything runs in the JVM with no graphics library at all.

What you'll learn

  • Representing 3D scenes: vertices, triangles and faces.
  • Perspective projection from 3D space to the 2D screen.
  • Rotation matrices and camera controls via sliders.
  • The painter's algorithm: sorting polygons by depth before drawing.
  • Flat shading with a simple light model.

Core idea

The engine's data model is minimal: a Vertex is three coordinates, a Triangle references three vertices and holds a color, and a scene is just a list of triangles.

javaclass Vertex {
    double x;
    double y;
    double z;
    Vertex(double x, double y, double z) {
        this.x = x;
        this.y = y;
        this.z = z;
    }
}

class Triangle {
    Vertex v1;
    Vertex v2;
    Vertex v3;
    Color color;
    Triangle(Vertex v1, Vertex v2, Vertex v3, Color color) {
        this.v1 = v1;
        this.v2 = v2;
        this.v3 = v3;
        this.color = color;
    }
}

A cube is simply twelve such triangles — two per face — and rendering is projecting each vertex and filling each triangle.

Why it matters

For Java developers this is the smoothest possible on-ramp to computer graphics: only the JDK is needed, the interactive sliders make every transformation tangible, and the finished engine is genuinely extensible — the author even ports it to a full demo with multiple textured shapes.
