About

Handmade Hero is a long-term educational project: every weekday, for one hour, Casey Muratori builds a commercial-quality game from absolute zero - graphics, sound, physics, AI, UI and tooling, all in C/C++ with a few pieces of assembly.

What you'll learn

  • Platform layer separation (win32 input, window, timing, audio) from game logic
  • Pixel-buffer rendering with direct memory access, parallax and scrolling
  • World grid collision, software sound synthesis and full memory control

Core idea

The project answers: how were 90s games built with nothing? Modules include the platform layer, shared structs (render buffer, game state), game logic, vector math, audio synthesis, asset management and world logic.

C++// module overview built over the project
win32_handmade.cpp  // platform layer: window, input, audio, timing
handmade.h          // shared structs (render buffer, game state)
handmade.cpp        // game logic: update and render
handmade_math.h     // vector/matrix math
handmade_audio.cpp  // sound synthesis and playback
handmade_asset.cpp  // asset management
handmade_world.cpp  // game world, collision, AI

Why it matters

Deep understanding of how computers, memory and rendering really work - the opposite direction from engine-based tutorials.
