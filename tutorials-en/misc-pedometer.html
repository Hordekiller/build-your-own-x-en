About

The pedometer chapter from 500 Lines: turning noisy accelerometer signals into a step count in Ruby. Smooth the signal with a windowed low-pass filter, then count peaks crossing a calibrated threshold with a cooldown.

What you'll learn

  • Window averaging as the simplest low-pass filter
  • Threshold crossing with cooldown to avoid double counts
  • The acceleration magnitude - orientation-independent

Core idea

Each step is a peak: the signal rises above a threshold -> one step, then a cooldown prevents recounting the same peak. A long window blurs steps, a short one keeps noise - the window matches walking cadence (~2 steps/s).

Rubyclass Pedometer
  def initialize
    @window = []
    @sum = 0.0
    @stepCount = 0
  end

  # low-pass filter: average of the last 20 samples
  def filter(value)
    @window << value
    @sum += value
    if @window.size > 20
      @sum -= @window.shift
    end
    @sum / @window.size
  end

  def process(sample)
    smoothed = filter(sample.acceleration_magnitude)
    return unless smoothed > @threshold
    unless @last_step_at && (now - @last_step_at) < 0.3
      @stepCount += 1
      @last_step_at = now
    end
  end
end

Why it matters

Signal processing in 20 lines: the filter-stabilize-count pipeline behind every fitness tracker.
