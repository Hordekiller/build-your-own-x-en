How to Create a Compiler

About

A long educational video shows the complete process of writing a compiler: from defining the input language to producing executable code - including fixing common mistakes live.

What you'll learn

  • The three core concepts: lexer (text to tokens), parser (tokens to tree), code generator (tree to assembly/machine code)
  • Start small: numbers and four operations first, then add conditionals and loops
  • Always test the assembly output with gcc or clang; add one feature at a time to keep debugging simple

Core idea

The value of a video tutorial is watching errors get solved in real time. A typical token structure covers numbers, identifiers, operators, parens and EOF.

C++enum TokenType {
    TOK_NUMBER,  // number
    TOK_IDENT,   // identifier (variable)
    TOK_PLUS,    // +
    TOK_STAR,    // *
    TOK_LPAREN,  // (
    TOK_RPAREN,  // )
    TOK_EOF
};

struct Token {
    TokenType type;
    std::string text;      // raw text of the token
    long double value;     // if it is a number
};

Why it matters

The lowest entry cost and the most insight for visual learners: it takes you from "what is a compiler?" to "I can build one myself".
