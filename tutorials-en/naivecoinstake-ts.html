NaivecoinStake: a tutorial for building a cryptocurrency with the Proof of Stake consensus

⚙ Language: TypeScript 📁 Blockchain / Cryptocurrency 🌐 English page 🔗 Original source
Original source: "NaivecoinStake: a tutorial for building a cryptocurrency with the Proof of Stake consensus" — a step-by-step TypeScript tutorial by Rich V. Ruch that replaces proof-of-work with proof-of-stake consensus.
↗ Visit the original tutorial فارسی — Persian version

About

NaivecoinStake continues where Naivecoin ended: instead of burning electricity on proof-of-work, nodes stake coins and the protocol chooses who may forge the next block proportionally to their stake — all in a TypeScript codebase that builds on the previous tutorial.

What you'll learn

  • A minimal working blockchain as a distributed, growing list of records.
  • Proof of Stake: a distributed choice of the next block's forger.
  • Turning a generic chain into a real cryptocurrency via transactions.
  • Wallets, addresses and proving ownership of coins.

Core idea

The tutorial is organized in chapters, each ending with a working milestone. The first chapter establishes the base: a minimal blockchain — a distributed database that keeps a continuously growing list of ordered records. The second chapter swaps consensus: a distributed algorithm decides which block should be next, and famously, proof of stake replaces proof of work. The third chapter turns the generic chain into a real currency: coins can be sent to addresses — provided you first prove you own them.

Core idea

Like its predecessor, everything starts with a typed Block and a pure hash function:

typescript// Block class: the base structure of every block in the blockchain
class Block {

    public index: number;          // block height in the chain
    public hash: string;           // block hash (unique identifier)
    public previousHash: string;   // hash of the previous block
    public timestamp: number;      // timestamp (seconds)
    public data: string;           // data stored in the block
    // ...
}
typescript// Computing the block hash with SHA256 from the block content
const calculateHash = (index: number, previousHash: string, timestamp: number, data: string): string =>
    CryptoJS.SHA256(index + previousHash + timestamp + data).toString();

Why it matters

Altcoins are built on consensus design, and this tutorial is the rare one that goes beyond proof-of-work with a complete, readable proof-of-stake implementation — including forging, signing and network sync.
