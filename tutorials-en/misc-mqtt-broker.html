Sol - An MQTT broker from scratch

About

Implement an MQTT broker in C: parse the binary protocol's fixed header, build PUBLISH packets, and manage topic subscriptions - the publish/subscribe core every IoT device talks to.

What you'll learn

  • The MQTT fixed header and variable byte integers
  • Building a PUBLISH packet byte by byte
  • Topic -> subscriber maps and wildcard routing

Core idea

Every MQTT message starts with a fixed header (type + flags + remaining length with a variable-byte encoding); CONNECT carries protocol level and client id, SUBSCRIBE carries packet identifier and topic filters.

Ctypedef struct {
    uint8_t type: 4;          // 1=CONNECT, 3=PUBLISH, ...
    uint8_t flags: 4;
    uint8_t remaining_len;   // Variable Byte Integer
} mqtt_fixed_header;

// build a PUBLISH packet (QoS 0)
int build_publish(uint8_t* buf, const char* topic,
                  const char* payload, int payload_len) {
    int off = 0;
    buf[off++] = 0x30;                         // PUBLISH QoS0
    buf[off++] = (uint8_t)(2 + strlen(topic) + payload_len);
    buf[off++] = (strlen(topic) >> 8) & 0xff;
    buf[off++] = strlen(topic) & 0xff;
    memcpy(buf + off, topic, strlen(topic));
    off += strlen(topic);
    memcpy(buf + off, payload, payload_len);
    return off + payload_len;
}

Why it matters

The broker is the heart of IoT messaging - building one makes binary protocols and pub/sub concrete.
