Building a spell-checker

⚙ Language: Clojure 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Building a spell-checker"

About

A spellchecker in Clojure: detection (the word is not in the dictionary) plus suggestions (generate one-edit candidates with deletions, insertions, substitutions and transpositions, then rank by corpus frequency).

What you'll learn

  • Generating edit-distance-1 candidates from a word
  • Dictionary lookup and the edits2 fallback
  • A naive Bayes ranking: most frequent valid word wins

Core idea

For every word, generate all one-character variants; keep those in the dictionary; if none qualify, apply a second edit. Clojure's persistent data and pure functions keep this classic algorithm clean.

Clojure;; all words reachable in one edit
(defn edits1 [word]
  (let [letters "abcdefghijklmnopqrstuvwxyz"
        splits (for [i (range (inc (count word)))]
                 [(subs word 0 i) (subs word i)])]
    (concat
      ; deletion
      (for [[a b] splits :when (pos? (count b))]
        (str a (subs b 1)))
      ; transposition of two adjacent letters
      (for [[a b] splits :when (pos? (count (subs b 1)))]
        (str a (subs b 1 2) (subs b 0 1) (subs b 2)))
      ; substitution
      (for [[a b] splits :when (pos? (count b)) c letters]
        (str a c (subs b 1)))
      ; insertion
      (for [[a b] splits c letters]
        (str a c b)))))

Why it matters

Peter Norvig's algorithm re-told in a functional language - the canonical small-NLP project.
