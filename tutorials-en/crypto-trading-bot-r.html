Build A Cryptocurrency Trading Bot with R

⚙ Language: R 📁 Bot 🌐 English page 🔗 Original source
Original source: "Build a Cryptocurrency Trading Bot with R" — a practical bot by Brad Lindblad that trades on GDAX: balances, EMA indicators and automatic limit orders, all under an always-on loop.
↗ Visit the original tutorial فارسی — Persian version

About

A real trading bot in R that talks to the GDAX exchange: read your USD and ETH balances, compute technical indicators (EMAs), compare them, and place limit buy/sell orders — logged to a file so you can audit every decision.

What you'll learn

  • Connecting to the GDAX API with rgdax and your keys.
  • Reading account balances and market candles.
  • Computing EMAs with TTR for signals.
  • Placing orders and logging the bot's activity.

Core idea

The bot is a set of small, single-purpose functions. Reading your balance is one:

r# Building the functions
curr_bal_usd <- function(x){
  m <-  accounts(api.key = "your_api_key", secret = "your_secret", passphrase = "your_passphrase")
  m <-  subset(m$available, m$currency == 'USD')
  m
}
curr_bal_eth <- function(x){
  n <- accounts(api.key = "your_api_key", secret = "your_secret", passphrase = "your_passphrase")
  n <- subset(n$available, n$currency == 'ETH')
  n
}

Signals come from indicator comparisons, and the loop is written so logs separate every run:

Why it matters

It demonstrates automating a financial API end to end — auth, market data, indicators, order placement — and the discipline of logging makes your decisions auditable and your mistakes fixable.
