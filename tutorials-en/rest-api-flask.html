Implementing a RESTful Web API with Python & Flask

About

An intro to REST APIs with Flask: resources, URL converters, request data, JSON responses and status codes - with curl examples for every endpoint and a small curl cheatsheet at the end.

What you'll learn

  • Decorator-based routing and URL converters (<int:id> etc.)
  • Reading query strings, form data and JSON bodies
  • Returning JSON with proper HTTP status codes

Core idea

Flask is a microframework on top of Werkzeug (a WSGI toolkit); a route with @app.route maps a method and path to a view function, and converters make path parameters typed.

Pythonfrom flask import Flask, url_for

app = Flask(__name__)

@app.route('/')
def api_root():
    return 'Welcome'

@app.route('/articles')
def api_articles():
    return 'List of ' + url_for('api_articles')

@app.route('/articles/<articleid>')
def api_article(articleid):
    return 'You are reading ' + articleid

if __name__ == '__main__':
    app.run()

Why it matters

The gentlest possible REST introduction: every concept shown with one endpoint and the curl line that tests it.
