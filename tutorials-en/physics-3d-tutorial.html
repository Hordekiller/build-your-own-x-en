About

A series that builds a complete 3D physics engine from scratch, starting with the vector mathematics that everything else relies on.

What you'll learn

  • Implementing Vec3: addition, scaling and the rest of vector algebra
  • From vectors to rigid bodies and forces
  • Stepping toward a full 3D simulation

Core idea

The first episode builds the Vec3 class - operator overloading included - because every later component (forces, collisions, rotations) is just vector math.

C++// the core of the 3D vector class - what the first episode builds
struct Vec3 {
  float x, y, z;

  Vec3 operator+(const Vec3& o) const { return {x + o.x, y + o.y, z + o.z}; }
  Vec3 operator*(float s)  const { return {x * s, y * s, z * s}; }
}

Why it matters

If you can implement vectors cleanly, rigid-body physics in 3D becomes an exercise in applying them.
