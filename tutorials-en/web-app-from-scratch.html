About

The first post of a series that builds a web application - and its web server - from scratch in Python, using only the standard library and ignoring WSGI. Covers the HTTP protocol and request/response formats in detail before writing a byte of code.

What you'll learn

  • The exact text format of HTTP requests and responses (RFC 2616)
  • Request line, headers, empty line and body anatomy
  • Writing a web server that feeds a hand-built web app

Core idea

Clients connect and send a text string; the server interprets it and returns a response. The request line is METHOD SPACE path SPACE HTTP-version \r\n, then zero or more header lines, an empty line, and an optional body.

HTTPGET / HTTP/1.1\r\n
Host: example.com\r\n
Accept: text/html\r
\r
POST / HTTP/1.1\r\n
Host: example.com\r\n
Accept: application/json\r\n
Content-type: application/json\r\n
Content-length: 2\r\n
\r
{}

Why it matters

Walking the whole stack yourself - server plus app - with no frameworks, revealing what WSGI and every framework quietly do.
