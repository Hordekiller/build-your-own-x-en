About

The In Practice chapter of LearnOpenGL: a real Breakout game built on pure OpenGL, applying every technique from the book - shaders, textures, particles, text and post-processing.

What you'll learn

  • AABB-circle collision with bounce direction detection
  • Particle systems, FBO post-processing (shake effect) and FreeType text rendering
  • Power-ups: big paddle, sticky ball, pass-through and multi-ball

Core idea

Levels are defined in text files - each row is a brick line, each character a brick color - so designing a level is just writing a file. The collision core finds the closest AABB point to the ball center, then reflects along the smaller overlap axis.

C++// circle (ball) vs AABB (brick/paddle) collision
Collision CheckCollision(BallObject &ball, GameObject &box) {
  // closest AABB point to the ball center
  glm::vec2 closest = glm::clamp(ball.Position,
      box.Position, box.Position + box.Size);
  glm::vec2 diff = ball.Position - closest;
  float distance = glm::length(diff);
  if (distance <= ball.Radius) {
    // find bounce direction by comparing overlaps
    glm::vec2 overlap = glm::abs(diff);
    if (overlap.x < overlap.y) ball.Velocity.x = -ball.Velocity.x; // side
    else                      ball.Velocity.y = -ball.Velocity.y; // top/bottom
    return { true, ball.Position - closest };
  }
  return { false, glm::vec2(0.0f) };
}
