About

The classic 'How to Create a Custom Physics Engine' series: impulse-based collision resolution, positional correction and a fixed-timestep loop.

What you'll learn

  • Resolving collisions with impulses along the contact normal
  • Positional correction so bodies do not sink into each other
  • A fixed-timestep accumulator for deterministic physics

Core idea

When two bodies overlap, the engine computes their relative velocity along the normal and applies an impulse that removes the closing speed. Residual penetration is then pushed apart by positional correction, and a fixed-timestep accumulator keeps steps identical frame to frame.

C++void PositionalCorrection( Object A, Object B )
{
    const float percent = 0.2;   // usually between 20 and 80 percent

    Vec2 correction = penetrationDepth / (A.inv_mass + B.inv_mass)
                      * percent;
    A.position -= correction * A.inv_mass;
    B.position += correction * B.inv_mass;
}
C++// game loop with a fixed timestep (summary)
accumulator += elapsedTime;           // accumulate the real elapsed time
while( accumulator >= dt ) {          // while there is enough accumulated time
    physics.Step( dt );
    accumulator -= dt;
}

Why it matters

Impulses and positional correction are the exact techniques used by Box2D-class engines - an industry-shaped answer in a handful of articles.
