Let's Build a Compiler

About

Jack Crenshaw's famous 1988 series "Let's Build a Compiler" used single-pass techniques in Pascal targeting the 68000. This port moves it to Haskell while keeping the translation faithful - using State monad for compiler state.

What you'll learn

  • Single-pass compilation: GetChar, Look, Match and direct 68k assembly output
  • Using the State monad to hold current character + remaining input in pure code
  • The progression: calculator, precedence, variables, if/else, loops, functions

Core idea

The Cradle project translates Crenshaw's state-holding approach into Haskell with the State monad, so every function stays pure and the emitted code is x86 assembly.

Haskelldata CradleState = CradleState { input :: String, cur :: Char }
type P a = State CradleState a

-- next input character
getChar' :: P Char
getChar' = do
    st <- get
    case input st of
      []     -> return '\0'          -- end of input
      (c:cs) -> put (st { input = cs, cur = c }) >> return c

-- emit output code
emit :: String -> P ()
emit s = liftIO $ putStrLn s

Why it matters

A great opportunity for Haskell and functional-language fans: compiler fundamentals in Crenshaw's style plus real practice with the State monad.
