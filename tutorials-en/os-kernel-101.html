About

Kernel 101: write a kernel that boots and prints 'my first kernel' — assembly entry, a C main, and a bootable ISO.

What you'll learn

  • Assembly entry point with a proper stack
  • Writing to VGA text memory at 0xB8000
  • Building a bootable ISO with grub-mkrescue

Core idea

The assembly entry sets up a stack (ESP must not be undefined!) and calls kmain. The C function writes a string straight into VGA text memory, and grub-mkrescue packages it into a bootable ISO.

section .text

start:
    mov esp, stack_top  ; set up the stack (required! ESP is undefined)
    call kmain          ; jump to the main code
