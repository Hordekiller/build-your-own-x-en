gifbot - Building a GitHub App

About

Gifbot watches GitHub events and reacts to comments that use the [gifbot:<query>] syntax: it searches Giphy, posts the top result as a commit comment on the pull request, and learns as a serverless Lambda function.

What you'll learn

  • Consuming GitHub webhook events in a serverless function.
  • Searching Giphy and posting results to pull requests.
  • Parsing a trigger syntax from comment bodies.
  • Deploying a bot as an AWS Lambda with API Gateway.

Core idea

The bot is two halves: search Giphy, then write a comment on GitHub — both plain HTTP calls with a token:

jsconst requestp = require('./requestAsPromise');

const searchGifs = (searchTerm) =>
  requestp({
    url: 'http://api.giphy.com/v1/gifs/search',
    json: true,
    qs: {
      q: searchTerm,
      api_key: 'dc6zaTOxFJmzC'
    }
  });

const addComment = (url, body, token) =>
  requestp({
    json: true,
    headers: {
      'Authorization': 'token ' + token,
      'User-Agent': 'ColinEberhardt',

  });

Why it matters

It demonstrates the modern bot architecture — event-driven, serverless, zero maintenance — and shows how external APIs (GitHub, Giphy) compose into one useful bot with a few dozen lines.
