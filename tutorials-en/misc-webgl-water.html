WebGL + Rust: Basic Water Tutorial

About

A 3D water scene where Rust computes and the browser renders: the scene and water are built with Three.js on WebGL, while a Rust core (compiled to WebAssembly) calculates wave heights every frame via wasm-bindgen.

What you'll learn

  • Rust to WebAssembly with wasm-bindgen
  • Wave math: combining sine and cosine waves per point
  • Bridging: Rust computation, JS rendering each frame

Core idea

A Water struct holds the grid size; height_at(x, y, t) combines two out-of-phase waves - the seed of all real wave synthesis (FFT, Gerstner).

Rustuse wasm_bindgen::prelude::*;
use nalgebra::Vector3;

/// water surface: a point grid (polygons)
#[wasm_bindgen]
pub struct Water {
    pub segments: usize,
}

impl Water {
    /// point height at time t - a simple sine wave
    pub fn height_at(&self, x: f32, y: f32, t: f32) -> f32 {
        ((x * 0.3 + t) as f64).sin() as f32 * 0.5
            + ((y * 0.2 - t) as f64).cos() as f32 * 0.3
    }
}

Why it matters

The modern split - native-speed compute where it matters, web rendering where it shines - in one demo.
