About

Let's Write Redux!: a test-driven implementation of Redux from scratch — createStore, getState, dispatch, subscribe, combineReducers and middleware basics, verified with Jest.

What you'll learn

  • The store contract implemented exactly as Redux documents it
  • Listening and notifying without leaks
  • combineReducers and middleware, in the spirit of the real API
  • Test-driven thinking about framework code

Core idea

A store is ten honest lines — the whole public API:

jsexport function createStore(reducer, initialState) {
  let state = initialState;
  const listeners = [];

  function getState() {
    return state;
  }

  function dispatch(action) {
    // the reducer computes the new state
    state = reducer(state, action);
    listeners.forEach(fn => fn());
  }
  ...
}
jsit('listeners are called on every dispatch', () => {
  const store = createStore((s = 0, a) => (a.type === 'INC' ? s + 1 : s));
  const spy = jest.fn();
  store.subscribe(spy);
  store.dispatch({ type: 'INC' });
  expect(spy).toHaveBeenCalled();
});
jsexport function combineReducers(reducers) {
  return function combinedReducer(state = {}, action) {
    const nextState = {};
    for (const key of Object.keys(reducers)) {
      nextState[key] = reducers[key](state[key], action);
    }
    return nextState;
  };
}

Why it matters

Writing Redux with tests the way its authors did converts architecture into muscle memory — and gives you a store you can debug line by line.
