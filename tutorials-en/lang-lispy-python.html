lisp.py: Make your own Lisp interpreter

About

lisp.py implements a Lisp interpreter in a few dozen lines of Python, packing the essential interpreter lessons: tokenizer, parser, evaluator with environment, and lambda/def/if support.

What you'll learn

  • Three tidy parts: tokenize, parse (recursive tree building) and eval (with environment)
  • Closures in practice: Lambda carrying its defining environment
  • Extensible: add let, begin and a simple GC afterwards

Core idea

The project is written to be read directly as an educational interpreter - standard Python only, no dependencies. eval dispatches on data type: numbers return themselves, symbols read from the environment, quotes bypass evaluation, lambdas build closures, and lists call functions with evaluated arguments.

Pythondef eval(x, env):
    if type(x) is int:            # number: itself
        return x
    if type(x) is str:            # symbol: read from env
        return env[x]
    if x[0] == 'quote':
        return x[1]
    if x[0] == 'if':              # conditional: only the right branch
        (_, test, true, false) = x
        return eval(true, env) if eval(test, env) else eval(false, env)
    if x[0] == 'lambda':          # lambda: build a closure
        (_, params, body) = x
        return Lambda(params, body, env)
    if x[0] == 'define':          # define a variable
        (_, name, value) = x
        env[name] = eval(value, env)
        return None
    # function call: eval operator and arguments
    op = eval(x[0], env)
    args = [eval(arg, env) for arg in x[1:]]
    return apply(op, args, env)

Why it matters

A small but complete starting point for interpreter programming in Python; for more depth at the same level, Norvig's lispy (90 lines!) is the next step.
