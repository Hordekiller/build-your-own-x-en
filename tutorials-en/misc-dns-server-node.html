Build a DNS Server in Node.js

⚙ Language: Node.js 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Build a DNS Server in Node.js"

About

A DNS server in Node without libraries: parse the binary DNS message (12-byte header, questions, answers), serve records from a zone map, and answer requests over UDP - exactly like a smart hosts file.

What you'll learn

  • The DNS message format: header, labels, A records
  • Parsing names: length-prefixed labels ending with \0
  • The golden rule: echo the request ID in the response

Core idea

Names are encoded as labels (length + characters) terminated by a zero byte. The response must copy the request's ID or the client rejects it.

JavaScriptconst dgram = require('dgram');
const server = dgram.createSocket('udp4');

const ZONE = { 'example.com': '93.184.216.34' };

server.on('message', (msg, rinfo) => {
    // 1. parse the question out of the message
    const qname = parseName(msg, 12);
    // 2. look it up in the zone
    const ip = ZONE[qname];
    // 3. build the response: same request ID + an A record
    const response = buildResponse(msg, qname, ip);
    server.send(response, rinfo.port, rinfo.address);
});

server.bind(53);

Why it matters

The internet's phonebook speaks a simple binary language you can serve yourself in an afternoon.
