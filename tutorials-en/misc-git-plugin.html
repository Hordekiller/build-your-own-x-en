Build your own Git plugin with python

About

Extend git with any language: any executable named git-XXX on your PATH runs when you type git XXX - the mechanism behind git-flow and every 'git plugin'. Built here in Python.

What you'll learn

  • The git- prefix naming convention and PATH discovery
  • Delegating to git with subprocess instead of reimplementing it
  • Plugins vs hooks: user-invoked vs automatic

Core idea

git brag finds and runs git-brag: an executable script that can take arguments like --help. Rely on subprocess calls to git itself rather than reimplementing git logic.

Python#!/usr/bin/env python3
import subprocess, sys

# count today's commits
result = subprocess.run(
    ["git", "log", "--since=midnight", "--oneline"],
    capture_output=True, text=True)
commits = result.stdout.strip().splitlines()
print(f"you made {len(commits)} commits today:")
for c in commits[:10]:
    print("  ", c)

Why it matters

A one-line convention unlocks infinite extensibility - and your first real dev tool is done.
