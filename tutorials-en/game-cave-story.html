About

A long-term playlist rebuilding Cave Story completely in C++: from engine setup to stages, enemies, weapons and boss fights - with three-level weapon upgrades, a dialogue engine, portals, saves and sound.

What you'll learn

  • The weapon XP system: collecting crystals raises level, taking damage lowers it
  • Map building with an editor, triggers, hidden doors and NPC dialogue
  • Enemy behaviours (flyers, swimmers, turrets), damage/health and boss combat

Core idea

The three-level weapon system is the heart of Cave Story: experience accumulates to level up, damage bleeds experience and can downgrade the weapon.

C++// three-level weapon system (Cave Story style)
class Weapon {
public:
  int level;  // 1, 2 or 3
  int exp;    // experience for upgrades

  void addExp(int amount) {
    exp += amount;
    if (exp >= REQUIREMENTS[level] && level < 3) {
      exp -= REQUIREMENTS[level];
      level++;
    }
  }
  void takeDamage() {
    exp -= PENALTY;
    if (exp < 0 && level > 1) {
      level--;
      exp = REQUIREMENTS[level];
    }
  }
};

Why it matters

To see how a real, complete game with all its systems is built, this is one of the best resources - you end with a playable Cave Story remake.
