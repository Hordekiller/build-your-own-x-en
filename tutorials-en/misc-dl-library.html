Core idea

A dense layer is np.dot(inputs, weights) + biases - the matrix multiply computes every neuron and every batch sample at once. That is the power of numpy.

Pythonimport numpy as np

class Layer_Dense:
    def __init__(self, n_inputs, n_neurons):
        # small random weights + zero biases
        self.weights = np.random.randn(n_inputs, n_neurons) * 0.01
        self.biases = np.zeros((1, n_neurons))

    def forward(self, inputs):
        self.inputs = inputs
        self.output = np.dot(inputs, self.weights) + self.biases
        return self.output

Why it matters

model.add() and model.fit() stop being magic once you've written the matrix math yourself.
