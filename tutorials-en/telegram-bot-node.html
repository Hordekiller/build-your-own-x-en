How to make a responsive telegram bot

⚙ Language: Node.js 📁 Bot 🌐 English page 🔗 Original source
Original source: "Making a telegram bot" — Soham Kamani's guide that builds a Telegram bot with webhooks, Node.js and Express, deployable with a single command.
↗ Visit the original tutorial فارسی — Persian version

About

A compact tutorial that turns a blank folder into a deployed Telegram bot: get a token from BotFather, create an Express server, register a webhook, and reply to every incoming message — then publish the whole thing with Zeit's now.

What you'll learn

  • Creating a bot and obtaining an API token from BotFather.
  • Setting a webhook and digesting updates with Express + body-parser.
  • Calling the Telegram sendMessage API with axios.
  • Deploying the bot to a public URL.

Core idea

Start with a fresh npm project and install the three libraries the bot needs:

shell## Create a new folder and enter it
mkdir my-telegram-bot
cd my-telegram-bot

## Initialize the npm project
npm init
npm install --save express axios body-parser

Then the server exposes the route Telegram will call on every message:

jsvar express = require("express")
var app = express()
var bodyParser = require("body-parser")
const axios = require("axios")

app.use(bodyParser.json()) // for parsing application/json
app.use(
	bodyParser.urlencoded({
		extended: true,
	})
) // for parsing application/x-www-form-urlencoded

// This is the route the API will call
app.post("/new-message", /* read the update and reply via sendMessage */)

Why it matters

The webhook model — traffic arrives at your server, you reply over HTTP — is the bedrock of modern chat bots, and this tutorial gives you a deployable example under 60 lines.
