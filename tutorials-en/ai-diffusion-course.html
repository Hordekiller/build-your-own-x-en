Diffusion Models for Image Generation

About

The Hugging Face Diffusion Course teaches image generation models from the ground up. This unit explains how diffusion models work — adding noise to images and learning to remove it — and then walks you through training a small UNet-based diffusion model on MNIST with the diffusers library.

What you'll learn

  • The intuition behind forward and reverse diffusion processes.
  • How a UNet denoises images step by step.
  • Schedulers: the noise schedule that controls the process.
  • Training a small model on MNIST with PyTorch and diffusers.
  • Sampling: generating brand-new images from pure noise.

Core idea

Diffusion is deceptively simple to implement: corrupt an image by mixing in noise, train a network to predict the noise back out, and at inference start from random noise and denoise repeatedly.

pythonimport torch
import torchvision
from torch.utils.data import DataLoader
from diffusers import DDPMScheduler, UNet2DModel

# Corrupt an image by mixing it with noise
def corrupt(x, amount):
    noise = torch.rand_like(x)
    amount = amount.view(-1, 1, 1, 1)  # reshape so broadcasting works
    return x * (1 - amount) + noise * amount

Why it matters

Diffusion models power Stable Diffusion and today's image generators. This course gives you the full intuition plus working code in one afternoon, and the later units extend the same ideas to text conditioning, CLIP and training larger models.
