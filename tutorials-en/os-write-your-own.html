About

A video course, 'Write your own Operating System', that builds a C++ kernel from the VGA text buffer upward.

What you'll learn

  • Writing characters directly to VGA text memory
  • Building a minimal C++ kernel and its build system
  • The path from print_char to interrupts and paging

Core idea

The first piece of the course is print_char(): a static VGA pointer at 0xB8000, row and column counters, and one character with its color attribute written into the text buffer.

C// the course's first code: print a character straight to the text screen
static void print_char(char c) {
  static uint16_t* vga = (uint16_t*)0xB8000;   // VGA text memory
  static uint8_t row = 0, col = 0;
  vga[row * 80 + col] = (0x0F << 8) | c;

Why it matters

Seeing a kernel built in C++ — the same language many already know — makes OS development feel instantly accessible.
