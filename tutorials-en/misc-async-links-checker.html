Writing a Link Checker

⚙ Language: Nim 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Writing a Link Checker"
↗ Visit the original tutorial فارسی — Persian version

About

Check hundreds of links concurrently with Nim's asyncdispatch: same async/await event loop as Node.js, futures for every request, and await-all to finish in seconds instead of minutes.

What you'll learn

  • async/await with an event loop (no OS operators)
  • Building a future per link and awaiting them together
  • failOnError: false for partial results

Core idea

Each checkLink is an async proc; the main loop gathers a seq of futures and awaits all(futures) - the event loop fires every request on the network simultaneously.

Nimimport asyncdispatch, httpclient

proc checkLink(url: string): Future[(string, bool)] {.async.} =
  try:
    let client = newAsyncHttpClient()
    let resp = await client.head(url)  # only headers
    client.close()
    result = (url, resp.status in {Http200, Http301, Http302})
  except:
    result = (url, false)

proc main() {.async.} =
  var futures: seq[Future[(string, bool)]]
  for link in links:
    futures.add(checkLink(link))
  # wait for all of them at once
  let results = await all(futures)
  for (url, ok) in results:
    echo (if ok: "OK " else: "BROKEN "), url

Why it matters

The same idea powering Node.js, exercised hands-on: concurrency for I/O-bound work without threads.
