The Super Tiny Compiler

About

The Super Tiny Compiler by James Kyle compresses a compiler skeleton into about 200 lines of JavaScript - Lisp-like input (add 2 (subtract 4 2)) to C-like output (add(2, subtract(4, 2))). This Go port follows the same path with explicit types and clean functions.

What you'll learn

  • The four stages: tokenizer, parser (AST), transformer, code generator
  • A traverser with enter/exit visits that walks the AST recursively
  • Because the input is tiny, you focus on concepts, not language details

Core idea

Three functions - tokenizer, parser, transformer (with inner traverser) - plus a code generator print the output. The famous trick is the traverser visiting AST nodes with enter/exit phases.

Go// transform nodes: calls become CallExpressions
func transform(node *Node, parent *Node) {
    switch n := (*node).(type) {
    case *NumberLiteral:
        // convert into an output NumberLiteral
    case *CallExpression:
        // part 1: callee becomes a separate CallExpression
        expression := &CallExpression{Callee: n.Callee, Arguments: []Node{}}
        // part 2: recurse over arguments with the new node as parent
        for _, arg := range n.Arguments {
            transform(&arg, expression)
        }
    }
}

Why it matters

The best first compiler: short, readable and tested. The Go port is great for fans of explicit types; the JavaScript original is the fastest conceptual intro.
