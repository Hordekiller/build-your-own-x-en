Let's code a web server from scratch with NodeJS Streams

About

Build a simple web server from zero with NodeJS: review how the built-in http module helps, then look inside the structure of an HTTP request and response, and finally build a low-level TCP server with the net module that you turn into a usable web server.

What you'll learn

  • What the built-in http module gives you - and what it hides
  • Anatomy of an HTTP request: request line, headers, empty line, body
  • Converting a raw TCP net server into an HTTP server (Stream API)

Core idea

Each header line is field: value, headers end with an empty line, and everything after is the request body - whose length matches the Content-Length header.

JavaScriptconst http = require('http');

const server = http.createServer();
server.on('request', (req, res) => {
  console.log(`${new Date().toISOString()} - ${req.method} ${req.url}`);
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello World!');
});
server.listen(3000);

Why it matters

Explains exactly what the http module does for you before teaching you to replace it - a great mental model of Node's networking stack.
