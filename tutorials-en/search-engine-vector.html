About

Build a vector-space search engine in Python: a concordance of all terms, document vectors, and cosine similarity ranking.

What you'll learn

  • Ranking with cosine similarity via dot products and norms

Core idea

Every document becomes a vector of term counts, with the concordance mapping words to indices. Similarity between a query and a document is the cosine of the angle between their vectors.

Pythonfrom math import sqrt, acos

def dot(vec_a, vec_b):
    return sum(a * b for a, b in zip(vec_a, vec_b))

def norm(vec):
    return sqrt(sum(x * x for x in vec))

def cosine(a, b):
    return dot(a, b) / (norm(a) * norm(b))

Why it matters

The vector-space model underlies modern retrieval and even embeddings; implementing it once makes rankings intuitive, not magical.
