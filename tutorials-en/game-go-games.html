About

A playlist making simple to medium games (platformers, divers, puzzles) in Go. With goroutines, garbage collection and fast compilation - plus the Ebiten library - Go is a great fit for game development.

What you'll learn

  • The Ebiten Game interface: Update (logic/input), Draw (render), Layout (window)
  • The basic loop: game state, input handling and sprite rendering
  • A fun side benefit: learning Go through small playable games

Core idea

Every game is a struct implementing Ebiten's Game interface; ebiten.RunGame runs the loop. State is plain fields updated in Update() and drawn in Draw().

Gopackage main

import (
    "log"
    "github.com/hajimehoshi/ebiten/v2"
)

// every game is a struct implementing the Game interface
type Game struct {
    playerX, playerY float64
}

// update logic: input and physics
func (g *Game) Update() error {
    if ebiten.IsKeyPressed(ebiten.KeyArrowLeft)  { g.playerX -= 2 }
    if ebiten.IsKeyPressed(ebiten.KeyArrowRight) { g.playerX += 2 }
    return nil
}

// render: draw the scene
func (g *Game) Draw(screen *ebiten.Image) {
    // draw the player rectangle on screen
}

func (g *Game) Layout(outsideWidth, outsideHeight int) (int, int) {
    return 640, 480
}

func main() {
    ebiten.SetWindowSize(640, 480)
    ebiten.SetWindowTitle("My Go Game")
    if err := ebiten.RunGame(&Game{}); err != nil {
        log.Fatal(err)
    }
}

Why it matters

Know Go and want to start game development? This is a great entry point - and if you don't know Go, building a small Ebiten game is one of the most fun ways to learn it.
