Build your own 3D renderer

⚙ Language: Java / JavaScript 📁 3D Renderer 🌐 English page 🔗 Original source
Original source: "Build your own 3D renderer" by Avik Das — an interactive, math-first introduction to ray tracing built for the web with three.js-free rendering.
↗ Visit the original tutorial فارسی — Persian version

About

Avik Das's interactive article builds a real raytracer piece by piece, in a web page that renders as you read. It starts with pure math — vectors and their operations — and ends with spheres, lighting, shadows and reflections, all implemented in JavaScript with an optional Java port.

What you'll learn

  • Vectors as the fundamental tool: addition, scaling and the dot product.
  • Rays, camera setup and the image plane.
  • Ray-sphere intersection, computed from the quadratic formula.
  • Lambertian shading and the role of surface normals.
  • Specular highlights, shadows and recursive reflections.

Core idea

The article grounds everything in geometry you can visualize. Intersection is just solving a quadratic: a ray is a point plus a direction, a sphere is a center and a radius, and their collision is found by substituting one equation into the other.

mathv = <x, y, z>                          // a 3D vector
v1 = <a, b, c>
v2 = <d, e, f>
v1 + v2 = <a + d, b + e, c + f>          // addition is component-wise
v2 - v1 = <d - a, e - b, f - c>

With those four operations you can already describe cameras, directions and surfaces — and therefore render a sphere.

Why it matters

It is one of the most gentle possible entries into graphics math: every equation is accompanied by an interactive 3D visualization. If the math-heavy books feel intimidating, this article gives you the intuition first, with code that fits on one screen.
