Writing Scalable Chat Service from Scratch

⚙ Language: Rust 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Writing Scalable Chat Service from Scratch"
↗ Visit the original tutorial فارسی — Persian version

About

A group chat service in Rust solving two classic problems: broadcasting messages to all users (PUB/SUB with ZeroMQ) and a stable message format between server and clients (Protocol Buffers instead of ad-hoc text).

What you'll learn

  • The PUB/SUB pattern with ZeroMQ sockets
  • Defining messages in .proto and generating typed code
  • Backward-compatible extensions through field numbering

Core idea

The server is a PUB socket, clients are SUB subscribers that set an empty wildcard. Protobuf encodes username, content and timestamp compactly; explicit field numbers allow extending the schema without breaking old clients.

Rust// server side (broadcast)
let ctx = zmq::Context::new();
let publisher = ctx.socket(zmq::PUB).unwrap();
publisher.bind("tcp://*:5555").unwrap();

// client side (receive everything)
let subscriber = ctx.socket(zmq::SUB).unwrap();
subscriber.connect("tcp://server:5555").unwrap();
subscriber.set_subscribe(b"").unwrap();  // all topics

loop {
    let msg = subscriber.recv_string(0).unwrap();
    println!("{}", msg.unwrap());
}

Why it matters

The two standard answers to chat's hard problems - pub/sub routing and versioned encoding - in one project.
