Hack the virtual memory

About

Hack the virtual memory: read and write another running process's memory directly through /proc — no ptrace, no kernel modules.

What you'll learn

  • What /proc/<pid>/mem exposes and how to open it
  • Reading a process's memory with pread()
  • Writing into a live process's memory with pwrite()

Core idea

The file /proc/<pid>/mem is the process's address space. read_byte() opens it and pread()s a single byte at an address; write_byte() does the same with pwrite() — memory modification of a live process in ~20 lines.

c// read one byte from the memory of a live process
int read_byte(pid_t pid, long addr) {
    char path[64];
    snprintf(path, sizeof path, "/proc/%d/mem", pid);

    int fd = open(path, O_RDONLY);
    char byte;
    pread(fd, &byte, 1, addr);
c// change one byte in the memory of a live process
int write_byte(pid_t pid, long addr, char value) {
    char path[64];
    snprintf(path, sizeof path, "/proc/%d/mem", pid);

    int fd = open(path, O_WRONLY);
    pwrite(fd, &value, 1, addr);

Why it matters

Virtual memory stops being abstract the first time you edit a running program's string from the outside — and this is the cleanest way to do it.
