About

Operating systems development for Dummies: a friendly walkthrough from a blank file to a kernel that prints to the screen.

What you'll learn

  • VGA text memory at 0xB8000 and text/attribute pairs
  • The kernel_main entry point
  • Compiling and linking a bootable kernel image

Core idea

The whole first milestone is kernel_main(): take the VGA text buffer at 0xB8000 and write characters and colors into it. Two arrays and a loop later, your kernel is printing.

c// kernel.c — the main kernel loop
void kernel_main(void) {
    char *video = (char *) 0xB8000;   // VGA text memory

    video[0] = 'H';
    video[1] = 0x07;            // attribute: white on black
