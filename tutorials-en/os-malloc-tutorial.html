About

A malloc tutorial: implement malloc and free as a linked list of blocks with alignment, splitting, and validation — checked with valgrind.

What you'll learn

  • The block_meta header: size, next pointer and a free flag
  • 8-byte alignment and requesting memory with sbrk
  • Validating pointers and keeping the allocator valgrind-clean

Core idea

The heap is a linked list of block_meta headers. malloc() aligns the requested size, walks the list, and if no block fits, asks the OS for more with sbrk. free() locates the header, validates it, and marks the block unused.

    size_t size;          // size of this block's data
    struct block_meta *next;  // next block in the list
    int free;             // 1 = free, 0 = in use
