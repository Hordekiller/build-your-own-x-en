Building a DNS server in Rust

⚙ Language: Rust 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Building a DNS server in Rust"
↗ Visit the original tutorial فارسی — Persian version

About

A DNS server in Rust, byte by byte: parse binary messages with a BytePacketBuffer, decode big-endian fields and length-prefixed labels, then forward queries to an upstream resolver (8.8.8.8) and return the answer - a real relay DNS server.

What you'll learn

  • Reading binary protocols with big-endian byte order
  • DNS name format: consecutive labels without null terminators
  • Forwarding: relay queries upstream and answer the caller

Core idea

Labels are stored consecutively (length + characters), big-endian throughout. A forwarded response returns to the exact SocketAddr captured by recv_from - that address is the glue.

Rustfn handle_query(socket: &UdpSocket, buf: &mut [u8]) -> Result<()> {
    // read the user's query and remember where it came from
    let (size, src) = socket.recv_from(buf)?;
    let query = Packet::from_buffer(&mut BytePacketBuffer::new(&buf[..size]))?;

    // forward to an upstream resolver
    let mut resolver = UdpSocket::bind("0.0.0.0:0")?;
    resolver.send_to(&buf[..size], "8.8.8.8:53")?;

    let mut response = [0u8; 512];
    let (n, _) = resolver.recv_from(&mut response)?;

    // answer the caller at their exact source address
    socket.send_to(&response[..n], src)?;
    Ok(())
}

Why it matters

All the concepts of binary systems - endianness, labels, relays - in one small protocol with a real purpose.
