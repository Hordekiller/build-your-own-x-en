About

A neural network OCR system in C#: render letters from fonts, convert each glyph to a pixel vector, and train a network to classify them.

What you'll learn

  • Turning a bitmap into a normalized input vector
  • Designing a network: 144 inputs, a hidden layer, and one output per character
  • Sigmoid activation and training with AForge.NET

Core idea

Each character is rendered with DrawChar() and then flattened into a vector of grayscale pixel values. The network receives that vector and outputs a score for every letter in the alphabet.

csharp// define a neural network: 144 inputs, 50 hidden neurons, one output per letter
NeuralNetwork network = new ActivationNetwork(
    new SigmoidFunction(2),     // sigmoid activation
    144, 50, 26);
csharp// render a printed letter from a font and turn it into a network input
Bitmap bitmap = DrawChar(letter, font, size);
double[] input = ImageToVector(bitmap);   // grayscale of each pixel, normalized to 0..1

Why it matters

OCR is a complete pattern-recognition pipeline in one project: capture, preprocessing, training and classification.
