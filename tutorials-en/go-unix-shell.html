Writing a simple shell in Go

About

A simple Unix shell in Go: a read-eval-print loop that executes commands and reports errors like a real sh.

What you'll learn

  • A REPL built on bufio and os.Stdin
  • exec.Command and capturing command output
  • The classic pitfall: passing a whole command string instead of arguments

Core idea

The loop reads a line, trims the newline, and runs it with exec.Command. The tutorial joyfully reproduces a classic pitfall - passing 'ls -l' as a single string instead of splitting it.

Gofunc main() {
    reader := bufio.NewReader(os.Stdin)
    for {
        fmt.Print("> ")
        input, err := reader.ReadString('\n')
        if err != nil {
            fmt.Println(err)
        }
