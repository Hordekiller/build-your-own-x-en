About

A Wikibooks classic (growing since 2007) that teaches Haskell practically by building a complete Scheme interpreter: data representation, environments, evaluation and IO.

What you'll learn

  • Haskell concepts through a real project: function composition, Functor/Monad, Parsec
  • Compiler concepts: data representation, environments, evaluation, error handling
  • Adding data types, variables (State monad, define/set!), lambdas and real IO

Core idea

Seven chapters move from simple evaluation of numbers and atoms, through Parsec parsing and LispVal data types, to environments with the State monad, closures and finally real IO.

Haskelldata LispVal = Atom String | List [LispVal] | DottedList [LispVal] LispVal
              | Number Integer | String String | Bool Bool

-- the heart of the interpreter: evaluation
(eval env (List [Atom "quote", val])) = return val
(eval env (List [Atom "if", cond, t, f])) = do
    result <- eval env cond
    case result of Bool False -> eval env f
                    _         -> eval env t
(eval env (List (Atom func : args))) = do
    funcVal <- eval env (Atom func)
    argVals <- mapM (eval env) args
    apply funcVal argVals

Why it matters

The best start for combining "build an interpreter" with "Haskell": short, step-by-step, community-supported - deep dive with Write You a Haskell afterwards.
