Build Your Own Cache

⚙ Language: Kotlin 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Build Your Own Cache"
↗ Visit the original tutorial فارسی — Persian version

About

CacheLite: a correct LRU cache in Kotlin. The combination of a HashMap (fast lookup) and a doubly linked list (usage order) gives O(1) get and set with eviction of the least-recently-used entry.

What you'll learn

  • Why LRU needs HashMap + doubly linked list together
  • moveToTail on access, evictHead when full
  • Kotlin operator overloading for natural get/set syntax

Core idea

Every key maps to a node in the linked list; using an entry moves it to the tail (youngest), and overflow evicts the head (oldest).

Kotlinclass CacheLite<K, V>(private val capacity: Int) {
    private class Node<K, V>(val key: K, var value: V) {
        var prev: Node<K, V>? = null
        var next: Node<K, V>? = null
    }

    private val map = HashMap<K, Node<K, V>>()
    private var head: Node<K, V>? = null   // oldest
    private var tail: Node<K, V>? = null   // newest

    operator fun get(key: K): V? =
        map[key]?.also { moveToTail(it) }?.value

    operator fun set(key: K, value: V) {
        val existing = map[key]
        if (existing != null) {
            existing.value = value
            moveToTail(existing)
        } else {
            val node = Node(key, value)
            map[key] = node
            appendTail(node)
            if (map.size > capacity) evictHead()
        }
    }
}

Why it matters

The cache policy used by OSes, databases and browsers fits in one small class - and stays O(1).
