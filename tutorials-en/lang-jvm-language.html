Creating JVM Language

About

Enkel is a simple Java-like language that generates JVM bytecode directly - the compiler output runs with the java command, making the JVM a safe island for your language.

What you'll learn

  • Generating bytecode with the ASM library: method visitors, ILOAD/BIPUSH/IADD/ISTORE
  • JVM structure: the operand stack, local variable table, this at index 0
  • Reading your output with javap -c and comparing it to javac output

Core idea

The series covers language design and AST, lexer/parser (hand-written or Antlr), bytecode generation with ASM, variables/functions/conditionals/loops/classes/inheritance, and error reporting.

Java// bytecode for compute(int x): return x + 3 - with ASM
MethodVisitor mv = cw.visitMethod(
    Opcodes.ACC_PUBLIC, "compute", "(I)I", null, null);

mv.visitVarInsn(Opcodes.ILOAD, 1);   // push local var 1 (x)
mv.visitIntInsn(Opcodes.BIPUSH, 3);   // push constant 3
mv.visitInsn(Opcodes.IADD);           // add the two ints
mv.visitVarInsn(Opcodes.ISTORE, 1);   // store the result back

Why it matters

For Java fans wanting to understand JVM languages like Kotlin and Scala: from lexer to a runnable .class file with real examples.
