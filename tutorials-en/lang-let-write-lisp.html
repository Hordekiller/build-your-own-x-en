Let’s go write a Lisp

About

A golden old-timer building a Lisp interpreter bottom-up in JavaScript: data representation and primitives first, then the parser, then closures and environments.

What you'll learn

  • Closures: a function must carry its defining environment - what gives Lisp its meaning
  • Sequential evaluation (begin), conditionals (if) and recursion
  • The difference between eval and apply; nested child environments

Core idea

A function call builds a child of the defining environment, binds parameters, then evaluates the body in it. Compared to Little Lisp, this article makes nested scope explicit - the foundation for understanding any language.

JavaScript// build the local environment for a function call
function callLispFunction(closure, args) {
    var localEnv = cloneEnvironment(closure.env);  // child of defining env
    closure.params.forEach(function (param, i) {
        localEnv[param] = args[i];    // bind parameters
    });
    // evaluate the body in the local environment
    return evalLisp(closure.body, localEnv);
}

Why it matters

A fun, instructive afternoon: building a Lisp interpreter from scratch in JavaScript with emphasis on environments and closures - then push on to quotes, macros and GC.
