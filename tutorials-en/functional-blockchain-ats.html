Functional Blockchain

⚙ Language: ATS 📁 Blockchain / Cryptocurrency 🌐 English page 🔗 Original source
Original source: "Functional Blockchain — A Brief Introduction to ATS" — Lance Galletti's article that builds a small blockchain in the ATS programming language.

About

A gentle introduction to the ATS language through a hands-on, functional blockchain. Lance Galletti uses ATS — a language that combines dependent types with functional and imperative programming — to model headers, blocks and the chain itself.

What you'll learn

  • The basics of ATS: syntax, types and the theorem-proving style.
  • Modeling a blockchain as algebraic data types.
  • Functionally handling hashing and block creation.
  • Reading code written in a statically typed functional language.

Core idea

After cloning the ATS toolchain, you define the domain types directly. A header carries the block's metadata, a block joins that header with its hash and timestamp, and the chain is simply a list of blocks:

atstypedef header = (int, int, data, result, queries, hash)
typedef block = (header, hash, string)
typedef chain = list0(block)

Why it matters

Most blockchain tutorials use OOP languages; this one shows that a ledger is naturally a functional data structure — a linked list of blocks — and that strong typing catches protocol mistakes at compile time.
