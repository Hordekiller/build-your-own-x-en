About

A RISC-V operating system tutorial in Rust: from boot and trap handling to processes and scheduling, on real RISC-V emulators.

What you'll learn

  • RISC-V assembly and the save_context pattern
  • Traps, exceptions and interrupts on RISC-V
  • Building processes and a scheduler in Rust

Core idea

Context switching on RISC-V is explicit: a save_context routine reserves 264 bytes on the stack and stores every general-purpose register there, giving each process its own frozen CPU state.

rust// save a process's full context on the stack
core::arch::global_asm!(
    "save_context:",
    "addi sp, sp, -264",      // room for all the registers
    "sd ra,   0(sp)",
    "sd gp,   8(sp)",
    // ... all the general-purpose registers
    "sd s0,  24(sp)"

Why it matters

RISC-V is the ISA everyone is building toward; learning OS development on it with Rust puts you ahead of the curve.
