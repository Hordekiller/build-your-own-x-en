How To Create a Telegram Bot Using Python

⚙ Language: Python 📁 Bot 🌐 English page 🔗 Original source
Original source: "How to create a Telegram bot with Python" — a freeCodeCamp tutorial by Athul Cyriac Ajay with a music-crafting twist: a bot that searches songs and plays previews.
↗ Visit the original tutorial فارسی — Persian version

About

A beginner-friendly Telegram bot with pyTelegramBotAPI: set a token from BotFather, register command and message handlers with decorators, and layer a real feature on top — searching songs with the Deezer API and sending audio previews.

What you'll learn

  • Creating a bot with BotFather and exporting its token.
  • Installing pyTelegramBotAPI and bootstrapping the client.
  • Command and message handlers with decorators.
  • Calling a music search API and sending results.

Core idea

The setup is small and immediate — install, export the token, and connect:

shellpip install pyTelegramBotAPI
export BOT_TOKEN=your-bot-token-here
pyimport os

import telebot

BOT_TOKEN = os.environ.get('BOT_TOKEN')

bot = telebot.TeleBot(BOT_TOKEN)

Handlers read like the API documentation itself:

py@bot.message_handler(commands=['start', 'hello'])
def send_welcome(message):
    bot.reply_to(message, "Howdy, how are you doing?")

@bot.message_handler(func=lambda msg: True)
def echo_all(message):
    bot.reply_to(message, message.text)

Why it matters

The decorator-based handler model makes bot logic legible from the first minute, and the music search feature shows how to move from "bot skeleton" to a genuinely useful tool in one sitting.
