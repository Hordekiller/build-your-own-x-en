About

This is a whole book, released as manuscripts: from your first hash to an open-ended full blockchain — blocks, transactions, Merkle trees, mining, and beyond — with Ruby as the implementation language and a "keep it simple" philosophy throughout.

What you'll learn

  • Hashing from the first line: Digest::SHA256.
  • Blocks, chains and hash linkage.
  • Transactions, inputs/outputs and Merkle trees.
  • Proof-of-work mining and network-level topics.
  • Design decisions and real-world trade-offs.

Core idea

The journey starts with the tiniest building block of crypto — a single hash:

rubyrequire 'digest'

Digest::SHA256.hexdigest( 'Hello, Cryptos!' )
ruby#=> "33eedea60b0662c66c289ceba71863a864cf84b00e10002ca1069bf58f9362d5"

From that single call, the book builds upward: block, chain, transactions, mining, networking — each layer tested and explained with plain English.

Why it matters

Few resources bring together depth, breadth and readability like a good book — and this one is free. The Ruby code is clean, the exercises are honest, and the manuscript format means you can even contribute corrections.
