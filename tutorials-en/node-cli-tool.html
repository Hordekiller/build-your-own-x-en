Create a CLI tool in Javascript

⚙ Language: Node.js 📁 Command-Line Tool 🌐 English page 🔗 Original source

About

A complete, modern path to a distributable CLI: initialize two npm projects — one for your tool, one as a test project — write the executable, link it with npm so it runs from anywhere, and verify the workflow before publishing.

What you'll learn

  • Structuring a tool package and a test project.
  • Using bin in package.json.
  • Linking and running the CLI with npm link.
  • Testing the command against a real folder.

Core idea

Two folders, two npm projects — the separation makes testing honest:

shell$ mkdir tool-tutorial
$ cd tool-tutorial
tool-tutorial$ mkdir tool
tool-tutorial$ mkdir testProject

Initialize each one, and the tool's bin field makes it executable:

shelltool-tutorial$ cd tool
tool-tutorial/tool$ npm init -y
// ...
tool-tutorial/tool$ cd ../testProject
tool-tutorial/testProject$ npm init -y
// ...

Why it matters

Most CLI tutorials stop at the code; this one takes you through the full author→link→run cycle, so the tool becomes a real command on your machine — and you understand what npm does when you publish it.
