About

Docker implemented in around 100 lines of bash: btrfs subvolumes, cgroups, chroot and veth networks — the whole container stack scripted with pure shell.

What you'll learn

  • The entire container surface in one bash script
  • btrfs subvolumes as image/container layers
  • cgroups for resource limiting, chroot for isolation
  • Networking containers with veth links and iptables

Core idea

Everything is one file, and every function is a docker command:

sh#!/usr/bin/env bash
set -o errexit -o nounset -o pipefail; shopt -s nullglob
btrfs_path='/var/bocker' && cgroups='cpu,cpuacct,memory';
[[ $# -gt 0 ]] && while [ "${1:0:2}" == '--' ]; do OPTION=${1:2}; [[ $OPTION =~ ^.*=.* ]] && OPTION=${OPTION%%=*}; case $OPTION in
  help) echo ...; exit 0;; esac; shift; done
shfunction bocker_check() {
	btrfs subvolume list "$btrfs_path" | grep -qw "$1" && echo 0 || echo 1
}
shfunction bocker_rm() { #HELP Delete an image or container:
BOCKER rm <image_id or container_id>
	[[ "$(bocker_check "$1")" == 1 ]] && echo "No container named '$1' exists" && exit 1
	btrfs subvolume del "$btrfs_path/$1" >/dev/null
}

Why it matters

The ultimate proof of concept: if a working container runtime fits in a shell script, the underlying ideas are simple — and now they're yours to read and modify.
