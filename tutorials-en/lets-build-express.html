About

A series building the Express library from scratch, chapter by chapter. Starts where most developers get confused: how next works and how route ordering behaves. Ends with a tiny library that matches one route, then grows into the real abstractions.

What you'll learn

  • How createApplication, app and the router fit together
  • The Layer and Route objects and per-route handler stacks
  • What lazyrouter() does and why app methods return this

Core idea

The app is just a function with methods; every HTTP verb iterates the methods package to add a route, and the router keeps a stack of layers - layers being the real heart of Express.

JavaScriptvar methods = require('methods');

methods.forEach(function (method) {
  app[method] = function (path) {
    this.lazyrouter();
    var route = this._router.route(path);
    route[method].apply(route, slice.call(arguments, 1));
    return this;
  };
});

app.lazyrouter = function lazyrouter() {
  if (!this._router) {
    this._router = new Router({});
  }
};

Why it matters

Reading real Express source becomes trivial once you have built the same shapes yourself - and the series keeps every chapter small.
