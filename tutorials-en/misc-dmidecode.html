Writing a DMIDecode Parser

⚙ Language: Nim 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Writing a DMIDecode Parser"
↗ Visit the original tutorial فارسی — Persian version

About

Parse dmidecode output in Nim: the tool reads hardware info (motherboard, BIOS, memory, serial numbers) from SMBIOS/DMI tables and prints structured sections - perfect raw material for a line-based parser.

What you'll learn

  • The dmidecode output format: Handle lines start sections
  • Distinguishing section names from indented fields
  • Building typed records for servers' inventory automation

Core idea

Each section starts with a Handle line carrying DMI type and size, the next line is the section name, and subsequent indented lines are field: value pairs - two rules parse the whole output.

Nimimport strutils, tables

type DmiRecord = object
  dmiType: int
  name: string
  fields: Table[string, string]

proc parseDMI(content: string): seq[DmiRecord] =
  var current: DmiRecord = DmiRecord()
  var inRecord = false
  for line in content.splitLines():
    if line.startsWith("Handle"):
      if inRecord: result.add(current)
      # e.g. Handle 0x0001, DMI type 1, 27 bytes
      let m = line.findAll("\d+")
      current = DmiRecord(dmiType: parseInt(m[1]),
                          name: "", fields: initTable[string, string]())
      inRecord = true
    elif line.startsWith(" ") and inRecord:
      let parts = line.strip().split(":", 1)
      if parts.len == 2: current.fields[parts[0]] = parts[1].strip()
    elif inRecord and not line.startsWith(" "):
      current.name = line.strip()
  if inRecord: result.add(current)

Why it matters

A real-world parsing task with an irregular text format - the perfect parser exerciser (40+ DMI types left to you).
