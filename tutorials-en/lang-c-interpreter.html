About

One of the most ambitious tutorials: a complete C interpreter written in C that is mature enough to interpret itself - it reads its own source files and runs them.

What you'll learn

  • A real (subset) C grammar: struct, enum, pointer, typedef, arrays, implicit int
  • Evaluation with a numbered heap (make_label) so pointers become indices
  • Scope with nested blocks (zset/zget) and functions with a function table

Core idea

The code is split into small files, each a learning stage: lexer (source to tokens), parser (tokens to AST), eval (AST execution). Self-interpretation - fixing the bugs of the interpreter running itself - is the best lesson of all.

Cvoid eval(struct AST_node *ast) {
    if (!ast) return;
    switch (ast->type) {
    case NODE_EXPR:   handle_expr(ast);  break;
    case NODE_ASSIGN: handle_assign(ast); break;
    case NODE_IF:
        if (is_true(eval_expr(ast->cond)))
            eval(ast->then_body);
        else if (ast->else_body)
            eval(ast->else_body);
        break;
    case NODE_WHILE:
        while (is_true(eval_expr(ast->cond)))
            eval(ast->body);
        break;
    }
}

Why it matters

To understand how C really works - not just its syntax - this project teaches pointer behaviour, scope structure and function implementation, and self-execution is a sweet payoff.
