Understanding Parser Combinators

⚙ Language: F# 📁 Programming Language 🌐 English page 🔗 Original source
Original source: "Understanding Parser Combinators"

About

Instead of writing one parser per language, combinators are small functions that combine to build parsers. Scott Wlaschin teaches the idea in F#, transferable to any language (Rust, Go and JavaScript ports exist).

What you'll learn

  • A parser is a function: input string in, either success (result + rest) or failure
  • The basic combinators: andThen, orElse, many - enough to define whole grammars
  • Why combinators struggle with left recursion, and how monads keep errors and state clean

Core idea

Three primitives (preturn, pzero, satisfy) plus structural combinators (andThen, orElse, many) build complex parsers. The article builds a calculator with operator precedence and a JSON parser, all in combinator style.

F#type Parser<'a> = string -> Result<'a * string, string>

// p1 and then p2
let andThen p1 p2 = fun input ->
    match p1 input with
    | Error e      -> Error e
    | Ok (r1, rest) ->
        match p2 rest with
        | Error e      -> Error e
        | Ok (r2, rest2) -> Ok ((r1, r2), rest2)

// p1 or p2
let orElse p1 p2 = fun input ->
    match p1 input with
    | Ok r     -> Ok r
    | Error _  -> p2 input
F#let number =
    many1 digitChar |>> toInt      // one or more digits to int

// expr := number (("+"|"-") number)*
let expr =
    number .>>. many (op .>>. number)

Why it matters

Find out what parsers are made of - without heavyweight frameworks - then reuse the idea in real DSLs and interpreters.
