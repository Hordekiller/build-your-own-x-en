About

The Little OS Book: a compact tutorial that takes you from a blank file to a working kernel in C and assembly.

What you'll learn

  • Writing a boot sector and loading the kernel
  • Setting up the GDT and switching to 32-bit mode
  • Linking and running your first kernel

Core idea

The 32-bit switch is a short ritual: disable interrupts, load the GDT, set bit 0 of cr0, and jump. From that point on, the code can run 32-bit C.

nasm; enter 32-bit mode from the 16-bit bootloader
[bits 16]

switch_to_32:
    cli                     ; disable interrupts (no 32-bit ISRs yet)
    lgdt [gdt_descriptor]   ; load the GDT
    mov eax, cr0
    or  eax, 0x1
    mov cr0, eax

Why it matters

It is the shortest reliable path from 'nothing' to a bootable kernel — ideal as a first OS project.
