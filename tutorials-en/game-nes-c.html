How to Program an NES game in C

⚙ Language: C 📁 Game 🌐 English page 🔗 Original source
Original source: "How to Program an NES game in C"

About

NES development teaches low-level programming and constraint-based design: the Ricoh 2A03 (a 6502 clone at 1.79 MHz), 2 KB of RAM and a separate graphics chip (PPU). These tutorials (lessons 01-24+) each cover one topic.

What you'll learn

  • Sprite structure in OAM: 4 bytes per sprite (y, tile, attr, x)
  • CHR-ROM for 8x8 tiles and nametables for placing them on a 32x30 grid
  • Reading the controller bits and moving sprites

Core idea

Graphics on the NES means arranging 8x8 tiles on a 32x30 grid. Global OAM holds 64 sprites; a simple move routine reads the pad bits and shifts sprite positions.

C// a simple sprite in OAM (sprite attribute RAM)
// each sprite is 4 bytes: y, tile number, attributes, x
struct sprite {
  unsigned char y;
  unsigned char tile;
  unsigned char attr;
  unsigned char x;
};

// global OAM - 64 sprites
struct sprite sprites[64];

// move a sprite with the controller
void move_sprite(void) {
  if (pad & PAD_LEFT)  sprites[0].x -= 1;
  if (pad & PAD_RIGHT) sprites[0].x += 1;
  if (pad & PAD_UP)    sprites[0].y -= 1;
  if (pad & PAD_DOWN)  sprites[0].y += 1;
}

Why it matters

Building for such strict hardware gives deep insight into low-level programming, memory management and constraint-based design - and it's fun!
