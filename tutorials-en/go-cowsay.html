Building a cli command with Go: cowsay

About

A Go version of the legendary cowsay. The tutorial teaches the core trick first: detect whether stdin is a pipe, read it rune by rune, then print a speech bubble around an ASCII cow — paying homage to the original Perl implementation's license along the way.

What you'll learn

  • Detecting pipes vs. interactive terminals with os.Stdin.Stat().
  • Reading input rune by rune with bufio.
  • Formatting text into a speech bubble.
  • Combining ASCII art with dynamic input.

Core idea

Everything pivots on one check: is the input piped, or a terminal?

gopackage main

import (
	"bufio"
	"fmt"
	"io"
	"os"
)

	info, _ := os.Stdin.Stat()
