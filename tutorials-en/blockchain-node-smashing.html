Writing a Blockchain in Node.js

⚙ Language: JavaScript 📁 Blockchain / Cryptocurrency 🌐 English page 🔗 Original source
Original source: "Writing a Blockchain in Node.js" — a Smashing Magazine tutorial by Rodrigo Quesada that builds CryptoBlock, a working cryptocurrency with mining, wallets and signed transactions.
↗ Visit the original tutorial فارسی — Persian version

About

A polished, intermediate-level cryptocurrency in Node.js: blocks with SHA-256 hashes, proof-of-work mining, a blockchain class with validation, and a transaction system with asymmetric signing so users own their money cryptographically.

What you'll learn

  • The CryptoBlock class: fields, hashing and proof-of-work.
  • Chain structure, genesis block and validation.
  • Transactions with elliptic-curve signatures.
  • Wallets: key pairs, addresses and transaction signing.

Core idea

The chain is built from a single well-structured class:

javascript// Importing the SHA256 hash function from the crypto-js library
const SHA256 = require('crypto-js/sha256');

// Encrypted block class — the building blocks of the blockchain
class CryptoBlock{
    // Class constructor; initialized with an index, timestamps, data and the hash of the previous block
    constructor(index, timestamp, data, precedingHash=" "){
        this.index = index;            // block position in the chain
        this.timestamp = timestamp;    // transaction recording time
        this.data = data;
        this.precedingHash = precedingHash;
        this.hash = this.computeHash();
        this.nonce = 0;
    } // ...

The only runtime dependency remains the hash function:

shellnpm install --save crypto-js

Why it matters

Between toy chains and production systems, this tutorial is the sweet spot: real cryptography for wallets and signatures, yet still fully readable in a single sitting — an excellent preparation for Bitcoin Core era projects.
