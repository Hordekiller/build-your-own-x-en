Approach: Building a toy template engine in Python

About

A toy template engine in Python with {{var}} variables and {% block %} loops - a tiny Django/Jinja-style engine in one file.

What you'll learn

  • Tokenizing templates with a single regex
  • The {{var}} and {% each %} block syntax
  • Dot-access to variables and parent context via '..'

Core idea

All syntax maps to regex tokenization: {{...}} for variables and {% ... %} for blocks. Loops iterate items via 'it', while '..' reaches the parent context.

HTML<!-- variables go between double braces -->
<div>{{my_var}}</div>

<!-- blocks use {% %} and close with 'end' -->
{% each items %}
    <div>{{it}}</div>
{% end %}
HTML<!-- loop over people; 'it' is the current item -->
{% each people %}
    <div>{{it.name}}</div>
{% end %}

<!-- '..' means the parent context variable -->
Pythonimport re

VAR_TOKEN_START = '{{'
VAR_TOKEN_END = '}}'
BLOCK_TOKEN_START = '{%'
BLOCK_TOKEN_END = '%}'

TOK_REGEX = re.compile(r"(%s.*?%s|%s.*?%s)" % (
    VAR_TOKEN_START, VAR_TOKEN_END,
    BLOCK_TOKEN_START, BLOCK_TOKEN_END))

Why it matters

One file, zero dependencies - and you understand exactly how Jinja and its friends tokenize and render.
