A BitTorrent client in Python 3.5

About

Markus Eliasson's tutorial implements a working BitTorrent client in Python 3.5, organized as a small package with modules for bencoding, tracker interaction, the peer wire protocol and the overall download logic. The article is precise about the protocol — even opening with the formal grammar of bencode.

What you'll learn

  • The bencode grammar, expressed formally as a grammar rule set.
  • Implementing a decoder with Python's bytes types.
  • An encoder and the OrderedDict discipline it requires.
  • Tracker requests and parsing announce responses.
  • Peer connections, handshakes and the message loop.
  • Assembling pieces into the final file with hash checks.

Core idea

The protocol begins with a formal grammar — exactly four productions:

text<BE>    ::= <DICT> | <LIST> | <INT> | <STR>

<DICT>  ::= "d" 1 * (<STR> <BE>) "e"
<LIST>  ::= "l" 1 * <BE>         "e"
<INT>   ::= "i"     <SNUM>       "e"
<STR>   ::= <NUM> ":" n * <CHAR>; where n equals <NUM>

And once the decoder exists, it is immediately testable in a REPL:

python>>> from pieces.bencoding import Decoder

# An integer starts with 'i' and runs of digits until 'e'
>>> Decoder(b'i123e').decode()
123

# A string states its length first, then the characters.
# Note that the result is a binary string, not unicode.
>>> Decoder(b'12:Middle Earth').decode()
b'Middle Earth'

Why it matters

Python lets you focus on the protocol rather than the plumbing, and this client is a model of clarity: grammar first, package structure second, tests throughout. It is an ideal starting point before tackling more complex peer-to-peer systems.
