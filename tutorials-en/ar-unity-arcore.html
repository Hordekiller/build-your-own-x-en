How To Unity ARCore

About

ARCore is Google's platform for augmented reality on Android. This video playlist shows how to build ARCore applications with Unity and the AR Foundation framework — detecting planes, placing objects on them with a tap, and handling light estimation so virtual objects blend with the real scene.

What you'll learn

  • Setting up an AR Foundation project with ARCore support.
  • Plane detection: how the camera floor/wall detection works.
  • Raycasting touch points onto detected planes.
  • Instantiating 3D objects anchored to real-world surfaces.

Core idea

The key interaction is a raycast: your finger taps the screen, a ray is cast into the scene, and if it hits a detected plane, the object is placed exactly there.

C#// Raycast onto detected planes and place an object (AR Foundation)
if (arRaycastManager.Raycast(touchPos, hits,
        TrackableType.PlaneWithinPolygon)) {
    var pose = hits[0].pose;                    // the ray's hit position
    Instantiate(prefab, pose.position, pose.rotation);
}

Why it matters

Google's approach differs from marker-based AR: the world itself is the target. Knowing ARCore gives you the platform-agnostic AR Foundation pattern, which carries over to iOS's ARKit later — one codebase, two mobile platforms.
