Regular Expression Matching Can Be Simple And Fast

Original source: "Regular Expression Matching Can Be Simple And Fast — by Russ Cox"

About

Regular expression matching with a simulated NFA - the classic article by Russ Cox showing how grep-style matching can be simple, linear and fast.

What you'll learn

  • The core data structures: State and Frag
  • Building an NFA fragment by fragment with patch lists
  • Why Thompson's construction avoids catastrophic backtracking

Core idea

The secret is compilation: a regex becomes a graph of State nodes (each with char, out, out1 and a lastlist stamp) and Fragments - partially built graphs with a list of undefined outgoing pointers to patch later.

Cstruct State
{
	int c;
	State *out;
	State *out1;
	int lastlist;
};
Cstruct Frag
{
	State *start;
	Ptrlist *out;
};
CPtrlist *list1(State **outp);
Ptrlist *append(Ptrlist *l1, Ptrlist *l2);

void patch(Ptrlist *l, State *s);

Why it matters

Russ Cox explains why some regexes explode on pathological input - and the linear-time engine that avoids it. Required reading for systems programmers.
