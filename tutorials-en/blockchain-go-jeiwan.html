Building Blockchain in Go

⚙ Language: Go 📁 Blockchain / Cryptocurrency 🌐 English page 🔗 Original source
Original source: "Building Blockchain in Go" — a multi-part series by Ivan Kuznetsov (Jeiwan) that evolves a basic chain into a full blockchain with PoW, persistent storage and networking.
↗ Visit the original tutorial فارسی — Persian version

About

Jeiwan's famous series builds a blockchain step by step in Go: a minimal block chain first, then proof-of-work, then persistent storage with BoltDB, then transactions, wallets, addresses and finally peer-to-peer networking. Each part compiles and runs.

What you'll learn

  • Defining blocks and hashing them with SHA-256.
  • Implementing proof-of-work mining.
  • Persisting the chain in BoltDB and the UTXO set.
  • Transactions, wallets and Bitcoin-style addresses.
  • A peer-to-peer node network with command-line clients.

Core idea

Everything starts from a plain struct — a block that records data and links to the previous one:

Gotype Block struct {
	Timestamp     int64
	Data          []byte
	PrevBlockHash []byte
	Hash          []byte
}
Gofunc (b *Block) SetHash() {
	timestamp := []byte(strconv.FormatInt(b.Timestamp, 10))
	headers := bytes.Join([][]byte{b.PrevBlockHash, b.Data, timestamp}, []byte{})
	hash := sha256.Sum256(headers)

	b.Hash = hash[:]
}

Why it matters

It is one of the most complete end-to-end blockchain tutorials available. Because every layer — hashing, mining, storage, wallets, networking — is implemented by hand in a clean language, you end up understanding Bitcoin's design rather than just its vocabulary.
