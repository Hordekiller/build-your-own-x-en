Write your Own Virtual Machine

About

Write your own VM: a complete LC-3 virtual machine in C that runs real (if tiny) operating systems — the classic 'write your own virtual machine' guide.

What you'll learn

  • The LC-3 architecture: registers, memory, condition flags
  • Implementing 12 instructions including traps and subroutines
  • Loading a program image and running a real OS
  • Building the complete toolchain: assembler and VM

Core idea

The whole machine is eight 16-bit registers:

cuint16_t reg[R_COUNT];
cenum
{
    OP_BR = 0, /* conditional branch */
    OP_ADD,    /* addition    */
    OP_LD,     /* load        */
    OP_ST,     /* store       */
    OP_JSR,    /* jump to subroutine */
    OP_AND,    /* bitwise and */
    OP_LDR,    /* load via register */
    ...
};
cenum
{
    FL_POS = 1 << 0, /* P */
    FL_ZRO = 1 << 1, /* Z */
    FL_NEG = 1 << 2, /* N */
};

Why it matters

One weekend, one real architecture, twelve instructions — and a genuine OS booting in your own emulator. The canonical first VM for a reason.
