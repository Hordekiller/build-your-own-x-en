Loading and rendering 3D skeletal animations from scratch in C# and GLSL

About

Implement skeletal animation (skinning) from scratch: the bone hierarchy, loading animations from a simplified gLTF format, computing global bone matrices and a vertex shader that blends them with per-vertex weights.

What you'll learn

  • The skeleton: a hierarchy of bones with local transforms
  • global = parent * local: computing the final bone matrices
  • GPU skinning: inverse bind matrices, bone indices and weights in the shader

Core idea

Inverse bind matrices move vertices from model space into bone space, so only the bone's movement applies. Each vertex carries up to four bone indices and weights summed by the shader.

C#// compute all global bone matrices by walking the tree
void ComputeBoneMatrices(Bone[] bones, int parentIndex,
                         Matrix4<float> parentMatrix) {
    for (int i = 0; i < bones.Length; i++) {
        if (bones[i].parent != parentIndex) continue;

        Matrix4<float> local = bones[i].localTransform;
        Matrix4<float> global = local * parentMatrix;     // global = parent * local

        boneMatrices[i] = bones[i].inverseBindMatrix
                                       .Multiply(global);
        ComputeBoneMatrices(bones, i, global);
    }
}

Why it matters

Characters that walk instead of sliding are one shader multiply away - game animation demystified.
