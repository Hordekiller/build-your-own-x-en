Markdown compiler from scratch in Ruby

About

Markdown has light syntax but does exactly what a language does: transform textual structure into another representation. This tutorial walks a small compiler - from lexer to generator - with Markdown as input and HTML as output.

What you'll learn

  • A two-part architecture: Parser produces internal objects (heading, paragraph, bold), Generator turns them into HTML
  • Prefix parsing: patterns tested line by line; the first match generates the structure
  • Stateful blocks (lists, code fences) teach keeping a current traversal state; escaping prevents HTML injection

Core idea

Because the language's complexity is tiny, you focus on compiler architecture: parsing, mapping to a simple AST and unified output generation. Adding a rule is just one more small method.

Ruby# heading rule: a line starting with 1-6 hashes
def parse_heading(line, output)
  if line =~ /^(#{1,6})\s+(.*)$/
    level = $1.length
    text  = $2
    # convert to internal structure (AST)
    output << { type: :heading, level: level, text: render_inline(text) }
    true
  else
    false
  end
end

# bold pattern: *text* to <strong>text</strong>
def render_inline(text)
  text.gsub(/\*(.*?)\*/) { "<strong>#{$1}</strong>" }
end

Why it matters

The tutorial blurs the line between document format and programming language - a perfect first parsing project before real grammars like JSON or Lisp.
