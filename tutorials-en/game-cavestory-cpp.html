Remaking Cavestory in C++

About

A video series rebuilding Cave Story - the genre-defining indie platformer - in C++ from zero: movement, jump physics, weapons, enemies, scene engine and scrolling.

What you'll learn

  • Entity architecture with pure-virtual update/render and inheritance
  • Player physics: input-driven horizontal velocity, gravity and jump impulses
  • Camera/scene scrolling and the full game loop

Core idea

Every entity derives from a base class exposing update(dt) and render(); the player combines input, gravity, jumping and collision resolution.

C++class Entity {
public:
  Vector2 position, velocity;
  bool grounded;
  virtual void update(float dt) = 0; // per-entity logic
  virtual void render() = 0;         // per-entity drawing
};

class Player : public Entity {
public:
  void update(float dt) override {
    // input drives horizontal velocity
    velocity.x = input * MOVE_SPEED;
    // gravity
    velocity.y += GRAVITY * dt;
    if (jump_pressed && grounded)
      velocity.y = -JUMP_SPEED;
    position += velocity * dt;
    resolve_collisions();
  }
};

Why it matters

By the end you have a complete platformer with Cave Story features - upgradeable weapons, smart enemies, portals and boss fights. Perfect for comfortable C++ programmers.
