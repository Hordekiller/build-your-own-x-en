Build your own Blockchain in JavaScript

⚙ Language: JavaScript 📁 Blockchain / Cryptocurrency 🌐 English page 🔗 Original source
Original source: "Build your own Blockchain in JavaScript" — nambrot's project that combines a working blockchain with an interactive React walkthrough of blocks, transactions and UTXO.
↗ Visit the original tutorial فارسی — Persian version

About

A JavaScript blockchain with a real UI: React components let you create blocks, craft transactions, sign them and inspect the UTXO pool — all running against a live chain in the browser, deployable with Helm charts on Kubernetes.

What you'll learn

  • Domain models: Block, Blockchain, Transaction, UTXO and UTXOPool.
  • Hashing and block verification in JS.
  • Cryptographic signing of transactions.
  • An interactive UI that makes each concept visible.

Core idea

The repository layout already teaches the architecture — domain logic separated from React components, with crypto utilities alongside:

texthelm-chart/            ← helm chart for deployment on Kubernetes
public/                ← static public files
src/
  components/          ← React components: build block, build transaction, sign, UTXO tables, walkthrough
  models/              ← domain models: Block.js, Blockchain.js, Transaction.js, UTXO.js, UTXOPool.js
  App.js               ← main component: navigation, chain selection/creation, welcome
  crypto.js

A block links to its parent by hashing the nonce plus the parent hash:

jsclass Block {
  constructor(blockchain, parentHash, nonce = sha256(new Date().getTime().toString()).toString()) {
    this.blockchain = blockchain;
    this.nonce = nonce;
    this.parentHash = parentHash;
    this.hash = sha256(this.nonce + this.parentHash).toString()
  }

Why it matters

Seeing blocks, transactions and signatures through a walkthrough UI fixes the abstract concepts — you click to sign a transaction and watch the UTXO pool change. Code and visualization together make it stick.
