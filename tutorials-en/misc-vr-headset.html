About

Relativ: a fully open-source DIY VR headset. Two display panels, an inertial measurement unit (IMU), 3D-printed parts and a SteamVR/OpenVR driver combine into a working headset - a complete hardware + firmware + desktop software project.

What you'll learn

  • Headset anatomy: displays, IMU, microcontroller and lenses
  • Writing a SteamVR/OpenVR driver that games talk to
  • Sensor fusion with a complementary filter (gyro + accelerometer)

Core idea

Latency kills VR. Sensor data must be read quickly and the display tracked against it; a complementary filter blends the fast-but-drifting gyro with the slow-but-stable accelerometer.

C// complementary filter: fast gyro + slow accel
float pitch = 0.0f;

void update_imu(float dt, float gyro_pitch, float accel_pitch) {
    // trust the gyro in the short term, the accel in the long term
    pitch = 0.98f * (pitch + gyro_pitch * dt) + 0.02f * accel_pitch;
}

Why it matters

A rare full-stack hardware project: prints, electronics, protocols and desktop VR software all in one open-source build.
