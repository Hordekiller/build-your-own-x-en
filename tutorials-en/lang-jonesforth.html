About

jonesforth is a single, heavily commented x86 assembly file by Richard Jones that builds a complete Forth language from nothing - labels and CPU instructions - in 4295 lines.

What you'll learn

  • The Forth dictionary: a linked list of word entries (name, link, execution code)
  • Two stacks (data and return) and the inner interpreter with IP/NEXT registers
  • How a compiler is bootstrapped on top of primitives using : and ; definitions

Core idea

The heart of Forth is the dictionary - a linked list where each entry defines a word with its name, link address and execution code. Primitives are written directly in assembly and operate on the data stack; colon definitions are sequences of addresses of other words, executed by the Forth virtual machine.

Assembly; each word in Forth looks like this
; flag | name | link-address | execution code
.word 0x3A, 0x3A        ; "defined word" marker
.word last_word        ; link to previous word
.byte 3                ; name length
.byte "DUP"            ; the name
DUP:                    ; execution code starts here
    mov (%esp), %eax   ; value on the stack
    push %eax          ; duplicate it
    jmp next_word      ; go to the next word
Assembly; the inner interpreter: emit and jump
next_word:
    mov (%esi), %ebx      ; next word address
    add $4, %esi          ; advance instruction pointer
    jmp *(%ebx)           ; jump to its code

Why it matters

This is a full classroom in one file: reading the comments takes you from raw bytes to a Forth virtual machine and compiler - pure understanding of where languages come from.
