Writing a INI Parser

⚙ Language: Nim 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Writing a INI Parser"
↗ Visit the original tutorial فارسی — Persian version

About

Parse the INI config format in Nim: sections in brackets, key=value pairs, comments with ; or # - still the format of php.ini and countless system tools.

What you'll learn

  • Section-based state maintained across lines
  • Splitting on the first = only (URLs contain =)
  • Safe access with getOrDefault for missing sections

Core idea

The parser skips blank lines and comments, records [section] boundaries, and adds key=value pairs to the current section table - split("=", 1) so values containing '=' survive.

Nimimport strutils, tables

type IniFile = Table[string, Table[string, string]]

proc parseIni(content: string): IniFile =
  var currentSection = ""
  var section = initTable[string, string]()
  for line in content.splitLines():
    let trimmed = line.strip()
    if trimmed.len == 0 or trimmed[0] in {';', '#'}: continue
    if trimmed[0] == '[':
      if currentSection != "": result[currentSection] = section
      currentSection = trimmed[1..^2]
      section = initTable[string, string]()
    else:
      let parts = trimmed.split("=", 1)
      let key = parts[0].strip()
      let value = (if parts.len > 1: parts[1].strip() else: "")
      section[key] = value
  if currentSection != "": result[currentSection] = section

let config = parseIni(readFile("app.ini"))
echo config["server"]["port"]   # 8080

Why it matters

INI is the simplest real config format - one state variable and a few rules give a complete parser.
