Visualize your local git contributions with Go

⚙ Language: Go 📁 Command-Line Tool 🌐 English page 🔗 Original source
Original source: "Visualize your local git contributions with Go" — a Flavio Copes tutorial that builds a small CLI scanning git repos and rendering your contribution stats.

About

A practical Go CLI: pass a folder with the -add flag, scan it recursively for git repositories, persist the found paths, then produce a summary of your commits — a real daily tool you work with as you build it.

What you'll learn

  • Reading flags with the flag package.
  • Recursive folder scanning and file persistence.
  • Executing git commands from Go and parsing the output.
  • Separating concerns: scan, stats, render.

Core idea

The program is planned as three functions, each with a clear job:

gopackage main

import (
    "flag"
)

// scan walks a path and its subfolders
// searching for git repositories
func scan(path string) {
    print("scan")
}

// stats produces a nice overview of your git contributions
func stats(email string) {
    print("stats")
}

func main() {
    var folder string
    var email string
    flag.StringVar(&folder, "add", "", "add a new folder to scan")
    // ...
}

Then each function is filled in — the scan grows into recursive traversal and file logging:

go// scan walks a new folder for git repositories
func scan(folder string) {
    fmt.Printf("Found folders:\n\n")
    repositories := recursiveScanFolder(folder)
    filePath := getDotFilePath()
    addNewSliceElementsToFile(filePath, repositories)
    fmt.Printf("\n\nSuccessfully added\n\n")
}

Why it matters

Small CLIs are where Go shines, and this one hits every core skill: flags, filesystem walking, shelling out to git and structured output — leaving you with a tool you will actually run.
