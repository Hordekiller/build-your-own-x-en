Write your own miniature Redis with Python

About

A miniature Redis in Python, served by gevent's concurrency and answering the real redis-py client. Commands are structured as a router; the wire protocol is handled manually; keys and lists live in memory, and gevent streams handle many clients at once.

What you'll learn

  • Reading and writing the Redis wire protocol by hand.
  • Concurrency with gevent: greenlets, streams, monkey patching.
  • Turning raw sockets into a library API (redis-py compatible).
  • Unit-testing a network server like a normal Python program.

Core idea

Concurrency without threads — gevent makes each connection a trivial greenlet:

pythonimport gevent
from gevent import monkey
monkey.patch_all()  # make the standard library cooperative

from gevent import socket

from gevent.stream import Stream
