Build Your Own Module Bundler - Minipack

About

Minipack: a module bundler in ~150 lines. Three steps - reading files and parsing imports, building a dependency graph, and emitting a single executable bundle - reveal exactly what webpack and Rollup do.

What you'll learn

  • Parsing files to AST and finding import declarations
  • Building the dependency graph with a BFS queue
  • Generating a self-executing module bundle

Core idea

Each asset records its filename, dependencies and transpiled code. The BFS graph walk assigns each module an id and keeps a mapping from relative path to child id - which the generated bundle uses to resolve modules at runtime.

JavaScript// create the dependency graph with breadth-first traversal
function createGraph(entry) {
    const mainAsset = createAsset(entry);
    const queue = [mainAsset];

    for (const asset of queue) {
        asset.mapping = {};
        const dirname = path.dirname(asset.filename);
        asset.dependencies.forEach(relativePath => {
            const absolutePath = path.join(dirname, relativePath);
            const child = createAsset(absolutePath);
            asset.mapping[relativePath] = child.id;
            queue.push(child);
        });
    }
    return queue;
}
