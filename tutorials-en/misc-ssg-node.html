Build a static site generator in 40 lines with Node.js

⚙ Language: Node.js 📁 Web Server 🌐 English page 🔗 Original source

About

A static site generator in Node at its essence: read Markdown files from a posts folder, render them with markdown-it, and wrap each in a full HTML template - a Jekyll/Hugo in about 40 lines.

What you'll learn

  • SSG vs CMS: building pages at build time, not request time
  • markdown-it rendering and template injection
  • Metadata (front matter) and an index page

Core idea

For each *.md file: read, render Markdown to HTML, write an HTML file. Add front matter and an index of all posts and you have a real blog generator.

JavaScriptconst fs = require('fs');
const path = require('path');
const md = new (require('markdown-it'))();

const DIR = 'posts';
const OUT = 'public';

const template = (title, body) => `<!DOCTYPE html>
<html lang="fa"><head><meta charset="utf-8">
<title>${title}</title></head>
<body><article>${body}</article></body></html>`;

fs.readdirSync(DIR).forEach(file => {
  const content = fs.readFileSync(path.join(DIR, file), 'utf8');
  const html = md.render(content);
  const title = file.replace('.md', '');
  fs.writeFileSync(path.join(OUT, title + '.html'), template(title, html));
});

Why it matters

Static generators look huge but are three operations: read, transform, inject - and now they're yours.
