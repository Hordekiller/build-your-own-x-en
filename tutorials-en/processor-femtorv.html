From Blinker to RISC-V

About

FemtoRV: a minimal RISC-V processor written in Verilog, documented as a step-by-step tutorial - from a blinking LED to a complete SoC.

What you'll learn

  • Designing a tiny RISC-V core in Verilog
  • A program counter that walks a small instruction memory
  • Decoding ALU-register, ALU-immediate and branch opcodes

Core idea

The SoC wraps a small RISC-V CPU: a clocked program counter reads instructions from a small memory and drives LEDs. The decode logic recognizes the standard opcodes - ALU-register, ALU-immediate, and branches.

Verilogmodule SOC (
    input  CLK,
    input  RESET,
    output [4:0] LEDS,
    input  RXD,
    output TXD
);
   reg [4:0] count = 0;
   always @(posedge CLK) begin
      count <= count + 1;
   end
Verilog   reg [4:0] PC  = 0;
   reg [4:0] leds = 0;
   always @(posedge clk) begin
      leds <= MEM[PC];
      PC   <= (!resetn || PC==20) ? 0 : (PC+1);
   end
Verilog   wire isALUreg  = (instr[6:0] == 7'b0110011); // rd <- rs1 OP rs2
   wire isALUimm  = (instr[6:0] == 7'b0010011); // rd <- rs1 OP Iimm
   wire isBranch  = (instr[6:0] == 7'b1100011); // branches

Why it matters

FemtoRV makes RISC-V approachable at the hardware level - you can synthesize a real processor and watch it blink.
