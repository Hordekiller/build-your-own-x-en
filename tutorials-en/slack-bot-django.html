How to build a Slack Bot with Python using Slack Events API & Django under 20 minute

⚙ Language: Python 📁 Bot 🌐 English page 🔗 Original source
Original source: "How to build a Slack bot with Python and Django" — a guide by freehunch that builds an events-API Slack bot on top of Django and Django REST Framework.
↗ Visit the original tutorial فارسی — Persian version

About

A production-shaped Slack bot: Django REST Framework exposes an /events endpoint that Slack's Events API calls, verification tokens protect it, and the bot replies through the Web API. Environment isolation comes from conda.

What you'll learn

  • Creating a conda workspace for the project.
  • Installing Django, DRF, slackclient and slackeventsapi.
  • Scaffolding a Django project and events app.
  • Handling Slack events in a DRF APIView.
  • Storing Slack credentials in Django settings.

Core idea

Everything rests on a handful of packages — web framework, REST framework and Slack clients:

shellconda create -n slack_bot python==3.5
# Windows
activate slack_bot
# macOS, Linux
source activate slack_bot

pip install django
pip install djangorestframework
pip install slackclient
pip install slackeventsapi

The events app is registered in Django settings and the bot's credentials are read from settings too:

py# slack/settings.py
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'rest_framework',             # <== add this line
    'events',
]

Why it matters

It shows the "grown-up" bot architecture: a verified event endpoint backed by a real web framework — the same shape used by production integrations, rather than a quick script.
