About

Gitlet: a Git implementation in JavaScript, sized for humans — init, add, commit, branch, merge, checkout and remote basics, with docs that read like a novel.

What you'll learn

  • The object model: blobs, trees, commits and refs
  • A working tree you can actually diff and merge
  • Branches, HEAD and detached HEAD semantics
  • Reading a complete Git core in one sitting

Core idea

Commit is nothing but plumbing — three objects chained:
