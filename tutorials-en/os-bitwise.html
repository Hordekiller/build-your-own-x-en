About

A video series that builds a complete software and hardware stack for a simple computer from scratch — from logic gates up to an emulator.

What you'll learn

  • Designing combinational logic: half adders and beyond
  • Building an ALU, registers and a CPU
  • Layering software on top of your own hardware

Core idea

Everything starts with a half adder — the first step toward a working adder built from logic gates: sum via XOR, carry via AND. From there the series climbs to a full computer you control at every level.

Verilog// half adder: first step toward an adder built from logic gates
module half_adder(
  input  a, b,
  output sum, carry
);
  assign sum   = a ^ b;   // XOR: sum without the carry
  assign carry = a & b;   // AND: the carry
endmodule

Why it matters

Few experiences teach computer architecture as thoroughly as watching a machine get built from the ground up, gate by gate.
