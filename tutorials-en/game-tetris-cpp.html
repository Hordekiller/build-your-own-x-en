About

A platform-independent Tetris in C++: the Board class knows nothing about graphics - no SDL, no OpenGL, no windows. Logic works with matrices and simple functions, renderable anywhere (desktop, mobile, web).

What you'll learn

  • Boards and pieces as matrices: both shape and color come from the matrix
  • Rotation as pre-computed states instead of rotation math
  • Collision checks by comparing piece cells against board cells

Core idea

Each tetromino is a 4x4 matrix; its rotation states are precomputed, so rotating just switches the index. Placement is validated by checking every nonzero piece cell against the board.

C++const int BOARD_WIDTH = 10;
const int BOARD_HEIGHT = 20;
int board[BOARD_WIDTH * BOARD_HEIGHT];  // 0 = empty, 1 = filled

// example: the L piece as a 4x4 matrix
int pieceL[4][4] = {
  { 0, 0, 0, 0 },
  { 1, 1, 1, 0 },
  { 1, 0, 0, 0 },
  { 0, 0, 0, 0 },
};

bool Board::isFreeBlock(int pX, int pY, int pType, int pRotation) {
  // compare every nonzero piece cell with the board
  for (int i1 = pX, i2 = 0; i1 < pX + size(pType); i1++, i2++) {
    for (int j1 = pY, j2 = 0; j1 < pY + size(pType); j1++, j2++) {
      if (getBlock(i2, j2, pType, pRotation) != 0 && isBlock(i1, j1))
        return false;   // overlap -> collision
    }
  }
  return true;
}

Why it matters

Matrix-based logic with precomputed rotations and zero graphics dependencies - readable and writable in under an hour; the best C++ game intro.
