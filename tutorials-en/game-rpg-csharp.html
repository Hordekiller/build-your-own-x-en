Learn C# by Building a Simple RPG

About

This free course teaches C# with a real project: a simple text RPG with no graphics - 9 locations, 3 monsters, 2 weapons and 2 quests. It starts from nothing, even installing Visual Studio.

What you'll learn

  • Classes, properties, functions, conditionals and loops through a real project
  • Inheritance: the WorldObject base class and Weapon/Monster/Quest subclasses
  • A complete small game: move, fight, pick up gear and complete quests

Core idea

Every game object derives from WorldObject (ID, Name, Description); Weapon adds MaximumDamage, and Monster, Quest, Location and Player follow the same pattern, then the world is assembled from them.

C#// base class for every game object
public class WorldObject {
  public int ID { get; set; }
  public string Name { get; set; }
  public string Description { get; set; }

  public WorldObject(int id, string name, string description) {
    ID = id; Name = name; Description = description;
  }
}

// a subclass inheriting from the base: a weapon
public class Weapon : WorldObject {
  public int MaximumDamage { get; set; }

  public Weapon(int id, string name, string description, int maximumDamage)
      : base(id, name, description) {
    MaximumDamage = maximumDamage;
  }
}

Why it matters

The best start for C# fundamentals through games: complete understanding of classes and object design, then move to the WPF graphical version.
