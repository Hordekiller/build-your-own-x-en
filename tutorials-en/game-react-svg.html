Developing Games with React, Redux, and SVG

About

This Auth0 tutorial builds a real game - no game engine! - with React, Redux and SVG. Aliens, Go Home! has a cannon aimed with the mouse shooting at flying saucers.

What you'll learn

  • Game state in Redux: every frame dispatches actions (move aliens, move shots, check collisions)
  • SVG components driven purely by props from state
  • requestAnimationFrame driving the loop from componentDidMount

Core idea

The game loop lives in the component lifecycle: each frame dispatches three actions - moveAliensDown, moveShotsUp, checkCollisions - and the SVG tree re-renders from pure reducers.

JavaScript// cannon component: position comes from state
const Cannon = ({ x, y }) => (
  <g>
    <polygon points="0,32 0,60 20,60 20,32"
             transform={`translate(${x}, ${y}) rotate(180)`}
             style={{ fill: '#000' }} />
  </g>
);

// game loop: each frame ticks an action
class Game extends React.Component {
  componentDidMount() {
    this.loopId = requestAnimationFrame(this.tick);
  }
  tick = () => {
    const { dispatch } = this.props;
    dispatch(moveAliensDown());   // move saucers
    dispatch(moveShotsUp());      // move bullets
    dispatch(checkCollisions());  // collisions
    this.loopId = requestAnimationFrame(this.tick);
  };
  render() {
    const { shots, aliens, cannon } = this.props;
    return (
      <svg width="1000" height="600">
        <Cannon x={cannon.x} y={cannon.y} />
        {shots.map(s => <circle key={s.id} cx={s.x} cy={s.y} r="4" />)}
        {aliens.map(a => <circle key={a.id} cx={a.x} cy={a.y} r="15" />)}
      </svg>
    );
  }
}

Why it matters

A complete game without a game library - just React, Redux and SVG with clean, testable pure logic and step-by-step GitHub code.
