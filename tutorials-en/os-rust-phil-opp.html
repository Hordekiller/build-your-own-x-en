Writing an OS in Rust

About

Writing an OS in Rust: a deep blog series from a freestanding Rust binary to a fully functional kernel with paging, heap allocation and more.

What you'll learn

  • Freestanding Rust and a custom target specification
  • Linked-list allocators and heap management
  • Paging, interrupts and CPU isolation

Core idea

The series starts with a freestanding Rust binary and immediately wires QEMU into the workflow: cargo build and cargo run with a built-in runner config boots the kernel automatically.

bashcargo build
cargo run    # with the built-in QEMU config, boots the kernel

Why it matters

Rust's memory safety is changing OS development, and phil-opp's series is the most polished, most complete treatment of it anywhere.
