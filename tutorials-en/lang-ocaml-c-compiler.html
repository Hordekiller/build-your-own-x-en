About

Nora Sandler's 10 in-depth articles compile a large C subset with OCaml: from int main() { return 1; } to structs, unions and pointers - emitting x86-64 assembly linked with gcc.

What you'll learn

  • A full pipeline: lexer/parser, return, locals and stack allocation, if/loops, functions, unary/binary operators, pointers, struct/union, typedef and advanced types
  • OCaml pattern matching as a perfect fit for ASTs - compiler code as a typing lesson
  • Every part ships tests and debugging guidance

Core idea

The series moves part by part: assembly for return, local variables with stack allocation, if/else and loops, functions and arguments, complete unary/binary operators, pointers with dereference and address-of, struct/union, remaining keywords and typedef, and finally advanced data types.

OCaml(* parse an expression with left-to-right precedence *)
let rec parse_exp tokens =
  let left, tokens = parse_exp1 tokens in
  parse_exp_tail left tokens

(* exp-tail := ("+"|"-"|"*"|"/") exp exp-tail | eps *)
and parse_exp_tail left tokens = match tokens with
  | Tok_PLUS :: rest ->
      let right, rest' = parse_exp1 rest in
      parse_exp_tail (Exp_Binop (Add, left, right)) rest'
  | Tok_MINUS :: rest ->
      let right, rest' = parse_exp1 rest in
      parse_exp_tail (Exp_Binop (Sub, left, right)) rest'
  | _ -> left, tokens

Why it matters

A complete, readable and realistic series: comfortable with OCaml? This is the road to a real (not toy) compiler that translates actual C programs.
