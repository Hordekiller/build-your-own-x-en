About

Build GIT — Learn GIT: a from-zero Git clone in JavaScript whose goal is understanding: commits, branches, diffs, merges and remotes, built by hand.

What you'll learn

  • Commits as increments of a head pointer
  • Branches as pointers, HEAD as a pointer to a pointer
  • Diffing and merging states you control
  • The confidence of using a tool you rebuilt

Core idea

The first commit is a single linked step:

javascriptfunction Commit(id, message) {
  this.id = id;
  this.message = message;
}
javascriptfunction Git() {
  this.lastCommitId = -1;
}

Git.prototype.commit = function(message) {
  var commit = new Commit(++this.lastCommitId, message);
  return commit;
};

repo.commit("Make commit work");
javascriptfunction Git(name) {
  this.name = name; // repo name
  this.lastCommitId = -1; // tracks the last commit id
  this.HEAD = null; // reference to the latest commit
}

Git.prototype.commit = function(message) {
  var commit = new Commit(++this.lastCommitId, message);
  this.HEAD = commit;
  return commit;
};

Why it matters

Learning Git by building Git works — every error message and merge conflict you'll see later becomes a map of code you already wrote.
