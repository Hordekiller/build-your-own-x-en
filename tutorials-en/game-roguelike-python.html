About

Home of one of the most famous roguelike tutorials: rewritten in 2019 for python-tcod with a clean architecture (engine.py, input_handlers.py) building a complete roguelike - from an @ on screen to complex systems.

What you'll learn

  • The clean Engine/EventHandler architecture with dependency injection
  • Tilesets, terminal contexts and console rendering with python-tcod
  • Advanced systems at the end: inventory, equipment and skill trees

Core idea

Engine handles events through a dispatched EventHandler producing actions; the main loop renders the console, waits for events and processes them.

Python# engine.py - the game core
import tcod
from input_handlers import EventHandler

class Engine:
    def __init__(self, event_handler: EventHandler):
        self.event_handler = event_handler

    def handle_events(self, events) -> None:
        for event in events:
            action = self.event_handler.dispatch(event)
            if action is None:
                continue
            action.perform(self, self.player)

def main() -> None:
    screen_width, screen_height = 80, 50
    tileset = tcod.tileset.load_tilesheet(
        "dejavu10x10_gs_tc.png", 32, 8, tcod.tileset.CHARMAP_TCOD)
    with tcod.context.new_terminal(
        columns=screen_width, rows=screen_height,
        tileset=tileset, title="My Roguelike") as context:
        event_handler = EventHandler()
        engine = Engine(event_handler)
        while True:
            root_console = tcod.console.Console(screen_width, screen_height)
            # ... draw the scene ...
            context.present(root_console)
            events = tcod.event.wait()
            root_console.clear()
            engine.handle_events(events)
