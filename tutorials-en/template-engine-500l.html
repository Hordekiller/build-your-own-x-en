About

The 500 Lines template engine: a full Django-style templating library in under 400 lines, compiling templates to Python for speed.

What you'll learn

  • Code generation: templates become Python functions
  • The CodeBuilder class for assembling source text
  • Efficient dot-lookup via generated nested variables

Core idea

Instead of interpreting template text at render time, the engine compiles it: variables are resolved into Python locals (c_user_name, c_product_list...), and a CodeBuilder assembles the rendered markup with proper indentation.

HTML<p>Welcome, {{user_name}}!</p>
<p>Products:</p>
<ul>
{% for product in product_list %}
    <li>{{ product.name }}: {{ product.price }}</li>
{% endfor %}
</ul>
