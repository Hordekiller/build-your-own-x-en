Creating a blockchain with JavaScript

About

Savjee's "SavjeeCoin" is the most-watched tiny blockchain tutorial on the web: a few dozen lines of JavaScript that define blocks, chain them, add a proof-of-work miner and validate the whole thing — complete with a visual explanation.

What you'll learn

  • A Block class with index, timestamp, data and previous hash.
  • Hashing with crypto-js SHA-256.
  • Genesis block creation and chain validation.
  • A proof-of-work miner with adjustable difficulty.

Core idea

jsclass Blockchain {
	// Constructor: initializes the chain by creating the genesis block
	constructor() {
		this.chain = [this.createGenesisBlock()];
	}

	// Genesis block: the first block of the chain, which cannot point to a previous block
	createGenesisBlock() {
		return new Block(0, "01/01/2017", "Genesis block", "0");
	}

	// Returns the latest block of the chain
	getLatestBlock() {
		return this.chain[this.chain.length - 1];
	}

	// Adds a new block to the chain
	addBlock(newBlock) {
		newBlock.previousHash = this.getLatestBlock().hash;
		newBlock.hash = newBlock.calculateHash();
		this.chain.push(newBlock);
	}
}

Why it matters

Its simplicity made it the canonical first blockchain: every concept — genesis block, chaining, mining, validation — maps to a method you can read in seconds, which makes the follow-up videos on transactions and wallets easy to understand.
