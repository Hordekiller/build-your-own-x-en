About

Write a shell in C the classic way: the loop, read a line, parse it, execute it - modeled after the famous Stephen Brennan pieces.

What you'll learn

  • The basic REPL skeleton: loop, read, parse, execute
  • Reading with a growing buffer and strtok splitting
  • The fork-and-wait execution model

Core idea

The shell's geometry is four functions chained in a loop: read a line, split it on whitespace, execute by forking, and wait. strtok walks the tokens one at a time to build argv.
