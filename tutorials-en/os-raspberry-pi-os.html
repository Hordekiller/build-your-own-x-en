About

Learning OS development with the Linux kernel and Raspberry Pi: from a bare UART 'Hello, world!' to interrupts, the MMU and process isolation.

What you'll learn

  • Booting your own kernel on a Raspberry Pi
  • Initializing the UART and printing to serial
  • Privilege levels, the MMU and process isolation

Core idea

Lesson 1 is a stripped kernel_main(): initialize the UART, send a string, then loop. Everything else — interrupts, virtual memory, processes — grows from that same tiny skeleton.

arm// kernel.c (lesson 1) — set up the UART and print a message
#include "uart.h"

void kernel_main(void) {
    uart_init();               // set up the serial port
    uart_send_string("Hello, world!\n");

    while (1) {
        // wait for the next character

Why it matters

Running your code on real Raspberry Pi hardware — with a structure modeled on Linux itself — is the most motivating way to learn OS internals.
