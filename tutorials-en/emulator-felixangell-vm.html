Virtual machine in C

Original source: "Virtual machine in C — by Felix Angell"
↗ Visit the original tutorial فارسی — Persian version

About

A tiny virtual machine in C, built from the ground up: an instruction set, a program, a fetch-decode-execute loop, and a simple assembler — complete with a Makefile that fits on screen.

What you'll learn

  • Designing an instruction set from scratch
  • Implementing the fetch-decode-execute loop
  • Writing a program in your own assembly
  • Using a Makefile-based C workflow effectively

Core idea

The whole language fits in one enum — five instructions:

A program in your very own instruction set:

MakefileSRC_FILES = main.c
CC_FLAGS = -Wall -Wextra -g -std=c11
CC = clang

all:
    ${CC} ${SRC_FILES} ${CC_FLAGS} -o mac
ctypedef enum {
    PSH,
    ADD,
    POP,
    SET,
    HLT
} InstructionSet;
cconst int program[] = {
    PSH, 5,
    PSH, 6,
    ADD,
    POP,
    HLT
};

Why it matters

A self-contained crash course in CPU emulation: by the end, 'how does a computer run code' feels like a question you answered with your own hands.
