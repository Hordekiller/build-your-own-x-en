Core idea

A prediction is a weighted sum plus bias pushed through a threshold. When the prediction is wrong, train() computes the error and nudges each weight in the direction that fixes it.

javascript// perceptron output: 1 if the weighted sum + bias crosses the threshold, else 0
function perceptron(inputs, weights, bias) {
  let sum = bias;
  for (let i = 0; i < inputs.length; i++) {
    sum += inputs[i] * weights[i];
  }
  return sum > 0 ? 1 : 0;
}
