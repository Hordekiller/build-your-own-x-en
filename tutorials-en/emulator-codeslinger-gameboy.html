About

The companion tutorial that carries the same style to the Game Boy: a Z80-based CPU core, carefully timed instruction execution, dual video layers and a sound output in C++.

What you'll learn

  • Running the CPU with cycle counting to match the hardware
  • Building the 160x144 screen from tile and background layers
  • VRAM, palettes and the video controller
  • The discipline of matching real hardware timing

Core idea

The engine is a clock: execute opcodes until a frame of cycles has elapsed:

cppvoid Emulator::Update( )
{
  const int MAXCYCLES = 69905 ;
  int cyclesThisUpdate = 0 ;

  while (cyclesThisUpdate < MAXCYCLES)
  {
     int cycles = ExecuteNextOpcode( ) ;
     cyclesThisUpdate += cycles ;
  }
}

Why it matters

From CHIP-8 to Game Boy is a short hop: same discipline, harder hardware. The tutorial sequence shows emulation as one continuous skill, not a ladder of separate projects.
