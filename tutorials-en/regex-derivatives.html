How to implement regular expressions in functional javascript using derivatives

About

Building a regex engine with derivatives - a mathematically elegant approach where matching a character transforms the regular expression itself.

What you'll learn

  • Reducing Perl/POSIX syntax to a small core
  • The derivative of a regex with respect to a character
  • Matching by repeatedly deriving the regex with the input

Core idea

Instead of backtracking, the engine derives: taking the derivative of a(b|c)d with respect to 'a' yields (b|c)d, and with respect to 'b', then 'c', then 'd' it walks the whole string. Each AST node overrides derive(char).

JSclass RegexpNode {
    derive (char) {
        return NeverMatches;
    }
}
// Literal, Star, Union, Concat... all override derive(char)
Examplestep   remaining input   regex (derivative)
0      abd               a(b|c)d
      ... derive a(b|c)d w.r.t. character 'a' ...
1      bd                (b|c)d
      ... derive (b|c)d w.r.t. character 'b' ...
2      d                 cd

Why it matters

Derivatives give a complete, backtracking-free regex engine - and a beautiful piece of theory that is also practical.
