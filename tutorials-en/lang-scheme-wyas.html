About

An ambitious rewrite of "Write Yourself a Scheme in 48 Hours" (v2, 2015) using modern engineering: cabal setup, QuickCheck and golden tests, haddock documentation, hygienic macros and bottom-up data structures.

What you'll learn

  • Hygienic macros with syntax-rules and define-syntax - no name clashes between macros and user code
  • LispVal as a sum type with pattern matching, errors via MonadError
  • A full test system: golden tests compare eval behaviour on sample scripts

Core idea

Code is organized in small modules (Language.Scheme.*) covering parser, runtime, environment and types; every module has its own tests. The interpreter pairs a fast map-based environment with pattern-matching evaluation.

Haskelldata Env = Env { envParent :: Maybe Env
               , envValues :: Map.Map Text LispVal }

eval :: Env -> LispVal -> IOThrowsError LispVal
eval env (LispAtom a) = lookupEnv env a
eval env (LispList [LispAtom "if", cond, cons, alt]) = do
    result <- eval env cond
    case result of
      LispBool False -> eval env alt
      LispList []    -> eval env alt   -- in Scheme, empty list = false
      _              -> eval env cons

Why it matters

For readers of v1: see how a professional interpreter is architected - modular structure, tests and macros reveal all the good Haskell patterns.
