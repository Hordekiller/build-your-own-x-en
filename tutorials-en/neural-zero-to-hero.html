About

Andrej Karpathy's course from Neural Networks: Zero to Hero — from micrograd's autograd engine to building and training GPT-style language models.

What you'll learn

  • Automatic differentiation from scratch with micrograd
  • Backpropagation and its intuition
  • Language modeling: from bigrams to a mini GPT with attention

Core idea

The course starts with micrograd: a Value class with data, gradient and a backward hook, forming a computation graph that makes autodiff nearly trivial. Everything after — makemore, wavelets of attention — builds on that tiny engine.

Python# micrograd: a Value with a computation graph for autodiff
class Value:
    def __init__(self, data):
        self.data = data
        self.grad = 0
        self._backward = lambda: None

    def __add__(self, other):
        out = Value(self.data + other.data)

Why it matters
