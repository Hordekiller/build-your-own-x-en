About

This playlist builds VICE, a professional chess engine (rated 2400+) from scratch in C: move generation, minimax/alpha-beta search, position evaluation, transposition tables, an opening book and a UI.

What you'll learn

  • Board representation (bitboards or arrays) and move structures
  • Minimax search with alpha-beta pruning and move ordering
  • Transposition tables with Zobrist hashing, opening books and the UCI protocol

Core idea

Evaluation sums material plus positional tables and mobility. Search generates and orders moves, pruning with alpha-beta; transposition tables avoid re-searching repeated positions.

C// a chess move

int evaluate(board_t *board) {

  score += material_score(board);
  score += piece_square_tables(board);
  score += mobility(board);   // number of legal moves
  return score;
}
