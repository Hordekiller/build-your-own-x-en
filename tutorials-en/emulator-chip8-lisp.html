About

CHIP-8 written in Common Lisp, as only Steve Losh can do it: a full essay on crafting a tiny emulator with vivid, opinionated commentary and impeccable Lisp.

What you'll learn

  • Type discipline with DEFTYPE for 4-, 8-, 12- and 16-bit integers
  • Modeling machine state with DEFSTRUCT
  • Emulation in a functional language
  • Readable, tested, classic Lisp style

Core idea

The chip is defined with surgical types — widths that mirror real silicon:

Common Lisp(deftype int4 ()  '(unsigned-byte 4))
(deftype int8 ()  '(unsigned-byte 8))
(deftype int12 () '(unsigned-byte 12))
(deftype int16 () '(unsigned-byte 16))
Common Lisp(defstruct chip
  ; ...
  (stack (make-array 16 :element-type 'int12 :fill-pointer 0)
         :type (vector int12 16)
         :read-only t)
  ; ...
  )
Common Lisp(defconstant +memory-size+ (* 1024 4))

(defstruct chip
  ; ...
  (memory (make-array +memory-size+ :element-type 'int8)
          :type (simple-array int8 (#.+memory-size+))
          :read-only t)
  ; ...
  )

Why it matters

The best-written emulator tutorial in any language: a tiny machine, gorgeous Lisp, and a narrative that makes you enjoy every register.
