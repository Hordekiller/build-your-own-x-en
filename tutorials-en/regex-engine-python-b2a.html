About

A from-scratch regex implementation in Python with a notebook-style walkthrough: parsing and matching through a set of assert-driven steps.

What you'll learn

  • Parsing alternation (|) and concatenation as recursive structure
  • Test-driven development: assertions as the spec
  • The parse tree behind a|b, ab, a+ and parentheses

Core idea

The parser separates operators by precedence: parse_split handles alternations, parse_concat handles sequences. Every step is pinned down by assertions on the parse tree.

Pythonassert re_parse('') is None
assert re_parse('.') == 'dot'
assert re_parse('a') == 'a'
assert re_parse('ab') == ('cat', 'a', 'b')
assert re_parse('a|b') == ('split', 'a', 'b')
assert re_parse('a+') == ('repeat', 'a')
