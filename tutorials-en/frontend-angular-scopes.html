About

Make your own AngularJS, part 1: scopes and digest — a deep, test-driven implementation of the exact scope mechanics AngularJS shipped in production.

What you'll learn

  • The watcher contract: fn, listener, and deep vs reference equality
  • Digest cycles, staleness detection and infinite-loop protection
  • $eval and $evalAsync for scheduling work
  • Testing framework internals with Jasmine

Core idea

A watcher is an object with a contract — what to watch, what to do when it changes, and how to compare:

jsScope.prototype.$watch = function(watchFn, listenerFn, valueEq) {
  const watcher = {
    watchFn: watchFn,
    listenerFn: listenerFn || function() {},
    valueEq: !!valueEq, // deep or reference comparison
    last: initWatchVal
  };
  ...
};
jsfunction initWatchVal() {} // a sentinel that equals nothing
jsScope.prototype.$eval = function(expr, locals) {
  // run a function/expression immediately in this scope's context
  return expr(this, locals);
};

Scope.prototype.$evalAsync = function(expr) {
  // run it later: in a digest cycle
  ...
};

Why it matters

This is Angular's scope engine chapter-by-chapter, tested as you go — after it, 'dirty checking' stops being a punchline and becomes something you built.
