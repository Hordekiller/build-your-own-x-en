About

Rebuilding Git in Ruby: the thoughtbot classic that reimplements init, add and commit against your own .rgit directory — objects, index and refs in idiomatic Ruby.

What you'll learn

  • The .git skeleton: objects/, refs/ and the index
  • Hash-based object addressing and compression
  • Building an index from file metadata
  • A minimal but real commit graph

Core idea

Everything starts with a fresh directory layout — your own .rgit:

ruby#!/usr/bin/env ruby
# bin/rgit-init
RGIT_DIRECTORY = ".rgit".freeze
OBJECTS_DIRECTORY = "#{RGIT_DIRECTORY}/objects".freeze
REFS_DIRECTORY = "#{RGIT_DIRECTORY}/refs".freeze

if Dir.exists? RGIT_DIRECTORY
  STDERR.puts "Error: .rgit already exists"
  exit 1
end
