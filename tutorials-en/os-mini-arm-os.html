Build a minimal multi-tasking kernel for ARM from scratch

About

Build a minimal multi-tasking kernel for ARM from scratch: lessons checked out as git branches, from context switching to interrupts.

What you'll learn

  • Saving and restoring registers with ARM assembly (stmfd)
  • Interrupt handling on an STM32
  • Round-robin multitasking with a few tasks

Core idea

Each lesson is a git branch. context_switch() pushes the current task's registers with stmfd, then restores the next task's. The included QEMU command boots the lesson kernel on a simulated STM32 board.

arm@ context_switch.S — save registers and switch to the next process
.global context_switch
context_switch:
    @ save the current process state
    stmfd sp!, {r0-r12, lr}     @ push registers and the return address
    mrs r0, spsr
bash# e.g. lesson 03 (interrupts)
git checkout 03-Interrupt
make
qemu-system-arm -M stm32-p103 -kernel build/interrupt.elf \
    -serial stdio -monitor none -nographic

Why it matters

It is one of the few projects that shows real ARM multitasking with a build that works out of the box — and git branches as lesson structure is genius.
