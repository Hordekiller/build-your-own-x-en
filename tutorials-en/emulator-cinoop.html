About

Writing a Game Boy emulator, Cinoop — a complete, no-frills emulator in C focused on getting the CPU and memory dead right, one opcode at a time.

What you'll learn

  • The Game Boy's 8-bit CPU and its 256 opcodes
  • Organizing opcode handlers with a dispatch table
  • Memory mapping, registers and the boot sequence
  • Squeezing every feature into plain C

Core idea

Every opcode lives in one big table — disassembly text, operand length and handler pointer:

cstruct instruction {
	char *disassembly;
	unsigned char operandLength;
	void *execute;
	//unsigned char ticks;
} extern const instructions[256];
...
const struct instruction instructions[256] = {
	{ "NOP", 0, nop },
	...
c// 0x06
void ld_b_n(unsigned char operand) { registers.b = operand; }
cif(registers.pc == 0x300) {
	printRegisters();
}

Why it matters

A Game Boy on your screen by the weekend: Cinoop proves that a full console emulator is nothing but a dispatch table and a lot of attention to detail.
