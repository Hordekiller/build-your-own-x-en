About

A practical series on physics engine architecture with a focus on broad-phase collision detection: brute force, uniform grids and AABBs.

What you'll learn

  • Representing bodies as AABBs (axis-aligned bounding boxes)
  • The brute-force pairwise approach and its O(n2) cost
  • Spatial hashing with a uniform grid to reduce candidate pairs

Core idea

The engine first checks bounding boxes, which are cheap - a body is a min/max rectangle pair. Naive pair enumeration works but costs O(n2); a uniform grid maps each body to its cell and only tests nearby cells.

JavaScript// an AABB at (10,20) with width and height 10
var myAABB = {
    min: [ 10, 20 ],
    max: [ 20, 30 ]
};
JavaScript// Math.floor( (position - grid min) / cell size )
var col  = Math.floor( (46  - grid.min.x) / grid.pxCellSize );
var cell = Math.floor( (237 - grid.min.y) / grid.pxCellSize );

grid[col][cell].push(entity);

Why it matters

Broad-phase design decides whether your engine runs at 60 FPS with 10 bodies or 10,000 - a core optimization every engine maker must know.
