Learn JavaScript Promises by Building a Promise from Scratch

⚙ Language: JavaScript 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Learn JavaScript Promises by Building a Promise from Scratch"
↗ Visit the original tutorial فارسی — Persian version

About

Build a minimal Promise implementation that matches standard behavior: state, value, handler queue, one-shot settling, then-chaining and a catch - understanding exactly what async/await hides.

What you'll learn

  • The pending/fulfilled/rejected state machine
  • settle(): settling once and notifying waiting handlers
  • then() that returns a new promise for chaining

Core idea

The class keeps state, value and a list of handlers; settle() runs once and flushes every queued handler. then() returns a new promise so results can chain.

JavaScriptclass MyPromise {
    constructor(executor) {
        this.state = 'pending';   // pending | fulfilled | rejected
        this.value = undefined;
        this.handlers = [];
        const resolve = value => this.settle('fulfilled', value);
        const reject = reason => this.settle('rejected', reason);
        try {
            executor(resolve, reject);
        } catch (e) {
            reject(e);
        }
    }

    settle(state, value) {
        if (this.state !== 'pending') return;   // settle only once
        this.state = state;
        this.value = value;
        this.handlers.forEach(h => h());
        this.handlers = [];
    }
}

Why it matters

Promises are the backbone of modern JS - and the whole mechanism is one state machine.
