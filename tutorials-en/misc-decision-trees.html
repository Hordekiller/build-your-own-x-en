Learn ML Algorithms by coding: Decision Trees

Original source: "Learn ML Algorithms by coding: Decision Trees"

About

Classification with decision trees, built from scratch: recursive questions (age over 30?) that split data into branches until leaves are mostly one class - with Gini impurity as the split criterion.

What you'll learn

  • Trees as sequences of simple questions
  • Gini impurity: 0 = pure, higher = more mixed
  • Candidate thresholds from adjacent-value midpoints for continuous features

Core idea

A good split separates mixed classes: Gini of a group is 1 - sum(p^2). Each split is chosen to maximize the impurity decrease, and thresholds come from the midpoints of sorted adjacent values.

Pythondef gini(groups, classes):
    """weighted impurity of all branches."""
    total = sum(len(g) for g in groups)
    score = 0.0
    for group in groups:
        size = len(group)
        if size == 0: continue
        # probability of each class inside this branch
        probs = [group.count(c) / size for c in classes]
        score += (size / total) * (1 - sum(p ** 2 for p in probs))
    return score

def best_split(data, classes):
    """lowest gini over every (feature, threshold)."""
    best = None
    for col in range(len(data[0]) - 1):
        values = sorted({row[col] for row in data})
        for i in range(len(values) - 1):
            threshold = (values[i] + values[i + 1]) / 2
            left  = [r for r in data if r[col] <= threshold]
            right = [r for r in data if r[col] > threshold]
            g = gini([left, right], classes)
            if best is None or g < best[0]:
                best = (g, col, threshold, left, right)
    return best

Why it matters

The tree behind random forests in ~40 lines: pick the question, split, recurse.
