About

Builds a WebSocket server from scratch in Ruby to answer what WebSockets really are and how they work: from the HTTP upgrade handshake to maintaining an open bidirectional connection between browser and server, implemented step by step.

What you'll learn

  • Why HTTP connections close and what problem WebSockets solve
  • The HTTP 101 Switching Protocols upgrade handshake
  • Reading and writing bidirectional frames on one socket

Core idea

WebSockets start life as ordinary HTTP requests: a client asks to upgrade (Sec-WebSocket-Key / Sec-WebSocket-Accept), the server answers 101, and from then on both sides freely exchange messages over the same socket.

Rubyserver = TCPServer.new('127.0.0.1', 2345)

loop do
  socket = server.accept
  request = socket.gets
  STDERR.puts request
  # .... handshake: validate the HTTP upgrade request
  # .... respond HTTP/1.1 101 Switching Protocols
  socket.close
end

Why it matters

Demystifies the 'future of the web' hype by implementing the protocol from zero - and it connects to a real browser.
