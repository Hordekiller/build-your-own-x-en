Kaleidoscope: Implementing a Language with LLVM

About

The official LLVM tutorial builds the Kaleidoscope language: functional syntax with def, extern, conditionals, loops, user-defined operators and mutable variables - ending with a real compiler backend.

What you'll learn

  • LLVM IR generation with IRBuilder and the JIT for immediate execution
  • SSA concepts: PHI nodes for if/else and alloca for mutable variables
  • The optimizer PassManager and producing real object files in the final chapter

Core idea

Chapters add one layer each: lexer, parser/AST, IR generation, JIT, optimizer, conditionals (PHI nodes), loops, user-defined binary operators (dynamic precedence table), mutable variables (alloca) and finally object file output.

C++Value *CodegenVisitor::visit(BinaryExpr &e) {
    Value *L = codegen(e.LHS);
    Value *R = codegen(e.RHS);
    switch (e.Op) {
    case '+': return Builder->CreateFAdd(L, R, "addtmp");
    case '-': return Builder->CreateFSub(L, R, "subtmp");
    case '*': return Builder->CreateFMul(L, R, "multmp");
    case '/': return Builder->CreateFDiv(L, R, "divtmp");
    default:  return LogErrorV("unknown operator");
    }
}

Why it matters

The most complete official introduction to building an LLVM frontend in C++ - the path if you want your language to run fast on a real CPU via JIT or AOT.
