A 3D Modeller

About

This chapter of the famous "500 Lines or Less" book builds a full interactive 3D modeller in Python using OpenGL. It is a small Tkinter application in which you can place, select and manipulate 3D primitives — spheres, cones, cubes — with a trackball-style interaction model, all rendered in real time.

What you'll learn

  • Structure of a GUI 3D application: viewer, scene graph and interaction.
  • OpenGL rendering loop from Python via GLUT.
  • The trackball interaction model for rotating the camera.
  • Selection: identifying which object the mouse clicked, using ray-based picking.
  • Undo/redo, transformations and persistent storage of the scene.

Core idea

Everything is organized around a Viewer (window and render loop) and a Scene that owns a list of nodes — the classic scene graph pattern, in a size you can hold in your head.

pythonclass Scene(object):

    # Default distance from the camera to place a new object
    PLACE_DEPTH = 15.0

    def __init__(self):
        # The scene keeps a list of displayed nodes
        self.node_list = list()
        # Tracks the currently selected node; some actions
        # may depend on something being selected
        self.selected_node = None

    def add_node(self, node):
        """Add a new node to the scene"""
        self.node_list.append(node)

    def render(self):
        """Render the scene"""
        for node in self.node_list:
            node.render()

Why it matters

Unlike pure renderers, this project exercises real interactive software: picking, camera control, undo and object editing. It is a perfect case study of how a small, well-factored codebase (about 500 lines) can deliver a desktop application experience.
