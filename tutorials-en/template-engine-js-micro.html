About

What you'll learn

Core idea

Templates live in script tags with an id. The tmpl function compiles the string into a JavaScript function, caches it, and then runs it with the data object as scope.

HTML<script type="text/html" id="item_tmpl">
  <div id="<%=id%>" class="<%=klass%>">
    <div class="item"><%=name%></div>
  </div>
</script>
