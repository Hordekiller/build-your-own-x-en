About

A blog without frameworks in pure PHP and MySQL: the post list, single post view and an admin section (write/edit) - revealing the simple creature behind WordPress and Laravel.

What you'll learn

  • PDO connections with ERRMODE_EXCEPTION
  • Prepared statements for inserts (SQL injection protection)
  • htmlspecialchars when printing user input (XSS protection)

Core idea

One posts table (id, title, content, created_at); ERRMODE_EXCEPTION turns silent SQL failures into exceptions - vital for debugging.

PHP// db.php - the shared connection
$pdo = new PDO(
    'mysql:host=localhost;dbname=blog;charset=utf8',
    'user', 'pass',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

// write a post with a form
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $title = $_POST['title'] ?? '';
    $content = $_POST['content'] ?? '';
    $stmt = $pdo->prepare(
        'INSERT INTO posts (title, content) VALUES (:t, :c)'
    );
    $stmt->execute([':t' => $title, ':c' => $content]);
    header('Location: index.php');
    exit;
}

Why it matters

The blog is the CMS industry in miniature - and the two security rules (prepared statements, escaping) are the whole game.
