Coding A Sudoku Solver in C

About

A focused video project building a Sudoku game/solver in C: reading boards from files, displaying them and solving with backtracking.

What you'll learn

  • The is_safe check: row, column and 3x3 box constraints
  • Recursive backtracking over the 9x9 grid
  • Simple optimizations like starting from the cell with fewest candidates

Core idea

solve() finds an empty cell, tries digits 1-9 that pass is_safe, recurses, and backtracks on failure - instant for almost all common puzzles.

Cint board[9][9];  // empty cell = 0

// can we place num at (row, col)?
int is_safe(int row, int col, int num) {
  for (int i = 0; i < 9; i++) {
    if (board[row][i] == num || board[i][col] == num) return 0;
  }
  int box_r = (row / 3) * 3, box_c = (col / 3) * 3;
  for (int i = 0; i < 3; i++)
    for (int j = 0; j < 3; j++)
      if (board[box_r + i][box_c + j] == num) return 0;
  return 1;
}

// recursive solving with backtracking
int solve(void) {
  for (int row = 0; row < 9; row++) {
    for (int col = 0; col < 9; col++) {
      if (board[row][col] == 0) {
        for (int num = 1; num <= 9; num++) {
          if (is_safe(row, col, num)) {
            board[row][col] = num;
            if (solve()) return 1;   // keep going - solved?
            board[row][col] = 0;     // no -> backtrack
          }
        }
        return 0;  // no digit worked
      }
    }
  }
  return 1;  // all cells filled - solved
}

Why it matters

A short, focused project finished in one session: deep understanding of backtracking plus real C practice - reusable for mazes and cube solvers.
