About

Building React From Scratch: a video walkthrough that creates a minimal React clone live — elements, render, reconciliation and state updates, all in plain JavaScript.

What you'll learn

  • What a React element is and how render turns it into a DOM node
  • A naive but correct diff algorithm
  • The open-sourced spirit: you can read all of React's core tricks here
  • The minimum viable React that still feels like React

Core idea

The seed of everything React does is one function from element to node:

JavaScript// the heart of React: turning an element into a real DOM node
function render(element, container) {
  const node = document.createElement(element.type);
  node.textContent = element.props.children;
  for (const name in element.props) {
    node[name] = element.props[name];   // apply props
  }
  container.appendChild(node);
}

Why it matters

Video is the fastest format for a tour like this: you watch a React-miniature assemble itself in minutes, and every subsequent chapter of the React docs makes sense.
