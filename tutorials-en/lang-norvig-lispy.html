How to Write a Lisp Interpreter in Python

Original source: "How to Write a Lisp Interpreter in Python"

About

Peter Norvig (Google research director, famous AI author) wrote this Lisp interpreter in about 90 lines of Python - a complete Lisp with functions, variables, conditionals and even quote.

What you'll learn

  • The three core concepts: Environment, eval and apply - straight from McCarthy's The Roots of Lisp
  • The Env chain: a dict with a parent; find walks up for scope, exactly like real languages
  • Real programs (factorials, counts) running on the interpreter prove it is real, not toy

Core idea

eval dispatches: symbols look up variables, quotes bypass evaluation, if evaluates conditionally, define stores, lambda builds a Procedure carrying its env, and everything else is a function call.

Pythondef eval(x, env=global_env):
    if isinstance(x, Symbol):       # variable
        return env.find(x)[x]
    elif not isinstance(x, list):   # number or string
        return x
    elif x[0] == 'quote':           # quote: no evaluation
        (_, exp) = x
        return exp
    elif x[0] == 'if':              # conditional
        (_, test, conseq, alt) = x
        exp = (conseq if eval(test, env) else alt)
        return eval(exp, env)
    elif x[0] == 'define':          # define a variable
        (_, var, exp) = x
        env[var] = eval(exp, env)
    elif x[0] == 'lambda':          # define a function
        (_, parms, body) = x
        return Procedure(parms, body, env)
    else:                           # function call
        proc = eval(x[0], env)
        args = [eval(arg, env) for arg in x[1:]]
        return proc(*args)

class Procedure(object):            # closure
    def __init__(self, parms, body, env):
        self.parms, self.body, self.env = parms, body, env
    def __call__(self, *args):
        return eval(self.body, Env(self.parms, args, self.env))
