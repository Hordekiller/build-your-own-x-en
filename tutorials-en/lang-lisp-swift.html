Building a LISP from scratch with Swift

⚙ Language: Swift 📁 Programming Language 🌐 English page 🔗 Original source
Original source: "Building a LISP from scratch with Swift"
↗ Visit the original tutorial فارسی — Persian version

About

Lisp is one of the simplest languages to give an interpreter (syntax is just parentheses and functions), and Swift offers nested enums and closures - a natural fit for functional data modelling.

What you'll learn

  • Modelling all language values with a Swift enum: atom, number, string, list, function
  • A char-by-char parser with recursion for nested parentheses
  • An evaluator pattern-matching on LispVal; functions as closures over their environment

Core idea

The interpreter has the classic three stages - tokenizer, parser, evaluator - and ends as a working REPL. LispVal.function(String, ([LispVal]) throws -> LispVal) describes functions as composable closures.

Swift// all language values: number, symbol name, list, function
enum LispVal {
    case atom(String)
    case number(Int)
    case string(String)
    case list([LispVal])
    case function(String, ([LispVal]) throws -> LispVal)
}
Swiftfunc parseList(_ chars: [Character], _ pos: Int) throws -> (LispVal, Int) {
    var result: [LispVal] = []
    var i = pos
    while i < chars.count {
        let c = chars[i]
        if c == ")" { return (LispVal.list(result), i + 1) }
        if c == "(" {
            let (list, next) = try parseList(chars, i + 1)   // nested list
            result.append(list)
            i = next
        } else {
            let (v, next) = try parseAtom(chars, i)
            result.append(v)
            i = next
        }
    }
    throw LispError.unexpectedEnd
}

Why it matters

Swift's strong typing is excellent for small academic interpreters; after this project, move to larger ones like mal or Crafting Interpreters.
