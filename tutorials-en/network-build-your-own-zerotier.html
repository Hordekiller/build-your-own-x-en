About

Build your own VPN/Virtual Switch: a virtual network interface (TAP) bridged over UDP to a userspace switch — the same trick ZeroTier uses to create private networks over the internet.

What you'll learn

  • Creating a TAP interface with tun_alloc()
  • The vport abstraction: one end is the kernel, the other is UDP
  • A select() loop that pumps frames between TAP and UDP sockets
  • How Layer-2 frames travel inside a UDP tunnel

Core idea

The vport is the key structure: it holds the file descriptor of the TAP device and the UDP socket connected to the virtual switch. Every frame read from the TAP interface is forwarded over UDP, and vice versa.

c#define TAP_DEV "/dev/net/tun"
#define UDP_PORT 9999

struct vport {
    int tap_fd;      /* fd of the TAP device (created by tun_alloc) */
    int udp_fd;      /* fd of the UDP socket connected to the VSwitch */
    struct sockaddr_in vs_addr;
};

Why it matters

Virtual network interfaces power modern SDN and mesh VPNs; building one shows how little is actually magic between your laptop and a global virtual LAN.
