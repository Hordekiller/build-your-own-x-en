Why you should build your own NoSQL Database

⚙ Language: Crystal 📁 Database 🌐 English page 🔗 Original source

About

Part philosophical manifesto, part implementation: a minimal NoSQL key-value database in Crystal. A TCP server accepts simple command key value lines, stores them in a hash in memory, and answers over telnet.

What you'll learn

  • Designing a tiny text protocol: command key value.
  • Accepting connections with TCPServer and fibers.
  • Handling multiple clients concurrently.
  • Turning a simple API into a real network service.

Core idea

The wire protocol is one line long:

textcommand key value

And the server fits in a few dozen lines — a socket loop, a fiber per connection, one hash:

crrequire "socket"

class Server
  def self.start
    server = TCPServer.new("localhost", 5000)
    server.recv_buffer_size = 4096
    data = Hash(String, String).new

    loop do
      socket = server.accept
      if socket
        spawn do
          loop do
            if request = socket.gets
              # parse "command key value" and dispatch
            end
          end
        end
      end
    end
  end
end

Testing it is as fun as old-school networking gets — telnet:

shelltelnet 127.0.0.1 5000

>set foo bar
bar
>get foo
bar
>invalid
error: "invalid" is not a valid command

Why it matters

It answers the question in the title: building the smallest NoSQL server shows that databases are just protocols over data structures — and demystifies the ones you use every day.
