About

A multi-hour freeCodeCamp course building a 2D game engine from scratch in Java, then developing a full Super Mario clone with it - packaged as a runnable jar at the end.

What you'll learn

  • Entity architecture: GameObject with position, size, animation and draw()
  • The 60 FPS game loop: update (logic/physics/collision) then render
  • Building a complete playable game on top of your own engine

Core idea

The engine exposes a base entity with draw; the main window loop runs update() and render() about 60 times per second.

Java// basic engine entity
public class GameObject {
  public float x, y;              // position
  public float width, height;     // size
  public int animationIndex = 0;
  public boolean isActive = true;

  public void draw(Graphics2D g) {
    // draw the current animation frame at the entity position
  }
}

// main loop: 60 frames per second
public class GameWindow implements Runnable {
  public void run() {
    while (running) {
      update();                   // logic: movement, physics, collision
      render();                   // draw all GameObjects
      Thread.sleep(16);           // ~60 FPS
    }
  }
}

Why it matters

The result is a toolkit (engine) plus a complete game (Mario clone) - the best way to understand what game engines actually are.
