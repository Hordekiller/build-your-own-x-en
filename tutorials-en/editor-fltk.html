About

Building a graphical text editor in C++ with FLTK: windows, menu bars, the text editor widget and toolbar callbacks.

What you'll learn

  • Composing an editor GUI with FLTK widgets
  • The Fl_Text_Editor widget and its buffer
  • Callbacks that mark the document changed

Core idea

The editor is a Fl_Double_Window housing a menu bar and an Fl_Text_Editor widget. A callback fired on text changes flips the changed flag, enabling undo tracking and save prompts.
