Write your own MVC from scratch in PHP

About

MVC explained by building it in plain PHP: a front controller routes every request through index.php, controllers fetch data from PDO-backed models and pass it to views - the Laravel pattern laid bare.

What you'll learn

  • Model / View / Controller separation of concerns
  • A .htaccess rewrite and URL-based routing
  • PDO prepared statements as the first injection defense

Core idea

Every request lands on index.php; the URL is exploded into controller/action arguments, and the matching controller class is required and invoked with the action method.

PHPclass Application {
    public function run() {
        // e.g. home/index/5
        $parts = explode('/', trim($_GET['url'] ?? 'home/index', '/'));
        $controller = ucfirst($parts[0] ?? 'Home') . 'Controller';
        $action = $parts[1] ?? 'index';
        $file = "app/controllers/$controller.php";
        if (!file_exists($file)) {
            http_response_code(404);
            die('not found');
        }
        require $file;
        $obj = new $controller;
        $obj->$action();
    }
}

Why it matters

The entire routing secret is splitting a URL and calling a class - and now you've seen it with your own eyes.
