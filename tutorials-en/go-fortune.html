Go CLI tutorial: fortune clone

⚙ Language: Go 📁 Command-Line Tool 🌐 English page 🔗 Original source
Original source: "Build a command-line app with Go: fortune" — Flavio Copes builds a Go wrapper around the classic fortune utility, learning process execution and piping along the way.

About

A tiny Go program that shells out to the Unix fortune command and prints a random wisdom line — a perfect excuse to learn os/exec, subprocess output and stderr pipes in Go.

What you'll learn

  • Running external commands with os/exec.
  • Capturing combined or separated stdout/stderr.
  • Reading subprocess output streams line by line.
  • Handling errors from child processes.

Core idea

The first version is deliberately naive — one command, capture everything:

gopackage main

import (
	"fmt"
	"os/exec"
)

func main() {
	out, err := exec.Command("fortune", "-f").CombinedOutput()
	if err != nil {
		panic(err)
	}

	fmt.Println(string(out))
}

The next iteration separates the streams — grabbing fortune's stderr pipe and scanning it:

gopackage main

import (
	"bufio"
	"fmt"
	"os/exec"
)

func main() {
	fortuneCommand := exec.Command("fortune", "-f")
	pipe, err := fortuneCommand.StderrPipe()
	if err != nil {
		panic(err)

		fmt.Println(outputStream.Text())

Why it matters

Process execution is how Go tools compose with the rest of the Unix world — and understanding the stdout/stderr split is exactly what you need for robust shell tooling.
