About

Kernel 201: add keyboard and screen support — serial output, scancode handling, and a moving cursor.

What you'll learn

  • Writing to serial port COM1 with outb
  • Receiving and decoding keyboard scancodes
  • Moving the cursor through VGA controller registers

Core idea

Devices are just registers: serial_write() pushes a byte to port 0x3F8, and move_cursor() programs the VGA controller's 0x3D4/0x3D5 registers with a 16-bit position.

c// write to the COM1 serial port
#define PORT_SERIAL 0x3F8

void serial_write(char c) {
    __asm__ volatile (
        "outb %0, %1"        // output byte c to PORT_SERIAL
        : : "a"(c), "Nd"(PORT_SERIAL));
}

Input and output are where an OS stops being a demo and starts being useful — and this is the cleanest example of port programming.
