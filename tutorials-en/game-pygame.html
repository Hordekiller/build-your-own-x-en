Developing Games With PyGame

About

Harrison's PyGame video series builds A bit Racey: a racing car dodging oncoming obstacles. Lesson one covers setup: installing PyGame, creating a window, the game loop and frame-rate control with Clock.

What you'll learn

  • pygame.init(), display setup and the fixed 60 FPS loop with Clock.tick()
  • Event handling (QUIT) and keyboard state via get_pressed()
  • Rendering with fill() and draw.rect() - your first playable game in ~30 lines

Core idea

The canonical structure: clock.tick(60) caps the frame rate, events are polled, keys move the car, and the frame is cleared and redrawn.

Pythonimport pygame

pygame.init()
win = pygame.display.set_mode((800, 600))
pygame.display.set_caption("A bit Racey")

clock = pygame.time.Clock()

# car state
x, y = 400, 500        # position
width, height = 40, 60
vel = 5                # speed

run = True
while run:
    clock.tick(60)     # max 60 frames per second
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            run = False
    # input: arrow keys
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT] and x > 0:          x -= vel
    if keys[pygame.K_RIGHT] and x < 800 - width: x += vel
    # render: clear and draw the car
    win.fill((0, 0, 0))
    pygame.draw.rect(win, (255, 0, 0), (x, y, width, height))
    pygame.display.update()

pygame.quit()
