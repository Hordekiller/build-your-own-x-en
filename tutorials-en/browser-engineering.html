About

Web Browser Engineering: a book that builds a browser from scratch in Python, starting with downloading a page over a raw socket.

What you'll learn

  • Speaking HTTP by hand with a socket
  • Parsing HTML and building a DOM
  • Rendering to a canvas with layouts and paint

Core idea

Chapter one throws away libraries entirely: a raw socket connects to example.com, sends a minimal HTTP/1.0 GET, and prints the response - the moment a 'browser' is born.

Python# chapter 1 of the book: download a page with a simple HTTP request
import socket

s = socket.create_connection(("example.com", 80))
s.sendall(b"GET / HTTP/1.0\r\nHost: example.com\r\n\r\n")

Why it matters

The book that lets you write a browser in fewer than a thousand lines - with tests, and every design decision explained.
