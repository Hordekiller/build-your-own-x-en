About

A neural net from scratch in Go using the gonum matrix library: weight matrices, seeded random initialization, and a full training cycle.

What you'll learn

  • Representing the hidden and output weight matrices with gonum's mat.Dense
  • Seeding rand so training is reproducible
  • Forward and backward passes with matrix algebra

Core idea

The NeuralNet struct carries two matrices — wHidden and wOut — plus a config. NewNetwork() seeds a random source and builds both matrices with the configured neuron counts.

go// the network: weights between each pair of layers + activation
type NeuralNet struct {
    config  NeuralNetConfig
    wHidden *mat.Dense   // hidden-layer weights
