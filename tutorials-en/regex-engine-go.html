How to build a regex engine from scratch

About

A regular expression engine in Go: tokenize the pattern, parse it into tokens for groups, ranges, repeats and alternation - ready to compile into a matcher.

What you'll learn

  • Tokenizing patterns into literals, groups, brackets and repeats
  • Handling character ranges like [a-zA-Z0-9_]
  • Parsing with a cursor-walking approach

Core idea

The engine first converts a pattern such as an email regex into a list of tokens - repeats, ranges and literals. A parser then walks the token stream and builds the shape of the matcher.

Gotype tokenType uint8
type token struct {
   ttype  tokenType
   min    int
   max    int
   negate bool
   chars  []rune
}
const (
   group         tokenType = iota
   bracket       tokenType = iota
   or            tokenType = iota
   repeat        tokenType = iota
   literal       tokenType = iota
)
Gofunc parse(regex string) *parseContext {
   ctx := &parseContext{
      pos:    0,
      tokens: []token{},
   }
   for ctx.pos < len(regex) {
      process(regex, ctx)
      ctx.pos++
   }
   return ctx
}

Why it matters

Reading a Go regex engine's tokenizer and parser demystifies how grep and syntax highlighters work.
