2D breakout game using Phaser

About

MDN's Phaser Breakout tutorial: each step ships a live editable example, so you can modify the code in the browser and instantly see the result. Full code is on MDN's GitHub.

What you'll learn

  • Phaser scenes: Boot, Preload, Create, Update
  • Physics bodies, bounce, velocities and immovable colliders
  • Collision callbacks - destroying bricks when the ball hits them

Core idea

The GameScene loads images, creates a bouncing ball and an immovable paddle under mouse control, lays out a brick grid with colliders, and destroys bricks on contact.

JavaScriptclass GameScene extends Phaser.Scene {
  constructor() { super({ key: 'GameScene' }); }

  preload() {
    this.load.image('ball', 'images/ball.png');
    this.load.image('paddle', 'images/paddle.png');
    this.load.image('brick', 'images/brick.png');
  }

  create() {
    // ball with physics
    this.ball = this.physics.add.image(400, 300, 'ball');
    this.ball.setBounce(1);     // full bounce
    this.ball.setVelocity(160, 160);
    // paddle: fixed at the bottom, follows the mouse
    this.paddle = this.physics.add.image(400, 550, 'paddle');
    this.paddle.setImmovable(true);
    this.physics.add.collider(this.ball, this.paddle);
    // brick grid
    for (let row = 0; row < 3; row++) {
      for (let col = 0; col < 8; col++) {
        const brick = this.physics.add.image(70 + col * 90, 60 + row * 40, 'brick');
        brick.setImmovable(true);
        this.physics.add.collider(this.ball, brick, this.hitBrick, null, this);
      }
    }
    this.input.on('pointermove', (p) => { this.paddle.x = Phaser.Math.Clamp(p.x, 50, 750); });
  }

  hitBrick(ball, brick) { brick.destroy(); }
}

Why it matters

Short, clean and interactive - the best introduction to Phaser and basic game concepts (physics, collision, states).
