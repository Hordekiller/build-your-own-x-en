About

The classic internet socket programming guide: TCP and UDP clients and servers in C, from the very first socket() call to advanced topics like select() and broadcast.

What you'll learn

  • The socket lifecycle: socket, bind, listen, accept, connect
  • Network byte order and the htons/htonl family
  • IPv4/IPv6-agnostic address resolution with getaddrinfo()
  • UDP datagrams vs. reliable TCP streams

Core idea

Everything in the guide rests on two ideas: converting between host and network byte order, and resolving addresses once with getaddrinfo(). Once those are in place, the rest of the API follows a fixed recipe.

chtons(port)     /* Host TO Network Short */
htonl(laddr)    /* Host TO Network Long  */
ntohs(port)     /* Network TO Host Short */
ntohl(laddr)    /* Network TO Host Long  */
inet_pton(AF_INET, "10.12.110.57", &sin.sin_addr);
cstruct addrinfo hints, *res;
memset(&hints, 0, sizeof hints);
hints.ai_family   = AF_UNSPEC;    /* IPv4 or IPv6 */
hints.ai_socktype = SOCK_STREAM;  /* TCP */

getaddrinfo("www.example.net", "3490", &hints, &res);

Why it matters

Beej's guide is the canonical on-ramp for systems-level networking — the one resource that turns socket API docs into something you actually understand.
