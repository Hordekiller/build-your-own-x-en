Implementing a Regular Expression Engine

Original source: "Implementing a Regular Expression Engine"

About

Building a regex engine in JavaScript for very large patterns, based on the state-machine model: states, transitions and epsilon moves.

What you'll learn

  • Modeling a matcher as states with transitions
  • Epsilon transitions that move without consuming input
  • Simulating the machine against an input string

Core idea

The engine is a nondeterministic finite automaton: each state holds an isEnd flag, a transition map indexed by symbol, and epsilonTransitions. Building the engine means wiring these states together.

JavaScriptfunction createState(isEnd) {
    return {
        isEnd,
        transition: {},
        epsilonTransitions: []
    };
}
JavaScriptfunction addEpsilonTransition(from, to) {
    from.epsilonTransitions.push(to);
}

function addTransition(from, to, symbol) {
    from.transition[symbol] = to;
}

Why it matters

State machines are the true heart of regex - and with NFA techniques you can handle patterns of millions of states.
