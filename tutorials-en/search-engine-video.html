About

A video-based course on building a search engine from scratch - tokenization, an inverted index and ranked retrieval.

What you'll learn

  • Tokenizing documents into word sequences
  • Building an inverted index: word to list of (doc, position)
  • Retrieval by intersecting posting lists

Core idea

The core data structure is the inverted index: for each word, a posting list of document IDs and positions. Queries then resolve to cheap list intersections instead of full scans.

Python# inverted index: each word -> list of (document id, position)
index = {}
for doc_id, words in enumerate(documents):
    for pos, word in enumerate(words):
        index.setdefault(word, []).append((doc_id, pos))

Why it matters

The videos make the classic IR pipeline visual - and this inverted index is the same idea behind every modern search engine.
