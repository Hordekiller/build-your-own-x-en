A Simple Content-Based Recommendation Engine in Python

⚙ Language: Python 📁 Web Server 🌐 English page 🔗 Original source
Original source: "A Simple Content-Based Recommendation Engine in Python"
↗ Visit the original tutorial فارسی — Persian version

About

Content-based product recommendation: turn each product into a feature vector (description, category, brand), compute pairwise cosine similarity with TF-IDF, and recommend the nearest items - no training, no cold-start problem.

What you'll learn

  • Building vectors with TF-IDF (linear_kernel for speed)
  • Scoring and ranking similar products for a given id
  • Handling new products with no sales history

Core idea

linear_kernel is cosine similarity computed fast for large matrices; the top-5 closest items (excluding itself) are the recommendations.

Pythonfrom sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import linear_kernel

# each product: id + combined feature text (title, brand, category)
vec = TfidfVectorizer(stop_words='english')
matrix = vec.fit_transform(products['combined'].values)

cosine = linear_kernel(matrix, matrix)   # pairwise similarity

def recommend(product_id, top_n=5):
    idx = products.index[products['id'] == product_id][0]
    scores = list(enumerate(cosine[idx]))
    scores = sorted(scores, key=lambda x: x[1], reverse=True)
    # first is the product itself; start from the second
    return [products.iloc[i]['id'] for i, s in scores[1:top_n + 1]]

Why it matters

No training, no user history - TF-IDF and one matrix multiply give any store 'similar products'.
