About

What you'll learn

  • Complete games with line-by-line explanation (sliding puzzles, snake, memory cards and more)

  • Per-chapter exercises to boost creativity

Core idea

The book's games follow a common skeleton: an event loop with QUIT handling, drawing to DISPLAYSURF, updating, then tick(FPS). Every game is complete and directly runnable.

Pythonimport pygame, sys
from pygame.locals import *

pygame.init()
FPS = 60
fpsClock = pygame.time.Clock()
DISPLAYSURF = pygame.display.set_mode((400, 300))
pygame.display.set_caption('Sample Game')
WHITE = (255, 255, 255)

while True:
    for event in pygame.event.get():
        if event.type == QUIT:
            pygame.quit()
            sys.exit()
    # draw the scene
    DISPLAYSURF.fill(WHITE)
    # ... draw game objects ...
    pygame.display.update()
    fpsClock.tick(FPS)
