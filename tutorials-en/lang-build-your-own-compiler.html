About

A Python tutorial that compiles a subset of its own language into a real x86-64 executable - not assembly! The result is a binary that runs directly on the OS.

What you'll learn

  • Mapping operators to x86-64 opcodes: ModRM/SIB addressing modes up close
  • The call stack rsp/rbp for locals and parameters; SystemV calling convention
  • ELF structure for a runnable executable; inspect output with objdump each chapter

Core idea

Chapters move in small steps: basics and first program, integer math, variables and stack memory, conditionals and loops, functions and calls, then IO and machine bytes.

Python# overview: mapping operators to x86-64 opcodes
# REX.W + 0x01 + ModRM  (e.g. add rax, rbx)
def gen_add(reg1, reg2):
    return bytes([0x48, 0x01, modrm(reg1, reg2)])

def modrm(reg_rm, reg_reg):
    # mod=11 (register-direct) + general registers
    return 0xC0 | (reg_reg << 3) | reg_rm

# for "a + b": a in rax, b in rbx
# then: gen_add(0, 3) -> add rax, rbx   -> 48 01 C3

Why it matters

If you want to know what a computer actually executes, this is the best choice: from your language to the bytes on disk, everything under your control.
