About

mal is not a single implementation: it defines the path to build a Lisp interpreter (Clojure-flavoured) in 9 steps, and you implement every step in any language you like - from Python and JavaScript to Assembly and Haskell.

What you'll learn

  • A shared test suite: every step ships the same tests, so passing them proves the step is done
  • Step 9 is self-hosting: the interpreter runs itself, testing the whole language infrastructure
  • Step 1 is the classic read-eval-print loop; each step adds one capability to the REPL

Core idea

Steps 0-2 build a REPL without evaluation, then numbers and operations, then printing data types with standard representations. Steps 3-5 add an environment with def! and let*, then functions and function calls - here the language becomes real. Steps 6-8 add quote/quasiquote macros, atom types and varargs, and step 9 adds classes, try/catch and operator data structures.

mal invests in every data type (numbers, strings, keywords, list/vector/map) from day one instead of just numbers and lists, which forces a complete central data structure (MalVal) from the start.
