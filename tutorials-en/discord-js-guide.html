Create a Discord bot

About

The complete, most-recommended resource for Discord bots in Node.js. It covers the entire lifecycle: creating the bot application, inviting it with OAuth2, writing your first command with discord.js, then commands, events, buttons, slash commands, and even sharding for big guilds.

What you'll learn

  • Creating a bot application and inviting it with OAuth2 scopes.
  • Setting up a Node.js project and installing discord.js.
  • Handling commands, events and slash commands.
  • Buttons, select menus, embeds and permissions.
  • Sharding and production considerations.

Core idea

The OAuth2 URL is what grants your bot its invite link — the first step before any code runs:

texthttps://discord.com/api/oauth2/authorize?client_id=123456789012345678&permissions=0&scope=bot%20applications.commands

Then the library comes from a single npm install:

shellnpm init -y
npm install discord.js

Why it matters

It is the definitive reference for a widely used platform: official, up to date, and organized so beginners get a running bot on the first page while still covering advanced topics like sharding that matter in production.
