About

An 8-part series building your first roguelike from the ground up - from drawing an @ symbol to full monster combat, random dungeons, field of view, items and more - using RogueSharp for logic and RLNET/MonoGame for display.

What you'll learn

  • Dungeon generation with a random-rooms creation strategy
  • Safe player movement: only walkable cells, with occupation tracking
  • RogueSharp's map API: walkable cells, room placement and player placement

Core idea

RogueSharp generates the dungeon map; the player spawns in the first walkable room and movement is only allowed into walkable cells that the player then occupies.

C#using RogueSharp;
using RogueSharp.MapCreation;

// build a dungeon with random rooms
IMapCreationStrategy<Map> strategy =
    new RandomRoomsMapCreationStrategy<Map>(80, 50, 30, 12, 6);
Map map = Map.Create(strategy);

// place the player in the first room
foreach (Cell cell in map.GetAllCells()) {
  if (cell.IsWalkable) { playerX = cell.X; playerY = cell.Y; break; }
}

// safe movement: only walkable cells
if (map.IsWalkable(newX, newY)) {
  playerX = newX; playerY = newY;
  map.SetIsWalkable(playerX, playerY, false); // occupy the cell
}

Why it matters
