Redux: Implementing Store from Scratch

About

Redux: implementing the store from scratch — an egghead lesson that builds createStore by hand and proves dispatch and subscriptions work end to end.

What you'll learn

  • The store as the single source of truth
  • Dispatch as the only way state changes
  • Subscribing and unsubscribing listeners
  • A tiny counter end to end

Core idea

createStore is the whole engine — state, listeners, dispatch:

jsconst createStore = (reducer) => {
  let state;
  let listeners = [];

  // only the reducer can change the state
  const getState = () => state;

  const dispatch = (action) => {
    state = reducer(state, action);
    listeners.forEach((listener) => listener());
  };
  ...
};
js// a simple counter reducer
const counter = (state = 0, action) => {
  switch (action.type) {
    case 'INCREMENT': return state + 1;
    case 'DECREMENT': return state - 1;
    default: return state;
  }
};

const store = createStore(counter);
store.dispatch({ type: 'INCREMENT' });

Why it matters

Fifteen minutes and one function — and you have personally implemented the state container that runs half the web's frontends.
