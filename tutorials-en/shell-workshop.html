About

A workshop that builds a real shell in C with pipes and redirection: parsing command lines and wiring file descriptors.

What you'll learn

  • getline() and splitting a line into argv
  • execvp and why it never returns on success
  • Pipes and redirection by juggling file descriptors

Core idea

After splitting a line into argv, the shell forks and calls execvp. Pipes let one process's stdout feed another's stdin - the file descriptor plumbing at the heart of every Unix pipeline.

Bashheeee> ls
shell   shell.c
Cchar *line = NULL;
int capacity = 0;
getline(&line, &capacity, stdin);
C/* arguments: { "ls", "-l", "/tmp" } */
char *argv[] = { "ls", "-l", "/tmp", NULL };
execvp("ls", argv);   /* on success this never returns */

Why it matters

Pipes and redirection are the essence of Unix; this workshop gets you to a working shell that does both.
