About

SlowTorch: a from-the-ground-up implementation of PyTorch in 100% pure Python — tensors, autograd and modules that mirror the torch API.

What you'll learn

  • A Tensor class with data, gradients and requires_grad
  • The Module pattern and Linear layers
  • Composing a TwoLayerNet exactly like PyTorch code

Core idea

The Tensor class is PyTorch's Tensor in miniature: it carries data, tracks gradients, and respects requires_grad. Modules and Linear layers compose into networks with the same look and feel as real torch code.

python# tensor: data + autograd capability (simplified)
class Tensor:
    def __init__(self, data, requires_grad=False):
        self.data = data
        self.grad = None
        self.requires_grad = requires_grad
