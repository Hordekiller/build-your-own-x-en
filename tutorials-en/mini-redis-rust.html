Build your own Redis client and server

About

An async Redis implementation in Rust under Tokio. You'll learn async primitives — spawning, shared state — by building a Mini-Redis server, client library, and wire protocol from scratch, runnable against genuine Redis tools.

What you'll learn

  • Tokio fundamentals: async tasks, channels, shared state.
  • Spawning and coordinating concurrent connection handlers.
  • The RESP protocol and a full client/server pair.
  • Integration-testing against the real CLI.

Core idea

Setup is honest: Rust toolchain first, then the reference tools — because real Redis clients are your test suite:

shell$ rustc --version
$ cargo install mini-redis
$ mini-redis-server

$ mini-redis-cli get foo

Then the build: a wire protocol crate, a server that parses frames and stores key/values in shared state, and a client crate exposing set, get and pub/sub — each chapter a complete Tokio lesson.

Why it matters

This is the canonical "async Rust by doing" path: every Tokio concept — tasks, channels, select, shared state — appears because the server needs it, and correctness is proven by interop with the actual Redis ecosystem.
