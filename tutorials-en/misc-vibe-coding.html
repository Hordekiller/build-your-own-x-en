About

A guide to 'vibe coding': building software by steering generative AI tools with natural-language descriptions instead of writing every line. It adapts classic build-your-own-X projects into prompt kits - goal, design constraints, acceptance tests and learning notes - so you still learn while the AI accelerates implementation.

What you'll learn

  • When AI-assisted building still teaches - and when it doesn't
  • Prompt patterns: explain first, implement separately, write tests
  • Adapting classic BYOX projects into prompt kits

Core idea

In every prompt you should ask the tool to 'explain first', 'implement separately' and 'write tests' - that keeps the learning cycle alive. Understand the architecture yourself; the AI only speeds up the implementation.

Prompt1. First explain the architecture and the key concepts.
2. Then implement it step by step, one file at a time.
3. Write acceptance tests for each step.
4. Point out what I should learn from each decision.

Rules: educational tone, no magic, no skipping steps, ask me before adding complexity.

Why it matters

Answers the big question of the AI era head-on: you can build things fast and still understand them deeply.
