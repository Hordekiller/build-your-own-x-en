About

Reimplement PyTorch's internals from the ground up across 34 stages: tensors, autograd, modules, optimizers and datasets — in Python.

What you'll learn

  • Building a Value node with a computation graph
  • Automatic differentiation via backward passes
  • The anatomy of a modern deep-learning framework

Core idea

Everything starts with Value: a node holding data, a gradient, and a reference to its parent nodes. From that single class, the whole framework — tensors, layers, optimizers — grows stage by stage.

python# stages 1-5: the core of autodiff — a node that knows its parents
class Value:
    def __init__(self, data, _children=(), _op=""):
        self.data = data
        self.grad = 0.0
        self._prev = set(_children)   # parents in the computation graph
        self._op = _op

Why it matters

Frameworks stop being magic once you have rebuilt their skeleton: this is the fastest way to understand exactly what PyTorch does for you.
