About

Build Yourself a Redux: from the Zapier engineering blog — a from-scratch implementation of reducer composition, store subscription and React wiring.

What you'll learn

  • Reducers as pure state transformers
  • combineReducers: one tree from many reducers
  • The subscribe/getState/dispatch store contract
  • Connecting a plain store to React components

Core idea

The store's power is that a single reducer can be grown from many:

jsfunction combineReducers(reducers) {
  return (state = {}, action) => {
    const nextState = {};
    for (const key in reducers) {
      // each reducer updates only its own slice
      nextState[key] = reducers[key](state[key], action);
    }
    return nextState;
  };
}
jsclass Counter extends React.Component {
  componentDidMount() {
    // every state change -> re-render
    this.unsubscribe = store.subscribe(() => this.forceUpdate());
  }
  componentWillUnmount() {
    this.unsubscribe();
  }
  ...
}

Why it matters

Redux's ideas — pure functions, one state tree, explicit dispatch — survive every framework cycle, and implementing them yourself is how they stop being buzzwords.
