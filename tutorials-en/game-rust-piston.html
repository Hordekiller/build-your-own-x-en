Adventures in Rust: A Basic 2D Game

About

One of the first famous Rust game tutorials: with Piston (a set of crates for windowing, input and rendering) it builds a simple 2D Defender-style shooter, focusing on modular architecture.

What you'll learn

  • Separating main.rs (window, event loop) from lib.rs (update/render logic, entities)
  • PistonWindow, events, draw_2d and the Update/Render traits
  • A working game with a single cargo run after adding crates to Cargo.toml

Core idea

main.rs owns the window and dispatches events: updates from input events, draws with draw_2d. Game logic lives in lib.rs as entities implementing Update/Render traits.

Rustuse piston_window::*;
use adventures::render::{Render, draw};
use adventures::update::{Update, update};
use adventures::Player;

fn main() {
    let mut window: PistonWindow = WindowSettings::new(
        "Adventures in Rust", [640, 480])
        .exit_on_esc(true).build().unwrap();

    let mut player = Player::new(&mut window);

    while let Some(event) = window.next() {
        // update logic with input events
        update(&mut player, &event);
        // render on draw events
        window.draw_2d(&event, |c, g| {
            clear([0.0, 0.0, 0.0, 1.0], g);
            draw(&player, &c, g);
        });
    }
}

Why it matters

A clean modular Rust game using the classic Piston stack - great practice organizing game code across files and traits.
