About

James Kyle's Super Tiny Compiler shows the skeleton of all compilers in minimal code: Lisp-like input (add 2 (subtract 4 2)) becomes C-like output (add(2, subtract(4, 2))) in about 200 lines.

What you'll learn

  • tokenizer: string to tokens; parser: tokens to AST; transformer: input AST to output AST via traverser; codeGenerator: AST to code
  • The traverser with enter/exit visits - the crucial recursive machinery
  • Documented, commented code you can step through with node

Core idea

All key compiler concepts - lexing, parsing, AST, traverser, codegen - fit in this tiny project because the input is simple; focus stays on concepts instead of language details.

JavaScriptfunction tokenizer(input) {
  let current = 0;
  let tokens = [];
  while (current < input.length) {
    let char = input[current];
    // parentheses
    if (char === '(') {
      tokens.push({ type: 'paren', value: '(' });
      current++; continue;
    }
    // numbers: several digits in a row
    const NUMBERS = /[0-9]/;
    if (NUMBERS.test(char)) {
      let value = '';
      while (NUMBERS.test(char)) {
        value += char;
        char = input[++current];
      }
      tokens.push({ type: 'number', value });
      continue;
    }
    // names (add, subtract, ...)
    const LETTERS = /[a-z]/i;
    if (LETTERS.test(char)) {
      let value = '';
      while (LETTERS.test(char)) {
        value += char;
        char = input[++current];
      }
      tokens.push({ type: 'name', value });
      continue;
    }
    const WHITESPACE = /\s/;
    if (WHITESPACE.test(char)) { current++; continue; }
    throw new TypeError('unknown character: ' + char);
  }
  return tokens;
}

Why it matters

A soft, friendly entry into compilers: keep the core in mind (tokenizer, parser, AST, traverser, codegen), then move on to Little Lisp or Crafting Interpreters.
