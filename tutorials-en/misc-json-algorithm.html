JSON Decoding Algorithm

⚙ Language: Python 📁 Web Server 🌐 English page 🔗 Original source
Original source: "JSON Decoding Algorithm"

About

A complete JSON decoder in about 80 lines: one recursive function that dispatches on the next character - strings with escapes, numbers with floats, arrays, objects, and the literals true/false/null.

What you'll learn

  • The 8 JSON value types and a single-dispatch decoder
  • String escaping and number parsing (int vs float)
  • Recursion across nested arrays and objects

Core idea

read_value looks at one character and hands off: " for strings, [ for arrays, { for objects, digits for numbers, and prefixes for literals - the cleanest recursive structure in parsing.

Pythondef decode(json_string):
    """the 80-line JSON decoder."""
    pos = 0
    n = len(json_string)

    def read_ws():
        nonlocal pos
        while pos < n and json_string[pos] in ' \t\n\r':
            pos += 1

    def read_value():
        nonlocal pos
        read_ws()
        c = json_string[pos]
        if c == '"': return read_string()
        if c == '[': return read_array()
        if c == '{': return read_object()
        if c in '0123456789-': return read_number()
        if json_string.startswith('true', pos):
            pos += 4; return True
        if json_string.startswith('false', pos):
            pos += 5; return False
        if json_string.startswith('null', pos):
            pos += 4; return None
        raise ValueError(f'invalid JSON: {c} at {pos}')

    return read_value()
