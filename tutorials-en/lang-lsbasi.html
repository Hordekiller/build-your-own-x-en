About

Ruslan Spivak's famous series (20+ parts) "Let's Build A Simple Interpreter": from a 3+5 calculator to a language with variables, conditionals, loops and clearly separated Lexer and Parser.

What you'll learn

  • Token and Lexer, Parser and AST, Interpreter (evaluation) as linear progress
  • Operator precedence and grammar diagrams; syntax diagrams for intuition
  • A visitor pattern over the AST; extension with your own keywords (BEGIN...END style)

Core idea

Ruslan writes extremely explanatory prose with grammar diagrams and "why not to do it this way" asides. The series ends with conditionals, loops, logical operators and the final structure of a real language.

Python# token types
INTEGER, PLUS, MINUS, MUL, DIV = 'INTEGER', 'PLUS', 'MINUS', 'MUL', 'DIV'

class Interpreter:
    def __init__(self, text):
        self.text = text
        self.pos = 0
        self.current_token = None

    def get_next_token(self):
        # lexer: skip whitespace, detect numbers/operators
        while self.pos < len(self.text) and self.text[self.pos].isspace():
            self.pos += 1
        if self.pos >= len(self.text):
            return Token(EOF, None)
        tok = self.text[self.pos]
        if tok.isdigit():
            start = self.pos
            while self.pos < len(self.text) and self.text[self.pos].isdigit():
                self.pos += 1
            return Token(INTEGER, int(self.text[start:self.pos]))
        if tok == '+':
            self.pos += 1
            return Token(PLUS, '+')
        raise Exception('parse error')

Why it matters

The best intuitive start for an interpreter with no compiler prerequisites - pair it with Norvig's lispy to compare shell-style and Lisp-style interpreters.
