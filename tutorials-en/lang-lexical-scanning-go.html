Lexical Scanning in Go

⚙ Language: Go 📁 Programming Language 🌐 English page 🔗 Original source
Original source: "Lexical Scanning in Go"

About

Rob Pike's classic talk explains how the lexers of Go's text/template and html/template packages are implemented - a state machine architecture later copied in many languages.

What you'll learn

  • The stateFn pattern: every state is a function that returns the next state function
  • The main loop: for state != nil { state = state(l) }
  • Sending tokens over a channel: items (type + text) separate the lexer from the parser

Core idea

The lexer is built around functions instead of switch logic, making it clean and testable. Each item carries a type, the raw text and a line number for error messages; the scanner runs as a goroutine feeding a channel.

Gotype stateFn func(*lexer) stateFn

func (l *lexer) run() {
    for state := l.state; state != nil; {
        state = state(l)   // run state, get next state
    }
}

// initial state: text until a left delimiter
func lexText(l *lexer) stateFn {
    for {
        if strings.HasPrefix(l.input[l.pos:], "{{") {
            l.pos += 2
            return lexLeftDelim   // go into the tag state
        }
        l.next()
        if l.pos >= len(l.input) {
            l.emit(itemEOF)
            return nil            // end
        }
    }
}

Why it matters

30 minutes of video plus a few hours of practice gets you pro-level lexer design with state machines - the foundation of every compiler frontend.
