Learn how to write a hash table in C

About

Build a hash table in C from scratch: key/value items, an array-backed table, a hash function with tunable prime and modulus, collision handling, and growing the table when it fills up - the fundamentals hidden inside every dictionary and cache.

What you'll learn

  • Hash functions and mapping keys to array indices
  • Collision resolution: chaining vs open addressing
  • Manual memory management and table resizing in C

Core idea

A weighted sum of characters mod m produces the index; tuning the prime multiplier a and table size m improves the distribution. Collisions are handled with chaining (a linked list per slot) or open addressing.

C#include <stdlib.h>
#include <string.h>

typedef struct {
    char* key;
    char* value;
} ht_item;

// simple hash: weighted sum of characters
static int hash(const char* s, const int a, const int m) {
    long hash = 0;
    const int len = strlen(s);
    for (int i = 0; i < len; i++) {
        hash = (hash * a + s[i]) % m;
    }
    return hash;
}

Why it matters

O(1) lookup feels like magic until you've managed the memory and collisions yourself - a rite of passage for C programmers.
