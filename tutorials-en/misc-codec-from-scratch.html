Video Encoding from Scratch

⚙ Language: Go 📁 Web Server 🌐 English page 🔗 Original source
Original source: "Video Encoding from Scratch"

About

Implement a practical subset of the H.264 video codec from scratch in Go: parsing NAL units, decoding macroblocks with motion compensation and Exp-Golomb (readUE/readSE) integers - far more instructive than a 600-page spec.

What you'll learn

  • H.264 structure: NAL units, start codes and types
  • Macroblocks: DCT coefficients, CAVLC and Exp-Golomb entropy coding
  • Motion compensation from previous frames

Core idea

Each NAL unit has a header byte whose bottom 5 bits are the type: 1 for non-IDR slice, 5 for IDR (keyframe), 7 for SPS metadata. Frames split into 16x16 macroblocks, each predicted from motion or decoded directly.

Go// parse a NAL unit: start code + header + payload
type NAL struct {
    Header  byte
    Type    int
    Payload []byte
}

func parseNAL(data []byte) (*NAL, error) {
    start := 0
    if len(data) > 4 && data[0]==0 && data[1]==0 && data[2]==0 && data[3]==1 {
        start = 4                            // 00 00 00 01
    } else if len(data) > 3 && data[0]==0 && data[1]==0 && data[2]==1 {
        start = 3                            // 00 00 01
    } else {
        return nil, errors.New("invalid NAL format")
    }
    header := data[start]
    return &NAL{
        Header:  header,
        Type:    int(header & 0x1F),         // 5 bits: NAL type
        Payload: data[start+1:],
    }, nil
}

Why it matters

Video compression becomes small, readable code - the H.264 subset every player and camera relies on.
