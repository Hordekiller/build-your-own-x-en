About

This article shows Ruby game development is fun: a terminal Snake game with no graphics, teaching structured thinking (Board, Snake, Food and Game classes) using terminal characters.

What you'll learn

  • Class design: Board (grid and bounds), Snake (segment list), Food (spawning), Game (loop)
  • The elegant growth trick: body.unshift(new_head) with conditional pop
  • Collision checks against walls or self, then render in the terminal

Core idea

The snake is a list of segments; each step prepends a new head and pops the tail unless food was eaten - movement and growth with no extra code.

Ruby# board: grid and bounds
class Board
  attr_accessor :grid_size, :x_limit, :y_limit
  def initialize(grid_size)
    @grid_size = grid_size
    @x_limit = @grid_size / 2
    @y_limit = @grid_size / 2
  end
  def random_position
    [rand(-@x_limit..@x_limit), rand(-@y_limit..@y_limit)]
  end
  def within?(x, y)
    x.between?(-@x_limit, @x_limit) && y.between?(-@y_limit, @y_limit)
  end
end

# snake: a list of segments
class Snake
  attr_accessor :body, :direction_head
  def initialize(length)
    @direction_head = [1, 0]
    @body = Array.new(length) { |i| [0, i] }
  end
  def head
    @body.first
  end
  # step: prepend the new head, pop the tail unless we ate
  def move(food_eaten = false)
    new_head = [head[0] + @direction_head[0], head[1] + @direction_head[1]]
    @body.unshift(new_head)
    @body.pop unless food_eaten
  end
end

Why it matters

A terminal Snake teaches structured game thinking with zero graphics - perfect for Rubyists who want a fun, instructive project.
