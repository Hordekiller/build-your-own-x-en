About

A JavaScript template engine in about 20 lines, using the Function constructor to compile template strings into code.

What you'll learn

  • The <%name%> interpolation syntax and its regex
  • Executing template code with the new Function constructor
  • Injecting data variables into the generated function scope

Core idea

A regex picks every <%...%> tag out of the template. The body is then compiled with new Function(...) using the data object's own keys as parameters - so the template body can literally use those names.

JavaScriptvar TemplateEngine = function(tpl, data) {
    // the magic happens here ...
}
var template = 'Hello, my name is <%name%>. I\'m <%age%> years old.';
console.log(TemplateEngine(template, { name: 'Krasimira', age: 29 }));
JavaScriptvar re = /<%([^%>]+)?%>/g;
var match = re.exec(tpl);
// match holds: "<%name%>", "name", plus index and input

// to process every match, loop with while (match = re.exec(tpl))
JavaScriptvar fn = new Function("arg", "console.log(arg + 1);");
fn(2); // prints 3 - just like function(arg) { console.log(arg + 1); }

Why it matters

Twenty lines that show how frameworks like the early lodash templates worked - code generation as a feature.
