Build Your Own Database

Original source: "Build Your Own Database" — a CodeProject series by Dudi (Moka) that implements a full on-disk database in C#, modeled on real storage engines.

About

A C# database engine developed in three layers: a block-oriented file storage, a record storage built on top of it, and indexes that map keys to record ids — a realistic on-disk architecture inspired by the CodeProject "Build Your Own" series.

What you'll learn

  • Modeling domain data (a cow farm) in C# classes.
  • Append-only file persistence with block headers.
  • Record storage: insert, update, delete, find.
  • Indexes: maps, B-trees and search structures.

Core idea

The whole database is defined by two contracts. The first is the domain — the data you store:

csharppublic class CowModel
{
    public Guid Id { get; set; }
    public string Breed { get; set; }
    public int Age { get; set; }
    public string Name { get; set; }
    public byte[] DnaData { get; set; }
}

The second is the record API — ad-hoc queries included:

csharppublic interface ICowDatabase
{
    void Insert (CowModel cow);
    void Delete (CowModel cow);
    void Update (CowModel cow);
    CowModel Find (Guid id);                       // adhoc
    IEnumerable<CowModel> FindBy (string breed, int age); // adhoc
}

Why it matters

Layered storage — block layer, record layer, index layer — is the architecture behind real databases like SQLite and Postgres, and this series makes each layer a discrete, testable milestone.
