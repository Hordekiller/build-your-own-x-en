About

A 500 Lines classic: optical character recognition without a neural network — least squares classification on normalized digit images.

What you'll learn

  • Preprocessing: binarizing, finding the center of mass, subsampling
  • Training by solving the least-squares problem directly
  • Predicting with a one-shot matrix solve instead of gradient descent

Core idea

Each digit is normalized into a small binary image. Instead of iterating, the tutorial solves for W directly with np.linalg.lstsq — minimizing ‖X·W − Y‖ in one step — then picks the digit with the highest score.
