Build a C#/WPF RPG

About

This series builds a complete graphical RPG: 2D world movement, turn-based combat, items, quests and trading rooms. Unlike the simple text RPG, it has a real WPF/XAML UI and introduces a layered architecture.

What you'll learn

  • Layered architecture: the game world fully independent from the UI
  • WPF/XAML UI and proper design rules for maintainable code
  • Turn-based combat, item handling, quests and trading rooms

Core idea

The course separates the game world from presentation with a layered design; the UI layer binds to world state while all logic stays testable and independent.

C#// layered architecture: world logic is UI-independent
// GameEngine/  - pure game logic (world, combat, quests)
// UI/          - WPF/XAML views bound to the engine
public class GameSession {
  public Player CurrentPlayer { get; set; }
  public Location CurrentLocation { get; set; }

  // the UI subscribes to these events; logic never touches controls
  public event EventHandler<GameMessageEventArgs> OnMessageRaised;
  public void MoveTo(Location loc) {
    CurrentLocation = loc;
    OnMessageRaised?.Invoke(this,
        new GameMessageEventArgs($"You moved to {loc.Name}"));
  }
}

Why it matters

After the text RPG, this is the natural next step: real WPF UI plus clean architecture patterns for a complete graphical game.
