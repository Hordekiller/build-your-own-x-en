How to implement a programming language in JavaScript

About

This series implements a small functional language called PL in JavaScript - tokens, variables, functions and arrays - with a distinctive style: short code examples and terse explanations, zero fluff.

What you'll learn

  • Tokens: a simple regex-based lexer; parsing: recursive-descent functions from the grammar
  • Evaluation: walking and executing the AST; functions: lambda and closures
  • Environment and scope: local and global variables

Core idea

A minimal parser for a math dialect handles parenthesized groups, numbers and words with precedence; the evaluator keeps an env table and evaluate/apply functions. The series is excellent for learning the execution model - where variables live and how function calls happen.

JavaScript// minimal parser for a math dialect (with precedence)
function parse_atom() {
  return function() {
    if (is_punc("(")) {
      skip_punc("(");
      var exp = parse_expression();
      skip_punc(")");
      return exp;
    }
    if (is_num()) return make_number(parse_num());
    if (is_word()) return make_word(parse_word());
    error("unexpected token");
  };
}

// expr := atom (("+"|"-") atom)*
function parse_expression() {
  var left = parse_atom();
  while (is_op("+") || is_op("-")) {
    var op = parse_op();
    var right = parse_atom();
    left = { type: "binary", operator: op, left: left, right: right };
  }
  return left;
}

Why it matters

In a few hours of study you own a functional language with functions, variables and arrays; the densest short read before deeper journeys like mal and Crafting Interpreters.
