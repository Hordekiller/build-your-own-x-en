How to build a simple actor-based blockchain

⚙ Language: Scala 📁 Blockchain / Cryptocurrency 🌐 English page 🔗 Original source
Original source: "How to build a simple actor-based blockchain" — a Luca Florio blog post that models a blockchain with Scala actors and proof-of-work.
↗ Visit the original tutorial فارسی — Persian version

About

A short Scala tutorial that treats a blockchain as a natural fit for the actor model: nodes are actors, blocks are messages, and proof-of-work becomes a computation each actor performs before broadcasting its new node.

What you'll learn

  • The actor model and how it maps to blockchain nodes.
  • Representing transactions and blocks as case classes.
  • A proof-of-work hash puzzle.
  • Message-passing between peers.

Core idea

The consensus rule is stated directly — a hash that starts with enough zeros:

textNzerosHash = SHA-256(previousNodeHash + proof)

And the domain is just two case classes:

scalacase class Transaction(sender: String, recipient: String, value: Long)

Why it matters

Connecting blockchains to message-passing concurrency is a genuinely different angle: you see distributed consensus as a systems problem rather than a data structure, which is how real permissioned networks are built.
