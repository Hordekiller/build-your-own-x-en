How to create an OS from scratch

About

How to create an OS from scratch: 23 tiny lessons from a boot sector that prints to the screen, all the way to fork() and beyond.

What you'll learn

  • The minimal boot sector: an infinite loop plus the 0xaa55 magic
  • Assembling and testing with NASM and QEMU
  • Growing the kernel lesson by lesson toward Unix features

Core idea

The first lesson is famously tiny: a boot sector that just loops forever, padded to 510 bytes and finished with the 0xaa55 boot signature. Building and booting it with qemu is the whole first lesson.

nasm; lesson01: the simplest boot sector — loop forever
loop:
    jmp loop

times 510-($-$$) db 0   ; pad up to byte 510
dw 0xaa55               ; the two magic boot bytes
bashnasm -f bin boot_sect_simple.asm -o boot_sect_simple.bin
qemu-system-i386 -fda boot_sect_simple.bin
# or build a floppy disk image and boot from it
dd if=/dev/zero of=floppy.img bs=512 count=2880
dd if=boot_sect_simple.bin of=floppy.img

Why it matters

Small, sequential, and complete — it is the most popular starting point for new OS developers for very good reasons.
