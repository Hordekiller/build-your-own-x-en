About

Kilo - a text editor in about 1000 lines of C, built in 9 steps from raw terminal mode to a syntax-highlighting editor.

What you'll learn

  • Putting the terminal into raw mode with termios
  • Reading keys and handling ctrl-key escapes
  • An append buffer (abuf) for blink-free screen updates

Core idea

Kilo starts with raw mode: disable canonical processing on the terminal so the editor can read keys as they arrive. Rendering goes through an append buffer so the screen refreshes in one write.
