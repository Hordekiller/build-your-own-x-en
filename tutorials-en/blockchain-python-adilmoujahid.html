A Practical Introduction to Blockchain with Python

About

A fully-fledged Python blockchain with three layers: a Flask blockchain API, a REST client to interact with the chain, and a cryptocurrency wallet layer that issues signed transactions with public/private keys.

What you'll learn

  • Transactions with digital signatures (ECDSA).
  • Blockchain API endpoints with Flask.
  • A REST client that mines and posts transactions.
  • Wallet management: keys, addresses and transaction signing.

Core idea

Transactions are objects that sign their own data:

pyclass Transaction:

    def __init__(self, sender_address, sender_private_key, recipient_address, value):
        self.sender_address = sender_address
        self.sender_private_key = sender_private_key
        self.recipient_address = recipient_address
        self.value = value

    def __getattr__(self, attr):
        return self.data[attr]

    def to_dict(self):
        return OrderedDict({
            'sender_address': self.sender_address,
            'recipient_address': self.recipient_address,
            'value': self.value
        })
    # ...

And the whole API layer comes together with one object:

pyapp = Flask(__name__)

Why it matters

It is a rare tutorial that gets all the way to a working wallet with real cryptographic keys — while remaining gentle for beginners. The client/server split also mirrors how real blockchain systems are organized.
